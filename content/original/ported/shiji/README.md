# 始计确定性移植

`zjjuxiang`（拒降）：其他角色被救离濒死后可发动一次，依次消耗限定技、造成 1 点伤害，
并按目标体力上限摸牌。周姬其余技能尚未完成，因此本包暂不发布武将定义。

`spdengli`（登历）：逐个【杀】目标比较使用者与目标的体力值；每个等体力目标独立触发一次。

`reshengxi`（界生息）：结束阶段开始时，若本回合未造成过伤害，可摸两张牌。

`xinjuxiang`（拒降）：限定技，其他存活角色脱离濒死状态后，可对其造成 1 点伤害。

`hxrenshi2`：仁释临时存储清理标记，无独立规则行为。

`xinguixiu`（新闺秀）：结束阶段开始时，体力为奇数则摸一张；否则若已受伤则回复一点体力。

`xuancun`（悬存）：其他角色的结束阶段开始时，若自己的手牌数小于体力值，可令其摸差值张牌，至多两张。

`shameng`（歃盟）：出牌阶段每回合限一次，弃置两张同色手牌并选择一名其他角色；其摸两张牌，然后自己摸三张牌。同色、非自身目标和次数均由主动技包契约声明并由引擎校验。

`spmingshi`（名士）：每受到一点来自其他存活角色的伤害，伤害来源锁定弃置一张手牌或装备牌。

`xianghai/xianghai_g`（乡害）：拥有者的装备牌在规则中视为【酒】；每名存活拥有者使其他角色
的手牌上限 -1，多个拥有者分别叠加且不影响自己。旧 JS 的全局助手 `xianghai_g` 已折叠进
父技能的权威光环，助手 ID 以空定义保留兼容。

`mbdiaodu`（调度）：准备阶段可发动；由拥有者选择一张当前可移动的装备牌，再选择一名既非
自己也非原持有者的合法接收者。目标同槽装备先进入弃牌堆，移动完成后原持有者摸一张牌。
卡牌、装备槽和接收者在每个选择屏障后都由引擎重新校验。

`qinzheng`（勤政）：锁定技；每次使用或打出牌后，根据本局累计次数命中的 3/5/8 倍数，
分别从牌堆顶优先获得一张【杀/闪】、【桃/酒】、【决斗/无中生有】。同次命中的牌批量获得，
不搜索弃牌堆；旧 `qinzheng_count` 仅用于界面计数，已折叠进引擎的权威历史。

`spwuku`（武库）：锁定技；有角色使用装备牌时，若拥有者的“武库”标记少于三枚，获得
一枚。装备牌使用与三枚上限均由权威过滤器校验；国战模式的二枚上限不建模，随既有
identity-standard 规则集发布。旧 JavaScript 只作语义证据，不进入 npack 或运行时。

`spsanchen`（三陈）：觉醒技，结束阶段开始时若“武库”标记大于 2，加 1 点体力上限、
回复 1 点体力并获得【灭吴】。`spmiewu`（灭吴）每回合限一次，消耗一枚“武库”，
将一张手牌或装备牌当任意基本牌或锦囊牌使用或打出，结算后摸一张牌。杜预
（`sp_duyu`）完成闭环，作为完整武将进入选将池。

`shenzhu`（神助）：使用实体【杀】后，选择摸一张牌且本回合使用【杀】的次数上限+1，
或摸三张牌且本回合不能再使用【杀】。`shenzhu_more`/`shenzhu_less` 为临时子技能。

`spjungong`（峻攻）：出牌阶段限一次，弃置 `used + 1` 张手牌/装备牌或失去等量体力，
对一名其他角色使用虚拟【杀】；若此【杀】造成伤害，则禁用本主动技至回合结束。
选择、失体力与命中禁用由 ABI 400 权威原语 `spjungong_discard_or_lose_then_sha` 与
`owner_source_sha_damage_recorded_by_skill` 响应。高览（`sp_gaolan`）与已移植的
`spdengli`（登历）完成闭环，作为完整武将进入选将池。

`spwanwei`（挽危）：出牌阶段限一次或当其他角色进入濒死状态时，可令其回复体力，然后失去体力。由 ABI 401 权威原语 `spwanwei_active` 与 `spwanwei_dying` 响应。

`spyuejian`（约俭）：手牌上限基数等于体力上限；濒死时可弃两张手牌/装备牌回复 1 点体力。
卞夫人（`sp_bianfuren`）完成闭环，作为第 347 名完整武将进入选将池。

`yingba`（英霸）：出牌阶段限一次，令一名其他角色失去 1 点体力上限并获得一枚“平定”
标记，然后自己失去 1 点体力上限。`yingba_mark` 提供按标记数的手牌上限加成。

完整武将 `shen_sunce`（神孙策）已发布：初始 1/6 体力，装配既有 `yingba`、`scfuhai`
与 `pinghe`；本批仅补角色闭包，不新增 ABI。

`gebo`（割卜）：任何角色回复体力后，牌堆顶一张牌进入“仁库”（映射为拥有者的技能牌堆）。

`spyilie`（毅烈）：出牌阶段开始时三选一：本阶段使用【杀】的次数上限+1；本回合使用
【杀】被【闪】抵消时摸一张牌；或背水失去 1 点体力并执行前两项。
`spyilie_add`/`spyilie_miss` 为临时子技能。

`spfenming`（分明）：出牌阶段限一次，选择一名体力值不大于你的角色；未横置则横置，
已横置则获得其一张牌（对自己仅装备区）。体力约束由 ABI 402 `hp_lte_owner` 校验。
SP 陈董（`sp_chendong`）与已移植的「毅烈」完成闭环，作为完整武将进入选将池。

`spxiangzhen`（象阵）：锁定技，你不能成为【南蛮入侵】的目标。
“南蛮造成伤害后来源与你各摸一张牌”需要按伤害来源区分的全局事件，暂未建模。

`spfangzong`（芳踪）：结束阶段开始时，若手牌数小于存活角色数（至多 8），摸至该数；
当前回合角色不能对你使用伤害牌（用 `card_target_cancel_from_current` 近似，按当前
回合角色统一取消，不区分牌类）。

`spxizhan`（嬉战）：其他角色回合开始时，须弃一张牌或失去 1 点体力；弃牌则令芳踪本回合
失效，并按花色视为用牌（♠酒 / ♥无中 / ♣铁索 / ♦火杀无视距离）。由 ABI 403
`resolve_spxizhan` 结算。SP 花鬘（`sp_huaman`）与象阵、芳踪完成闭环。
