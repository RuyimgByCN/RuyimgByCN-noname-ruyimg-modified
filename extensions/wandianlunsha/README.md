# 玩点论杀归档扩展迁移

- 来源：`archive/upstream/noname/apps/core/extension/玩点论杀`。
- 本批闭合 `wdb_feishi`（费诗，3 体力，蜀）：【率言】在其他角色于费诗回合外回复后，由费诗
  选择是否发动，再由回复角色强制选择令费诗摸一张牌，或令费诗弃置其一张手牌/装备牌；
  【墨守】仅阻止【乐不思蜀】和【兵粮寸断】以费诗为目标。
- 本批闭合 `wdb_hanlong`（韩龙，4 体力，魏）：【伺机】按弃牌阶段实际弃置的【杀】数摸两倍牌；
  【刺酋】令对未受伤目标造成的【杀】伤害 +1，若增加后足以令其进入濒死，则该角色进入濒死时
  立即死亡，韩龙同时失去【刺酋】。
- 本批闭合 `wdb_liufu`（刘馥，3 体力，魏）：【筑城】在没有“筑”的结束阶段存入牌堆顶
  `max(1, 已损失体力)` 张牌，成为【杀】目标时令使用者弃置等量牌，否则取消该目标；【夺气】
  可在他人的出牌阶段发生弃牌后移去一张“筑”并结束该阶段。旧 JS 的过滤器使“有筑时获得全部筑”
  分支不可达，迁移按实际可执行语义保留。
- 本批闭合 `wdb_liuyan`（刘焉，3 体力，群）：【绝道】弃一张手牌后横置，横置期间其计算至
  他人以及他人计算至其的距离均 +1；【割据】准备阶段可按“没有任何同势力成员能以攻击范围覆盖
  刘焉”的其他已知势力数摸牌。
- 本批闭合 `wdb_liuzan`（留赞，4 体力，吴）：【亢音】出牌阶段限一次，先失去 1 点体力并弃置
  一名其他角色的一张手牌或装备牌；若弃置基本牌，可令 1 至已损失体力名角色各摸一张牌；否则
  本回合按已损失体力增加进攻距离和【杀】额外目标数。
- 本批闭合 `wdb_tianyu`（田豫，4 体力，魏）：【车阵】在无装备时防御距离 +1、有任意数量装备时
  进攻距离固定 +1；【诱战】可在距田豫不大于 1 的角色成为【杀】目标时弃置一张装备牌，使其
  视为使用【诱敌深入】。该锦囊可被【无懈可击】抵消；生效后取消原【杀】，迫使原使用者无距离、
  无次数限制地反复对受保护角色使用【杀】，直至造成伤害，若拒绝或无【杀】则受到该角色 1 点伤害。
- 本批闭合 `wdb_xizhenxihong`（习珍习宏，4 体力，蜀）：【负仇】可在成为【杀】目标时交给来源
  一张手牌或装备牌、取消该目标并去重记录来源；每个回合结束后按首次记录顺序逐一跳过死亡来源，
  先摸一张牌，再无距离限制地选择是否对该来源使用【杀】，不能或拒绝则失去 1 点体力。【噤言】
  在体力不大于 2 时禁止黑色锦囊按原牌使用或响应，仅允许从手牌经本技能视为【杀】使用或打出。
  旧技能描述中的“本回合到来源距离视为 1”没有对应可执行 JavaScript，故不写入规则。
- 本批闭合 `wdb_yangyi`（杨仪，3 体力，蜀）：【筹度】出牌阶段限一次，弃置一张手牌或装备牌，
  令所选角色使用一张虚拟【调兵遣将】；【立断】可在其他角色于其回合外恰好获得一张可使用的
  装备牌到手牌后发动，该角色交给杨仪一张手牌，否则立即使用该装备。【调兵遣将】先令使用者摸
  一张牌，再亮出牌堆顶存活角色数一半（向上取整）的牌；每个目标独立经过【无懈可击】窗口后，
  可用一张手牌替换其中一张，最后使用者把至少一张余牌按所选顺序置于牌堆顶，其余弃置。
- 本批闭合 `wdb_zaozhirenjun`（枣祗任峻，3 体力，魏）：【粮策】每个出牌阶段限一次将一张
  手牌中的基本牌当【五谷丰登】使用，并可在其余牌进入弃牌堆后令任意存活角色获得仍在弃牌堆
  的全部余牌；【坚壁】成为非 `multitarget` 且目标不少于两人的锦囊目标时，可排除其中一个目标；
  【军屯】可反复重铸手牌区或装备区的一张装备牌。【五谷丰登】按原目标数亮牌、每个未排除目标
  独立经过标准【无懈可击】窗口并强制获得一张，余牌统一以可审计原因进入弃牌堆。
- 本批闭合【望梅止渴】：标准【无懈可击】窗口后，目标若并列最低体力且受伤则回复 1 点体力，
  随后重新计算并列最低手牌；满足时按本牌是否执行过回复摸一或两张牌。
- 旧 JavaScript 只作语义证据，不进入 npack 或运行时；原始 GPL v3 许可证、九名武将立绘、
  三张卡图及【望梅止渴】音频随包保留。

```bash
cargo run -q -p content-cli -- pack \
  content/original/ported/wandianlunsha/*.skill \
  --characters content/original/ported/wandianlunsha/characters.json \
  --cards content/original/ported/wandianlunsha/cards.json \
  --metadata content/original/ported/wandianlunsha/metadata.json \
  --assets content/original/ported/wandianlunsha/assets \
  --out content/original/ported/wandianlunsha/wandianlunsha.npack.json \
  --package-id wandianlunsha
```
