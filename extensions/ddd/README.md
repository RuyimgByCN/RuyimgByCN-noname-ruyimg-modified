# 3D精选归档扩展迁移

- 来源：`archive/upstream/noname/apps/core/extension/3D精选`。
- 该扩展并非单纯皮肤包：它注册 `ddd` 武将包，含 31 名武将及对应技能；按武将闭包逐批重写。
- 本批闭合 `ddd_handang`（韩当，4 体力，吴）与【险袭】：出牌阶段使用【杀】时，可无视距离
  追加任意个仍满足其他目标规则的角色；只追踪本次新增目标。该【杀】完整结算后，统计其中未被
  此【杀】伤害的目标数 X，韩当可弃置 X 张手牌/装备牌并依座次对这些目标各造成 1 点伤害；
  取消或牌数不足则摸 X 张牌并失去 1 点体力。
- 第二批闭合 `ddd_zhouchu`（周处，5 体力，吴）与锁定技【侠横】：出牌阶段开始时强制选择
  一名角色弃置至多两张手牌/装备牌，再强制选择一名角色造成 1 点伤害；两名角色均非自己时
  减 1 点体力上限，为同一角色时失去技能；累计对三名不同角色执行伤害后永久删除两项惩罚。
- 第三批闭合 `ddd_liuchong`（刘宠，4 体力，群）与【精彀/末焱】：武器牌结算后攻击范围
  并列全场最大时强制选择一名其他角色造成 1 点伤害；每轮开始可公开牌堆顶三张，令选定角色
  获得至少一张并弃置余牌，本轮刘宠受伤时，若该角色手牌数不大于所获牌数，则伤害加 1。
- 第四批闭合 `ddd_luoxian`（罗宪，4 体力，蜀）与【示烈】：每回合限一次，需要使用【杀】
  或【闪】时，可明置任意张此前未公开且点数和不小于双方当前体力之和的手牌；这些牌保留在
  手牌并持续公开，以无实体来源的对应基本牌继续结算，点数和精确相等时摸等量牌。
- 第五批闭合 `ddd_dingfeng`（丁奉，4 体力，吴）与【短兵】：出牌阶段可将一张黑色非锦囊
  手牌/装备牌直接作为【兵粮寸断】置入自己的判定区，摸两张牌，再可使用一张计入通常次数但
  无视距离的虚拟【杀】；其后以牌造成伤害时，可把判定区内的【兵粮寸断】移至受伤角色的判定区。
  上游译文把后一条件写作“使用【杀】造成伤害”，但可执行旧 JS 只检查牌伤害，本迁移按代码语义。
- 第六批闭合 `ddd_wuzhi`（吴质，3 体力，魏）与【灵涌/虚孝】：任意角色跳过阶段后可循环
  判定，结果不为【杀】时可使用判定实体牌并选择继续；黑色基本牌因弃置进入弃牌堆后，可逐张
  直接作为【兵粮寸断】置入任意合法角色判定区，并令该角色摸两张牌。
- 第七批闭合 `ddd_xujing`（许靖，3 体力，蜀）与【虚誉/实荐】：使用牌结算后可摸一张，随后
  本回合下一张牌结算后强制弃置一张手牌/装备牌；其他角色出牌阶段第二张牌结算后，可交给其
  一张手牌/装备牌，并在其下一张有目标牌指定首个目标时选择令该牌额外结算一次或自己摸一张。
- 第八批闭合 `ddd_caomao`（曹髦，3 体力，魏，主公）与【太思/驱车/潜龙】：回合结束时可把
  本回合仍留在弃牌堆的一张牌交给任意角色，若其本回合伤害过曹髦则曹髦摸两张；限定技依次
  赠红牌、将黑牌当不计次数的【杀】，每个动作令本回合距离 -1，至多执行体力上限轮；击杀后
  摸三张。当前身份模式没有额外的击杀奖惩摸牌/弃牌流程，故【潜龙】的奖惩取消条款无可取消事件。
- 第九批闭合 `ddd_xinxianying`（辛宪英，3 体力，魏）与【洞察/智解】：其他角色回合开始时，
  双方依次将一张手牌置为辛宪英的“鉴”；该回合结束时辛宪英与回合角色依次获得一张“鉴”。
  两张同色“鉴”可响应为【闪】，两张异色“鉴”可响应为【无懈可击】，响应后摸两张牌。
- 第十批闭合 `ddd_xianglang`（向朗，3 体力，蜀）与【恰化/恂恂/腹笥/拓籍】：其他角色
  回合开始时可明置其体力值张手牌并令其本回合获得观顶四张、二顶二底的【恂恂】；明置手牌
  不计手牌上限，其他角色可声明其实际牌名并在向朗逐次确认后直接使用或打出该实体牌；向朗
  回合内手牌全部明置时，其他角色只能继续使用非自身手牌来源；借牌结算后若仍全部明置，
  向朗可摸三张牌。牌主可单次同意/拒绝，或记住至本回合结束。
- 第十一批闭合 `ddd_yujin`（于禁，4 体力，魏）与【整军】：仅在于禁自己的出牌阶段内，
  某角色的体力、手牌数或装备数发生变化且变化后与于禁对应数值相等时，三类各可发动一次；
  分别令该角色回复或失去 1 点体力、摸一张或由其弃置一张手牌/装备牌、将其一张装备牌
  移至任意合法角色的同类区域。同一批移牌同时改变手牌与装备时，两类机会均可依次处理。
- 第十二批闭合 `ddd_liuye`（刘晔，3 体力，魏）与【察势/齐策】：其他角色出牌阶段开始时，
  刘晔可弃置一张手牌/装备牌；该阶段内其后来使用的首张花色或类别相同的牌会令双方各摸一张，
  命中或阶段结束后清除记录。准备阶段可摸两张并锁定【齐策】，直至自己使用任意锦囊牌后解锁。
  旧译文称“下一张牌结算结束后”检查，但可执行旧 JS 实际监听阶段内首张匹配牌的使用时点，
  本迁移按代码语义。
- 第十三批闭合 `ddd_baosanniang`（鲍三娘，3 体力，蜀）与【枝连/赍剑】：一名角色回合结束时，
  若本回合恰好只有鲍三娘与另一名仍存活男性角色使用或打出过牌，可令双方各摸一张或各弃一张，
  然后获得本回合进入且仍在弃牌堆的全部【杀】；出牌阶段限一次展示并交给其他男性角色一张
  手牌【杀】，由其展示一至两张同色【杀】或普通锦囊，双方依座次各虚拟使用一个未重复牌名。
- 第十四批闭合 `ddd_zhenji`（甄宓，3 体力，魏）与【淼形/浮世】：起始手牌数变为三倍，
  开局按顺序等分三组、保留一组并将另两组暗置为两组“水相”；摸牌阶段后可令选中的不等量
  水相补至或弃至当前手牌数。每回合限一次，使用或打出基本牌结算后可用全部手牌交换一组
  水相，再可令一名男性角色选择是否用其全部手牌交换任一组水相。
- 第十五批闭合 `ddd_zhaoang`（赵昂，4 体力，魏）与【奋计】：自己的摸牌/弃牌阶段开始时，
  可选择一个本局未以此法使用过、当前存在合法使用方式的普通锦囊牌并完整虚拟使用。摸牌阶段
  的通常摸牌改为该次锦囊结算实际造成的伤害总量；弃牌阶段的通常弃牌改为该牌声明目标数，
  可弃牌不足时弃置全部手牌/装备牌。牌名使用记录在技能实例存续期间永久保留。
- 第十六批闭合 `ddd_liuba`（刘巴，3 体力，蜀）与【丰政/玉律】：每名角色每个出牌阶段
  限一次将点数和恰为 13 的任意张手牌作为完整【无中生有】使用；每轮首次实际阶段开始时，
  刘巴可按上一轮不同使用者人数观看并分配等量牌堆顶牌，全部选择完成后统一获得，任一角色
  获得超过两张则刘巴失去【丰政】。开局摸一张并将一张手牌置为公开“玉律”；任意一批牌进入
  弃牌堆且含相同物理点数时，令当前回合角色摸一张或弃一张，本回合第二次发动后用手牌交换
  “玉律”，没有手牌则先摸一张。
- 第十七批闭合 `ddd_jianshuo`（蹇硕，4 体力，群）与【分野/逝潮】：出牌阶段限一次与
  一名其他角色发起拼点，其余角色依座次可加入任一方并各扣置一张手牌；统一公开并弃置全部
  实体拼点牌，以两方点数均值严格判胜，胜方依座次各可对一名不同且当前合法的败方角色使用
  一张无距离、无次数限制的虚拟【杀】。准备阶段按逝潮标记选择全场第 N 大手牌数角色；不足
  N 个不同档位时取最少档，将手牌调整至该角色手牌数且不超过存活主公体力上限。该目标在
  蹇硕下次准备阶段前对其造成伤害时可防止之并令 N 永久加一。
- 第十八批闭合 `ddd_guanning`（管宁，3 体力，群）与【游学/承经】：每轮首次阶段开始时
  建立并强制转交全场唯一“游学”标记，按旧持有者到新持有者的规则距离摸牌；标记持有者
  回合结束时，把其本回合最后一张非转化、单实体且仍在弃牌堆的基本牌或普通锦囊替换为
  管宁的公开“经”。出牌阶段限一次，可将一张手牌或装备牌按“经”的牌名与属性完整使用，
  结算后若该素材仍在弃牌堆，可交给当前“游学”持有者的下一名存活角色。
- 第十九批闭合 `ddd_caoshuang`（曹爽，5 体力，魏）与【专摄/危秋】：其他角色出牌阶段
  开始时可正面交给其一张手牌并记录牌名；其本回合使用同名基本牌或普通锦囊时，可无视距离
  为该牌增加一个合法目标，回合结束时若仍有记录牌名未被使用，可对其造成 1 点伤害。任意角色
  回复体力前，若曹爽没有手牌，则取消本次回复并令曹爽摸一张牌。
- 第二十批闭合 `ddd_xuelingyun`（薛灵芸，3 体力，魏）与【涟洏/暗织】：使用红色牌完整
  结算后可获得仍在弃牌堆的实体材料；仅有一张材料时，本回合只能使用、打出或用于救人的
  点数更小的牌。任意角色回合开始时，若全局上一张使用或打出的牌为黑色，可指定一名角色，
  该回合其首次成为黑色牌目标时从当前牌的目标中移除。
- 第二十一批闭合 `ddd_liuhong`（刘宏，4 体力，群，主公）与【失兴/党锢/覆宗】：根据场上
  是否存在未受伤女性与本回合是否已有锦囊牌使用，动态获得现有【享乐/酒诗/制衡】技能闭包；
  结束阶段横置任意名未连环角色直至连环人数不少于存活群势力人数，其他已连环角色的弃牌阶段
  将装备区计入手牌；开局按群势力人数摸牌，群势力角色死亡时由其强制弃置刘宏一张手牌或装备牌。
  本批同时修复依赖包【酒诗】：正面朝上时翻面并使用无实体牌【酒】，背面受伤后可选择翻回。
- 第二十二批闭合 `ddd_xiahouxuan`（夏侯玄，3 体力，魏）与【朗怀/玄论】：摸牌阶段可展示
  当前手牌，以阴/阳转换状态分别改摸现有花色数或缺少花色数并切换状态；受到伤害后可摸四张，
  当前回合结束时选择四张手牌/装备牌并任意排序、拆分置于牌堆顶底，或令该选项消失并强制发动
  下一次【朗怀】。强制状态只在【朗怀】实际发动后清除；已被强制但回合末无手牌时不结算置牌。
- 第二十三批闭合 `ddd_zhangkai`（张闿，初始 3/上限 4 体力，群）与【劫行/拜泪】：限定技
  【劫行】可取消其他角色的回复并改由张闿回复等量体力，或取消其他角色的装备牌使用并将仍在
  当前使用者手牌区或处理区且可装备的本次实体牌依次置入张闿装备区；本次截取回复不会立即重置技能，之后张闿正常
  回复体力或使用装备牌结算完毕才恢复【劫行】。【拜泪】可获得装备数唯一最多角色的一张手牌
  或装备牌，或对 1 体力角色造成 1 点伤害；若目标因此死亡，张闿失去【拜泪】。
- 第二十四批闭合 `ddd_liangxi`（梁习，4 体力，魏）与【仝御】：出牌阶段限一次，将一至四张
  花色各不相同的手牌当【五谷丰登】使用，并选择顺时针或逆时针结算；额外展示与实体材料数
  相同的牌。每名目标选择令此牌对其无效，或本回合不能使用、打出手牌；结算后，梁习可令一名
  选择无效的存活角色获得全部仍在弃牌堆的剩余展示牌。
- 旧 JavaScript 只作语义证据，不进入 npack 或运行时；原始 GPL v3 许可证及武将立绘随包保留。

```bash
cargo run -q -p content-cli -- pack \
  content/original/ported/ddd/*.skill \
  --characters content/original/ported/ddd/characters.json \
  --metadata content/original/ported/ddd/metadata.json \
  --assets content/original/ported/ddd/assets \
  --out content/original/ported/ddd/ddd.npack.json \
  --package-id ddd
```
