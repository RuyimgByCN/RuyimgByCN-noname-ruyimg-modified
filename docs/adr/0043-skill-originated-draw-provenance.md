# ADR 0043：技能摸牌效果来源与防递归触发

- 状态：已接受
- Engine semantics：27

## 背景

「展骥」会在拥有者出牌阶段因其他效果摸牌后再摸一张，但自身追加的摸牌不能再次触发。只有 `CardsDrawn` 的玩家和牌列表无法区分原始摸牌与技能自身摸牌，依赖触发次数上限会错误压缩同一结算段内的多次独立摸牌。

## 决策

- VM 发出的摸牌效果在进入权威调度器时附带技能实例来源；普通系统摸牌保持无来源；
- 来源只随待执行效果传播，事件格式和旧包不变；
- 调度某个效果产生的事件时临时暴露来源技能，稳定状态、快照与状态哈希不保留该瞬时值；
- 新增通用过滤器 `owner_draws_during_own_play_not_self`，同时校验拥有者、当前回合、出牌阶段和来源技能实例。

## 结果

「展骥」可对同一结算段内的多次外部摸牌逐次触发，又不会自递归；后续需要排除自身效果的摸牌触发器可复用同一来源机制。
