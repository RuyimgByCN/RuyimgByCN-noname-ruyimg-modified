# ADR 0727：N06 重放/恢复逐命令事件对照

日期：2026-09-16
状态：已实施（engine-native）
关联：[0723](0723-native-n06-distance-differential-reward-ordering.md)、[0726](0726-native-n05-negative-hp-rescue-rounds.md)、进度文档 N06

## 背景与决定

进度文档 N06 剩余项：「重放/恢复逐命令事件对照」——既有恢复矩阵只覆盖选择点
（挂起窗口），缺少对**任意确定性命令脚本**的三线逐命令对照：同脚本从零重放、
半程快照恢复后续跑，与基准线在每条命令后比对状态哈希与完整日志事件序列。

### 设计（`replay_and_restore_per_command_parity`）

- **脚本策略**（`next_script_command`）：开放选择按策略应答（无懈 Pass、濒死/改判
  出牌、天妒 Confirm、弃牌按 min、其余首选项）；出牌阶段仅在本回合未出杀且
  距离可达时出杀（策略级避免拒绝，脚本无拒绝命令）；否则推进阶段。
- **基准线**：seed 307 原型局收集 60 条命令（断言 ≥40），逐命令记录
  （state_hash, 全量日志克隆）。
- **重放线**：同 seed 从零重跑同一命令序列，逐命令断言哈希与完整日志一致——
  证明引擎行为只由 (初始状态, 命令序列) 决定，无隐藏非确定性。
- **恢复线**：半程 save→restore（恢复件日志为空）后续跑剩余命令，逐命令断言
  哈希与基准一致、事件**增量**与基准自挂起点之后的切片一致，终态哈希一致。

### 意义

- 逐命令粒度强于 golden（只验终态）与恢复矩阵（只验选择点）：任何一条命令后
  的事件顺序/内容漂移立即失败。
- 重放线独立验证确定性契约（ADR 0707 事件栈语义的可重放承诺）；
  恢复线独立验证「恢复件与原实例继续等价」在任意中间点成立，而非仅挂起点。

## 影响

- 测试 143 项（native_kernel 82、boundary_snapshot 56、场景 2、源码 2、调试 1），净增 1。
- 规则版本不变（7）；golden 不变。
- N06 剩余：多牌稳定顺序扩展、旧线等价负载对照（N12，需旧线可运行）。
