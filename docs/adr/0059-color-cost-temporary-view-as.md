# ADR 0059：按弃牌颜色授予临时转化技

- Engine semantics：43

旧版技能可在阶段开始时选择弃置一张手牌，并按其有效颜色临时获得固定颜色的 view-as 能力。该行为由动态选择成本、阶段生命周期和现有 view-as 规则共同组成，不需要旧 JS 运行时或技能 ID 分支。

引擎增加两个通用 effect：`choose_discard_hand_add_skill_by_color` 以可取消选择弃置一张可弃置手牌，再按有效颜色添加指定技能定义；`remove_skill_by_def` 移除玩家身上同定义的全部实例。内容包用两个固定颜色临时技能表达转换规则，利用新实例的 `use_count` 精确实现每个出牌阶段独立计数，并在阶段结束时移除。

`nsduijue` 因此完全由 DSL 组合：弃红授予黑牌当【决斗】、弃黑授予红牌当【决斗】，每阶段各限两次。
