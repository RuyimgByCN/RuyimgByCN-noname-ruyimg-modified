# ADR 0116：回合外失去最后手牌的每回合限次过滤器

## 背景

SP「守成」与 HUICUI 蒋琬费祎「守成」都监听一名非当前回合角色失去手牌后变为空手。
前者每次可摸一张，后者每回合限一次且可摸两张。复用无次数限制的过滤器会放宽后者语义，
修改原过滤器则会错误限制前者。

## 决策

新增 `owner_alive_event_player_outside_turn_from_hand_empty_once`。它沿用既有过滤条件：技能拥有者
存活、事件角色存活且不是当前回合角色、事件确实从手牌区移出至少一张牌，并在事件后没有手牌；
同时使用 `SkillInstance.turn_fire_count` 限制每个角色回合最多发动一次。计数只由真正的回合推进
重置，底层 `SetTurnState` 不伪造回合边界。

旧 JavaScript 的身份暴露与 AI 子技能属于客户端策略，不进入权威规则。当前引擎每个
`CardsMoved` 事件只绑定一个来源区域；多来源移动按确定的事件顺序逐个结算，第一次实际发动会
消耗该回合次数。

HUICUI 包显式依赖 SHIJI 包并复用 `reshengxi` 的稳定技能 ID，由两个重写技能闭合蒋琬费祎。

## 版本

该能力要求 Rule VM ABI 26、Rule IR 37、引擎语义修订 112。ABI 26 主机继续按加法兼容规则
加载 ABI 3–25 内容包。
