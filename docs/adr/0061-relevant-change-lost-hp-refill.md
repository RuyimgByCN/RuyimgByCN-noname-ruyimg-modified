# ADR 0061：相关状态变化后的损失体力补牌过滤

- 状态：Accepted
- Engine semantics：45

## 决策

新增 `owner_hand_below_lost_hp_after_relevant_change` 过滤器。它只在以下事件中成立：拥有者的伤害、失去体力、回复体力或体力上限变化；或牌移动触及拥有者的手牌区、装备区、判定区。事件结算后的手牌数还必须小于当前已损失体力值。

补牌数量继续使用普通 DSL 查询表达式 `max_hp(self) - hp(self) - hand_count(self)`，不新增技能专用效果或状态。

## 结果

`shangshi` 可以覆盖旧实现监听的个人得失牌与体力状态变化，同时不会因其他角色无关的牌移动重复询问。每个触发仍是独立的可选续体，选择后按最新状态计算补牌数。
