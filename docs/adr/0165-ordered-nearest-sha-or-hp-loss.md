# ADR 0165：按座次逐人对最近目标出杀，否则失去体力

## 决策

Rule VM ABI 90 增加通用 effect `force_others_use_sha_on_nearest_or_lose_hp(player)`。它在激活时按
座次顺时针快照除拥有者外的存活角色，随后逐人结算：参与者可选择一张当前合法的实体【杀】或
出牌阶段转化【杀】，并只能选择与其最终距离并列最小、同时满足普通【杀】目标与距离规则的角色；
取消、无合法来源或无合法最近目标时失去一点体力。

队列、来源牌选择和目标选择均使用可序列化 continuation。参与者使用的【杀】不计入普通出杀次数，
但完整经过目标校验、响应、伤害、触发与濒死流程；这些流程结束后再恢复下一名快照角色。已经死亡的
后续角色会跳过，激活后不因技能拥有者死亡或失去技能而中断已建立的队列。

## 原因

旧「乱武」不是一次性群体伤害：每名角色都拥有独立的来源牌和最近目标选择，且一名角色的【杀】
可能产生响应、触发和濒死屏障。若在技能专用代码中用同步循环处理，会越过 Choice 屏障并破坏录像、
重连和状态哈希；若只允许实体【杀】，又会漏掉旧实现接受的 `viewAs` 来源。

## 结果

- 「乱武」本身只保留一次性主动技声明，不在引擎中按武将或技能 ID 分支。
- 相同的“顺序强制用牌，否则付出代价”技能可继续复用 typed effect 与 continuation 模式。
- Golden 覆盖座次顺序、最近目标、取消、转化【杀】、不消耗普通次数以及濒死后恢复队列。
- 贾诩须在通用多人濒死救援队列完成后发布；该依赖已由 ADR 0166 明确并实现，不能以仅由濒死者
  自救的旧简化流程伪装完成。
