# ADR 0096：按来源角色记录本回合【杀】伤害事件

## 决策

在既有确定性回合 flags 中增加按玩家编号分区的【杀】伤害事件计数，并增加查询值 `owner_sha_damage_dealt_zero_this_turn`。实际非失去体力伤害提交后，若伤害携带逻辑【杀】牌种，则为来源角色递增一次；切换回合时与其他按玩家回合计数统一清零。

## 原因

旧版 `stdduanbing` 在伤害生效前查询来源角色本回合的 `sourceDamage` 历史，只有当前【杀】伤害之前不存在同类记录时才令伤害加一。计数必须在伤害提交后递增，才能让当前首段伤害命中条件；按来源角色分区后，其他角色先造成【杀】伤害不会消耗技能拥有者的首次机会。

## 兼容性

新 modifier 值追加在枚举末尾，既有序列化序号稳定。Rule IR 与技能 VM ABI 不变；引擎语义修订号递增到 81，未使用新值的内容包行为不变。
