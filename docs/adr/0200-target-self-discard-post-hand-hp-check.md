# ADR 0200：目标自行弃牌后的手牌/体力后置检查

## 状态

已接受。

## 背景

SIXIANG「秉正」在拥有者的结束阶段可选择一名能够自行弃置手牌或装备牌的角色。目标自己选择并
弃置一张牌；该异步弃置及其嵌套触发全部结束后，若目标手牌数不等于体力值，技能拥有者失去一点
体力。旧 JavaScript 通过 `chooseTarget`、目标的 `chooseToDiscard` 和两个连续 `await` 表达，
不能直接进入确定性运行时。

现有单步弃牌原语不能表达两个不同观察者的连续 Choice，也不能保证手牌/体力比较发生在卡牌移动
触发链之后。

## 决策

ABI 127 追加触发过滤器
`owner_is_target_any_alive_self_discardable_hand_equip`，只在拥有者为当前事件角色且场上至少一名
存活角色能够自行弃置手牌或装备牌时提供可选发动窗口。

新增通用效果
`choose_target_self_discard_then_owner_lose_hp_if_hand_ne_hp(player)`：

- 第一阶段由技能拥有者强制选择一名当前仍可自行弃牌的存活角色；
- 第二阶段由目标本人强制选择并弃置自己的一张合法手牌或装备牌；
- 牌的所有权、区域、弃置保护、观察者、目标存活和技能实例在每个 Choice 屏障恢复时重新验证；
- 后置检查进入 `deferred_tail_effects`，等待移动及其嵌套触发结束后重新读取目标手牌与体力；
- 两者不相等且拥有者仍存活时，以标准体力流失管线令拥有者失去一点体力。

该效果使用 HOST_EFFECT 141、continuation 96 和 `EffectRequest` 哈希标签 178。

## 后果

- 目标选择和目标自行选牌是两种不同观察者的权威 Choice，可回放且不会泄露隐藏牌。
- 后置比较能观察到弃牌触发造成的摸牌、体力或死亡变化。
- 旧 JavaScript 仅作语义证据，不进入 npack 或运行时；后续同类技能可直接复用该 DSL 原语。
