# ADR 0044：用牌后的手牌类别与目标数过滤契约

- 状态：已接受
- Engine semantics：28

## 背景

「图射」在拥有者使用有目标的非装备牌后检查其当前手牌：没有基本牌时可摸等同完整目标数的牌。旧实现挂在逐目标事件上，需要额外判断只处理第一个目标；新引擎的 `CardUsed` 已按整次用牌只发出一次。

## 决策

- 新增通用过滤器 `owner_source_non_equip_no_basic_hand_has_targets`；
- 使用事件中的逻辑牌类别排除装备牌，使用拥有者当前手牌的有效牌类别检查基本牌；
- 使用既有 `event_target_count` 传递完整目标数，不新增事件或效果类型；
- 触发保持可选，由统一的可选触发选择流程处理。

## 结果

多目标用牌只触发一次并按完整目标数摸牌；后续需要组合“用牌者、牌类别、手牌类别、是否有目标”的技能可复用同一权威过滤契约。
