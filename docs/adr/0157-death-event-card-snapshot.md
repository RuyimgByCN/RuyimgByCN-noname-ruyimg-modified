# ADR 0157：死亡事件携带清理前的手牌与装备快照

## 决策

ABI 82 为 `PlayerKilled` 追加 `hand_equip_cards`，记录死亡清理前由死者持有的手牌和装备。死亡清理仍立即把手牌、装备和判定牌移入弃牌堆；触发上下文只公开手牌与装备快照，不包含判定区。

DSL 新增过滤器 `owner_alive_event_cards_nonempty` 和效果 `gain_event_cards(player)`。效果只移动事件快照中执行时仍位于弃牌堆的牌，因此多个触发按座次处理时不会复制或重复获得同一张牌。

## 原因

旧版 `xingshang` 在 `die` 时读取死者的 `he` 区。现有引擎在发出死亡事件前已经完成清理，若仅按死亡后的区域查询会错误地得到空集合。通用事件快照保留了旧语义需要的事实，同时避免为技能 ID 增加宿主分支。

## 结果

- 旧 JavaScript 仍只作为语义规格，不在运行时加载。
- 其他需要处理死亡前手牌或装备的技能可复用同一事件卡牌通道。
- `gain_event_cards` 在执行时重新校验弃牌堆位置；已被更早效果移动的牌自动忽略。
