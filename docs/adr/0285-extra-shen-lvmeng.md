# ADR 0285：EXTRA 神吕蒙与实体牌选择

## 决定

旧 JavaScript 只作为语义合同，神吕蒙的 `shelie`、`gongxin` 重写为 DSL 和类型化效果：

- 涉猎复用权威摸牌替换标志，将牌堆顶至多五张移入处理区并公开；选择续体要求每种当前
  有效花色恰好一张，选择牌进入手牌，其余进入弃牌堆。
- 攻心复用主动技单回合次数与目标手牌非空约束；目标全部手牌只向技能拥有者展示，
  可取消红桃选择。选中的红桃随后必须选择弃置，或公开并移动到牌堆顶。
- 所有选择恢复时重新验证实体牌仍在原区域、花色和所有权未变化。

## 兼容性

HOST_EFFECT、`EffectRequest`、续体和稳定哈希标签只在尾部追加。
Rule VM ABI 为 209，Rule IR 为 95，Engine semantics revision 为 183；
内容 schema、包格式、网络、回放与快照 schema 不变。
