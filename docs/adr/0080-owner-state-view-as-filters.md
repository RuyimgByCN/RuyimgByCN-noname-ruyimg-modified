# ADR 0080：视为技拥有者状态组合过滤器

## 决策

新增两个通用视为牌过滤器：`owner_single_red_hand` 仅在实体牌为红色且拥有者手牌中恰好只有一张有效红牌时匹配；`owner_hand_gt_hp` 仅在拥有者手牌数大于当前体力值时匹配。二者继续与既有来源区域、有效花色、主动使用和响应管线组合。

ONLYOL「竭勇」据此把最后一张红色手牌当【杀】使用或打出；SP「严整」据此把装备区牌当【无懈可击】使用。旧 JavaScript 只作语义证据，不进入包或运行时。

## 原因

两项条件都是可复用的拥有者公开状态约束。将它们放进声明式过滤器可避免技能 ID 特判，并让出牌、普通响应、AI/合法动作查询与实体牌消耗共享同一判断。

## 兼容性

两个过滤器沿用加法兼容的 Rule VM ABI 5，内容 Schema 保持 3；Rule IR 版本升至 8，引擎语义修订号升至 65。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
