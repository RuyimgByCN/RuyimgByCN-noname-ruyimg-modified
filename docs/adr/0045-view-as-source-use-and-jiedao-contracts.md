# ADR 0045：视为技来源、次数与【借刀杀人】契约

- 状态：已接受
- Engine semantics：29

## 背景

「谋逞」在出牌阶段每回合限一次，可将一张黑色手牌或装备牌当【借刀杀人】使用。既有 `view_as` 已能声明来源区域，但主动发动路径只接受手牌，也没有权威次数限制；编译器也尚未开放已有的【借刀杀人】玩法入口。

## 决策

- `view_as` 新增可选 `uses_per_turn N`，复用 `SkillInstance.use_count` 与回合开始重置机制；
- 主动发动统一使用既有来源区域查询，装备牌在同一事务内先移入手牌，再交给已有用牌流程消耗；失败时事务整体回滚；
- `jiedao` 映射到既有 `TrickJiedao`，继续复用其双目标、武器、无懈与后续选择流程；
- 新字段进入 npack 逻辑哈希，缺省字段保持旧包兼容；不增加技能名分支。

## 结果

扩展只需声明 `view_as jiedao play_phase black from hand_equip uses_per_turn 1;` 即可获得服务器权威校验。后续同类视为技可复用相同契约，无需修改引擎。
