## 决策

旧 JavaScript 只作语义合同，不进入内容包或运行时。XIANDING 傅干按上游元数据发布为群势力、
3 体力，技能为【巧谏】与【析察】。

【巧谏】在每个出牌阶段对每名其他角色限一次。双方依次秘密选择任意张手牌或装备牌，待两边选择
都完成后才同时弃置并比较实体牌点数和；拥有者较大时回复 1 点体力，并令目标下回合获得“首张
【杀】及首张普通锦囊可各额外结算一次”或“不能使用伤害牌”之一。多个傅干对同一目标的策略按
位合并，可同时生效。拥有者点数和不大于目标时，获得双方仍在弃牌堆的牌；这些实体牌不计入手牌
上限，也不会进入弃牌阶段的超限弃牌选择，离开手牌后自动解除追踪。

【析察】在每受到一点伤害后均可独立发动：查看来源手牌并秘密选择至多两张（手牌不足两张时全选）。
同一来源的多次标记合并；该来源下一次使用牌时必定消费监听。若本次使用的任一实体材料被标记，
则取消整张牌的后续效果，并由傅干获得该次使用的全部实体材料；未命中时只消费监听。

ABI 586 新增 `resolve_qiaojian`、`resolve_xicha` 两段结算状态机及四个精确触发过滤器。装备牌的
`CardUsed` 替换窗口统一移到装备移动之前，同时保留实体装备转化牌作为其他逻辑牌使用时的原有
弃置语义；手牌上限修正器复用技能实例已有实体牌追踪，不增加第二套牌标签系统。
