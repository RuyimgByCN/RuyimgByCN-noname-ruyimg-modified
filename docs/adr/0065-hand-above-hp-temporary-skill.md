# ADR 0065：严格手牌体力触发与临时技能生命周期

- 状态：已采纳
- 日期：2026-07-15

## 背景

旧版 `refresh:rezongshi` 在准备阶段检查拥有者手牌数是否严格大于当前体力，满足时
通过 `addTempSkill` 获得本回合【杀】无次数限制。现有 DSL 已有手牌上限、增加技能和
移除技能原语，但缺少这项严格比较过滤器，已有子技能也没有表达临时生命周期。

## 决策

1. 增加通用触发过滤器 `owner_is_target_hand_above_hp`，仅在存活拥有者是事件角色且
   手牌数严格大于非负当前体力时成立。
2. `rezongshi` 复用 `alive_group_count` 手牌上限值源，并在准备阶段授予子技能。
3. `rezongshi_paoxiao` 复用 `sha_use_limit`，在拥有者的 `turn_ended` 事件中移除自身，
   精确对应旧版 `addTempSkill` 的默认持续时间。
4. 不加入技能 ID 特判。

## 结果

同一过滤器和临时技能生命周期可复用于后续迁移。触发判定语义增加，因此引擎语义
修订号升至 49。
