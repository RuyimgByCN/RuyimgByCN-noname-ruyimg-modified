# ADR 0164：逐目标【杀】响应数与非最低体力过滤器

## 决策

Rule VM ABI 89 增加通用 modifier `sha_response_count_if_other_female`。它只在技能拥有者是当前
【杀】的使用者且当前目标为女性/双性角色，或技能拥有者是当前目标且使用者为女性/双性角色时生效。
单目标与多目标【杀】共用 `sha_response_count_for`；多目标队列在进入每个目标前重新计算需求，不能把
第一个目标的响应数缓存给后续目标。

ABI 89 同时增加触发过滤器 `owner_is_target_not_min_hp`：拥有者必须存活、是事件角色，且当前体力值
不是所有存活角色中的并列最低值。并列最低不触发。

两项能力均以追加枚举值和追加 ABI 映射发布，不改变旧包已有序列化编号。旧 JavaScript 只作为语义
证据；运行时只加载编译后的规则索引和 npack。

## 原因

旧「肉林」同时监听用【杀】和成为【杀】目标，并按每一个目标的性别决定额外【闪】数。把结果只在
整张牌开始时计算会错误处理“女性目标后接男性目标”的多目标【杀】。旧「崩坏」使用 `isMinHp()`，
其语义包含并列最低，因此不能用唯一最低或固定阈值替代。

## 结果

- 「肉林」由声明式 modifier 表达，不增加武将或技能 ID 的 Rust 分支。
- 所有【杀】响应入口共享同一查询，后续相同的参与者条件可以继续作为通用 modifier 扩展。
- Golden 必须覆盖双向性、女性/双性边界、男性不生效，以及多目标逐目标重算。
- 「崩坏」的两个强制分支继续使用现有 `choose`、失去体力和体力上限效果；新能力只负责触发边界。
