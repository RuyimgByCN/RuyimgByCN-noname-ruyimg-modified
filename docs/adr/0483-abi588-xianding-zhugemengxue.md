## 决策

旧 JavaScript 只作语义合同，不进入内容包或运行时。XIANDING 诸葛梦雪按上游元数据发布为魏势力、
女性、3 体力，技能为【寄春】与【寒英】。

【寄春】在出牌阶段选择一张手牌或装备牌，再选择一名手牌数与自己不同的角色。目标手牌较少时，
展示并交给其该牌，随后自己摸该牌本地化名字数张牌；目标手牌较多时，展示并弃置该牌，随后弃置
目标区域内一至该名字数张可弃牌。两个分支在每个出牌阶段各限一次，普通主动技次数仍复用引擎
已有的逐出牌阶段计数，不新增计数框架。

【寒英】在准备阶段展示牌堆顶侧首张类型为装备且不带 `gifts` 标签的牌；若存在与拥有者手牌数
相同且可使用该装备的存活角色，拥有者必须选择一名，由该角色直接使用。装备沿普通 `UseCard`、
同栏替换和装备事件管线从牌堆进入装备区，不伪造手牌获得/失去事件。

ABI 588 为包卡牌规则元数据增加缺省兼容的 `name_length` 与 `gift` 字段；缺省值不改变历史内容包
逻辑哈希。标准牌名字数由权威内建映射提供，扩展牌由 npack 元数据提供。共享区域实体牌使用通过
既有物理来源计划传入普通用牌管线，全部新增效果参数进入确定性状态哈希。
