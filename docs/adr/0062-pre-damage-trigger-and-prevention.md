# ADR 0062：伤害生效前触发与防止

- 状态：已接受
- Engine semantics：46

## 决策

伤害先经过现有静态修正，得到确定的伤害值，再分发 `damage_before`。触发技能可通过 `prevent_current_damage()` 防止这一次伤害；可选触发、技能效果及其派生触发全部结束后，调度器才提交或丢弃原伤害。

伤害实例使用引擎分配的临时编号绑定，禁止按技能 ID 分支。属性连环伤害重新进入同一调度路径，因此每个目标都能独立触发伤害前技能。

## 原因

旧版 `damageBefore` 发生在扣减体力之前，不能用现有的伤害后事件近似。把待提交伤害保存在确定性的效果队列中，可跨可选确认和快照恢复，同时为后续同类技能提供公共时机。
