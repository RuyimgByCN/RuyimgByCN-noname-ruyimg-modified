# 0467 ABI 570 兵势于吉【道转/符济】

日期：2026-08-03  
状态：已落地  
领取者：B（Codex overflow）

## 决策

旧 JavaScript 只作为语义合同，不进入内容包或运行时。新增 ABI 570 的
`resolve_potyuji(player, target, card, action)`，复用现有无实体牌虚拟基本牌、权威实体牌
选择、展示/赠予、持久牌标签、按花色检索、当前伤害修改和当前【杀】基础伤害管线。

## 语义

- 道转：每回合限一次声明任意合法基本牌；弃置自己或当前回合角色的一张手牌/装备牌作为
  成本。每轮每种牌名限一次，普通/火/雷【杀】按同一牌名记录；若成本来自当前回合角色，
  本轮禁用。声明、成本选择和继续用牌/响应均经过可恢复 Choice，恢复时重新验证实体牌。
- 符济：出牌阶段限一次，展示自己的任意张手牌/装备牌，并按选择顺序一一交给等量不同的
  其他角色；实体牌保留“符济”标签，获得者得到对应结算技能；标签在该牌首次用牌完整结算
  后消费，符合旧 `gaintag` 离区即移除、失牌历史仍供本次结算读取的生命周期。
- 使用任意包含“符济”实体来源的牌时，每张来源牌分别按原始花色从牌堆取得一张牌；逻辑牌
  为【杀】时每次伤害 +1，为【闪】时完整结算后摸一张。复合牌只要有任意带标签来源即生效。
- 赠牌后若于吉手牌数为全场最少，摸两张并获得下一张【杀】和下一张【闪】强化；强化可与
  标签效果叠加，分别在对应牌结算后移除，未消费部分在下个自己的回合开始时清理。
