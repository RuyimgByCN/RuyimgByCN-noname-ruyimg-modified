# ADR 0112：有来源伤害的逐点可获得牌触发

## 决策

新增触发过滤器 `owner_is_target_source_alive_gainable_card_per_damage_point`。它只在技能拥有者是受伤角色、伤害来源仍存活且来源存在可获得牌时通过，并按伤害点数生成相互独立的触发：伤害来源为其他角色时检查其手牌区和装备区；来源就是拥有者时只检查装备区。

过滤器只负责唤醒与重复次数，实际选牌仍使用通用 `take_one_card` 效果，并在选择恢复时重新校验来源、接收者和合法区域。这样反馈类技能不需要技能专用 Rust 分支，也不会在来源无牌时产生空确认。

## 版本与兼容

该能力要求 Rule VM ABI 22、Rule IR 33、引擎语义修订 108。ABI 22 主机继续按加法兼容规则加载 ABI 3–21 包；内容 Schema、网络协议、回放 Schema 与快照 Schema 均不变。新增 `TriggerFilter` 枚举项追加在末尾，保留既有序列化序号。
