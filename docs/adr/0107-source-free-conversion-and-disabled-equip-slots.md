# ADR 0107：无来源动态转换与装备栏废除

## 决策

`view_as_index` 增加包驱动的无来源动态牌族合同。扩展可声明 `basic` 或 `ordinary_trick`、当前分支、每轮一次、下一分支与权威成本；客户端通过 `UseSkillCard` 提交具体逻辑牌名、目标和装备栏选择，核心仍使用普通牌的合法性及结算管线。响应、无懈和濒死自救通过现有 `ChoiceRequest` 暴露同一转换能力。

装备栏采用玩家权威状态中的五个禁用计数，顺序为武器、防具、防御坐骑、进攻坐骑、宝物。废除启用栏位时立即将其中装备移入弃牌堆；禁用栏位拒绝后续装备，并由状态不变量保证禁用栏内不会残留装备。转换分支、当轮已用分支和装备栏禁用状态均参与序列化与确定性哈希。

该能力要求 Rule VM ABI 17、Rule IR 28、引擎语义修订 103 与网络协议 5；ABI 3–16 的旧包继续按加法兼容规则加载。

## 理由

旧 `chooseToUse` 同时承担动态牌名选择、响应/救援窗口、转换状态和成本。将旧 JS 继续放入运行时会破坏可审计性与跨目标确定性；把每个技能写成核心分支又无法支撑上千技能。包声明只表达差异，核心提供一次通用能力，既保留旧语义，也让后续扩展只需安装 `.npack`。
