# ADR 0570：ABI 634 3D精选管宁【游学/承经】

本批按武将闭包发布管宁（`ddd_guanning`，4041793471）与【游学】（`dddyouxue`，
2449657606）、【承经】（`dddchengjing`，4114032104）。旧 JavaScript 只作语义证据，不进入
npack 或运行时。

【游学】在每轮首次实际阶段开始时触发。场上没有“游学”标记时先由管宁获得，再强制转交给
一名当前没有标记的存活角色；已有标记时直接转交。标记全场唯一，管宁按旧持有者至新持有者
的规则距离摸牌；首轮同样执行。

【承经】只在当前“游学”持有者的回合结束时检查。核心按使用顺序记录该回合非转化、恰有一个
实体材料的基本牌或普通锦囊，并从后向前选择仍在弃牌堆的第一张；旧“经”先弃置，再把候选牌
置为公开“经”。出牌阶段限一次，管宁可选择一张手牌或装备牌，按当前“经”的实体牌名与属性
走完整普通用牌和目标选择管线；完整结算后素材仍在弃牌堆时，可交给当前“游学”持有者的下一名
存活角色。

ABI 634 增加 `resolve_ddd_guanning(player,actor,action,card)`、两个精确触发过滤器和可恢复 Choice；
TurnState 仅在加载该能力的内容包时记录有序候选。装备区转化素材沿用共享 view-as 标记，并在
普通用牌入口统一放行，不建立管宁专用用牌旁路。

验收：【游学/承经】Golden 2/2、content-compiler 524/524、engine-api 4/4、engine-core lib
55/55、Rule VM 单元 10/10 与集成 5/5、31 个扩展空 store 冷导入均通过；内容锁为
`034214f96f787fb543ae9918ba3a516cab2cce55d7f964dbba5aec6f4edb0724`。

`official/ddd@0.1.0` 更新为 ABI 634，累计含 18 名武将、39 项技能、52 个模块、46 个触发、
6 项主动规则、5 项视为规则、4 项修正器和 18 项立绘资源；logic hash 为
`bffd8031e086447a83b9a6167d34d03bae6b5a512b0cf6e5268bdce4f4ae5f2e`，asset hash 为
`2611fa176cc1d1c623f94c4846bcafdc1a8b8e8a827f32d85d13b11b025e9aae`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`08596dc95c84723ad0002a1d6c78ae4e230f01e6953972613282664babe69802`；两份管宁立绘 SHA-256
均为 `b8ec096d4b9ad506485487d5649a12ee47707e9624c333f204f31b5713040224`。

编译产物按架构计划 §37.10 在本批门禁结束后清理；`.npack`、扩展、立绘、许可证、源码和
文档属于交付物并保留。本 ADR 只证明 3D精选第十八个武将闭包，不代表整个扩展迁移完成。
