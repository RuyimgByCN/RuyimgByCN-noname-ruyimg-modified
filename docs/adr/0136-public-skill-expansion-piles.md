# ADR 0136：通用公开技能扩展牌堆

## 决策

Rule VM ABI 46 增加：

```text
choose_store_hand_sha_in_skill_pile(player)
choose_spend_skill_pile_for_dying_jiu(player, dying)
```

权威状态新增通用 `Expansion` 区域和按 `(owner, skill definition)` 排序的 `skill_piles` 查找表。
牌仍是普通实体牌和区域成员，查找表只负责给技能定位稳定、可复用的公开牌堆；状态不增加
「醇醪」专用字段。存入时只能选择当前手牌中的一至多张逻辑【杀】，恢复选择时重新检查去重、
位置和牌名；牌进入扩展区后正面公开，其他玩家与旁观投影都能看到牌面。

濒死时技能拥有者可消耗一张当前牌堆牌到弃牌堆，再令濒死角色通过标准用牌管线对自己使用虚拟
【酒】。回复、离开濒死、牌事件及后续触发均由既有管线产生。濒死和回合开始属于中断窗口；其
可选技能及嵌套选择全部结算后，才恢复原生求救或回合推进续体。

## 不变量与兼容性

每个查找项必须唯一、严格按拥有者和技能定义排序，且引用一个归属同一玩家的 `Expansion` 区域；
不同技能不能复用同一个区域。快照恢复会重建规范顺序，状态哈希只在实际存在技能牌堆时加入
`skill-piles/v1`，旧零状态路径与旧包哈希保持不变。核心只解释通用区域和效果，不识别程普或
「醇醪」定义 ID；旧 JavaScript 不进入运行时。
