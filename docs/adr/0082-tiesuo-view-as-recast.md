# ADR 0082：视为【铁索连环】与零目标重铸

## 决策

把 `tiesuo` 加入通用 `view_as` 牌名集合，并映射到既有 `TrickTiesuo` 结算。视为技选择一至两名目标时沿用【铁索连环】及【无懈可击】管线；选择零名目标时沿用既有重铸语义，消耗实体牌并摸一张牌。

神话再临「连环」据此声明为“梅花手牌视为【铁索连环】”。旧 JavaScript 仅用于核对来源区域、花色、目标数与重铸分支，不进入内容包或运行时。

## 原因

【铁索连环】的使用和重铸已经由统一卡牌结算实现，视为技只缺少声明式牌名映射。复用同一入口可避免为「连环」复制卡牌逻辑，也保证实体牌消耗、无懈窗口、连环状态与重铸摸牌保持一致。

OFFLINE `huamao_lianhuan` 没有随本次迁移：它的有效花色由父技能在运行中随机选择并重新分配，不能按静态译文误写成固定梅花。

## 兼容性

没有新增 VM 指令或宿主效果，规则 VM ABI 维持 5，内容 Schema 维持 3；Rule IR 版本升至 10，引擎语义修订号升至 67。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
