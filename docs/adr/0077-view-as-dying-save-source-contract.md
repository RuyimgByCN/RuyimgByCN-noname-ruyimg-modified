# ADR 0077：视为牌濒死自救来源契约

## 决策

濒死自救只接受 `response` 或 `any` 窗口中声明为【桃】或【酒】的 `view_as`，并同时校验来源区域与牌过滤器。候选牌按桃、酒、自然牌、技能、手牌、装备区的稳定顺序选择；结算从实体牌实际所在区域移入弃牌堆。

补充通用 `black_basic_equip` 过滤器和查询期值 `owner_equip_count`。旧 JS 只作语义证据，不参与运行时。

## 原因

原实现只扫描手牌且忽略窗口、来源区域，会漏掉装备区牌自救，也会让仅装备区技能错误消费手牌。统一走既有 `view_as` 来源和过滤器可让主动使用、普通响应与濒死自救保持同一契约。

## 兼容性

新增过滤器复用 Rule VM ABI 5，内容 Schema 保持 3；Rule IR 版本升至 5，引擎语义修订号升至 62。既有 ABI 3/4 包仍可由 ABI 5 主机加载。
