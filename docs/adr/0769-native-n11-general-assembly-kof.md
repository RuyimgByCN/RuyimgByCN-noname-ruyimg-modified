## 决策

1. **武将元数据扩展**：`STANDARD_GENERALS` 扩为四元组
   `(名称, 势力, 技能集, 体力上限)`——标准版体力配置入目录；
   新增 `general_hp(g)` / `general_skills(g)` 查询助手。
2. **明置实际装配**：`RevealGeneral` 校验通过后授予该武将全部技能
   （`SkillInstance` 插入）并配置体力（首次明置主将 → 体力上限取
   武将体力，超出部分截断；副将明置不改体力）。**暗置技能资格门控**
   由此结构性成立：技能实例仅在明置后存在，暗置期间
   `core.skills` 无实例（正反回归覆盖）。
3. **双将合法性**：将池抽取互不重复 + 回归断言双槽不同下标。
4. **KOF 会话**（`examples/n11_kof` 重写）：两位选手各 3 将队列
   （官方将池确定性抽取）；每局双方出队首将（明置装配同款）；败者
   武将淘汰出池、胜者保留回队尾；一方池空则会话终局；会话状态
   文本序列化 `save/restore` 严格互逆（续跑往返断言）。
