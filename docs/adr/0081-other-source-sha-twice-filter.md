# ADR 0081：其他来源【杀】伤害的每回合两次过滤器

## 决策

新增通用触发过滤器 `owner_alive_other_source_sha_twice`：技能拥有者存活时，仅观察其他存活角色造成的逻辑【杀】伤害，并按技能实例在每回合至多发动两次。

OFFLINE「淑丽」据此在可选触发确认后，复用 `draw_each_by_seat` 让技能拥有者与伤害来源按座次各摸一张牌。旧 JavaScript 只作语义证据，不进入内容包或运行时。

## 原因

“全局观察其他来源”“逻辑【杀】”“每回合次数限制”都属于触发条件，不应拆成技能 ID 特判或运行时 JavaScript。过滤器复用现有逻辑牌判定、存活判断与技能实例回合计数。

## 兼容性

没有新增 VM 指令或宿主效果，规则 VM ABI 维持 5，内容 Schema 维持 3；Rule IR 版本升至 9，引擎语义修订号升至 66。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
