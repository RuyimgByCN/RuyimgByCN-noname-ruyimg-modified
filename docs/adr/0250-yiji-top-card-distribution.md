# ADR 0250：遗计牌堆顶分配

## 决策

ABI 174 增加 `distribute_top_two_cards(player)`。技能每匹配一个伤害点，将牌堆顶至多两张牌
移入公共处理区；技能拥有者反复选择非空剩余牌子集和一名存活角色，直到全部牌进入对应角色
手牌。

## 实现

初始移牌和后续选择通过延迟效果分段；同一次遗计的未分配牌优先于下一伤害点继续处理。子集、
处理区归属和目标存活状态在每个屏障重新校验；仅剩一张牌时自动选中该牌，只询问接收者。选择
使用 continuation 116，`EffectRequest` 稳定哈希标签为 216。

旧 JavaScript 的联网倒计时、连线动画、身份暴露和 AI 分配逻辑不进入运行时。
