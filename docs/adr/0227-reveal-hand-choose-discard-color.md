# ADR 0227：展示手牌后由展示者选择弃置颜色

## 决策

ABI 154 追加通用 effect `reveal_hand_choose_discard_color(player)`。它公开该玩家的完整当前
手牌；只有一种有效红黑颜色时直接选中，两种颜色同时存在时由该玩家强制选择，随后弃置所选
颜色的全部当前可弃手牌。选择通过新增 continuation 108 保存玩家与候选颜色掩码，并在提交时
重验观察者、颜色和当前牌状态。

同时追加 `owner_source_sha_target_alive_hand_nonempty` 过滤器，精确表达“存活拥有者使用
【杀】指定一名有手牌的存活目标”，避免空手目标收到可选发动提示。

## 原因

旧「将烈」的实际 JavaScript 与描述存在易误读差异：展示手牌后由【杀】的目标自行选择颜色，
不是技能拥有者选色；单色手牌也不会打开选择。已有按固定牌名弃置效果无法表达动态颜色选择，
技能专用宿主逻辑又无法供后续迁移复用。

## 验证

Golden 覆盖空手目标不触发、可选发动、双色时由目标选色、单色自动处理、公开展示、只弃所选
颜色及非法颜色提交拒绝。
