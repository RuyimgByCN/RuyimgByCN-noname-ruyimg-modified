# ADR 0190：按装备栏取得目标装备

## 背景

旧版 `mobile:xinduodao` 在拥有者受到伤害后检查伤害来源的武器栏，并在玩家确认后取得
结算时仍可获得的全部武器。旧实现依赖 JavaScript 事件对象和 `getEquips(1)` 动态查询，
不能直接进入确定性运行时。

## 决策

新增 Rule VM ABI 117 原语：

`gain_target_equipment(player, target, slot)`

原语只序列化玩家、目标和稳定装备栏标签；执行时重新扫描目标装备区，将仍处于该栏位的
全部牌按一次给予移动送入获得者手牌。无匹配牌时确定性地空操作。

同时新增 `owner_is_target_source_has_weapon` 过滤器，只在拥有者是受伤角色、伤害来源存在
且当前仍装备至少一张武器时提供可选触发。过滤器不要求来源存活，与旧 JavaScript 仅检查
来源对象及可获得武器的行为一致。

## 结果

- 运行包不执行旧 JavaScript。
- 可选确认和最终装备扫描之间的状态变化不会产生陈旧牌引用。
- 同一原语可复用于其他按武器、防具、坐骑或宝物栏取得装备的技能。
