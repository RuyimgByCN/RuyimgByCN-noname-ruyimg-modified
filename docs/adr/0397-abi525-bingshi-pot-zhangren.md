# ADR 0397：ABI 525 兵势张任（伏暗/引弦）

本批发布兵势张任（`pot_zhangren`，3752976087）及「伏暗」
（`potfuan`，2955537231）、「引弦」（`potyinxian`，2595028433）。旧
JavaScript 仅作为语义合同，不进入 npack 或运行时。

## 决策

- 「伏暗」复用回合弃牌花色历史：结束阶段把基础攻击范围调整为零并清空「引弦」
  加值，按减少值至多摸五张，再从手牌选择本轮未记录过的花色。
- 其他角色回合结束时，移除本回合进入弃牌堆的全部已记录花色，并无距离、次数限制
  地对一名合法角色使用虚拟【杀】；首次【杀】造成伤害后可追击一次，或令原目标的
  非锁定技失效至其回合结束。追击分支全局只能选择一次，忠实保留旧技能状态。
- 「引弦」对攻击范围内距离最远目标使用【杀】时令基础伤害 +1；回合外每完成一次
  用牌，技能实例的攻击范围加值 +1。
- ABI 525 新增两个 typed effect 和两个精确过滤器，其余选牌、虚拟杀、伤害、弃牌
  花色历史与临时技能失效均复用既有管线。
