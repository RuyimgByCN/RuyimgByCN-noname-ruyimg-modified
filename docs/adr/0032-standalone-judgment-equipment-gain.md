# ADR 0032：独立判定与按颜色获得装备

## 决策

Rule VM 新增 `judge_gain_equipment_by_color(player)` 类型化效果：执行一次确定性判定；红色从牌堆
顶向下获得第一张装备牌，黑色从弃牌堆顶向下获得第一张装备牌，没有符合牌时不再执行移动。
判定复用引擎现有的翻牌、洗牌、有效花色与移动牌路径，旧 JavaScript 只保留为语义证据。
触发目录同时追加“拥有者成为锦囊目标，且单目标或有可弃手牌/装备牌”筛选器，供存畏复用。

## 原因

首个使用者是 `newjiang:biancai`（辨材）。把牌堆遍历和判定留在旧 JS 或技能私有代码会绕开
服务器权威、确定性牌堆顺序和回放哈希；一个类型化复合效果足以覆盖其完整语义，无需增加 JS
运行时、脚本回调或新的选择状态。

## 兼容性

新 `EffectRequest`、VM 效果标签与触发筛选器均追加在旧序号末尾，旧 npack、快照和回放的已有枚举序号不变。
现有标准内容不调用该效果，因此已固定的开局和完整对局状态哈希保持不变；内容包与 manifest 哈希
按新能力正常变化。`EngineSemanticsId` 从修订 15 升至 16，Native、浏览器 WASM 与 skill-vm 必须
重新通过跨目标一致性门禁。
