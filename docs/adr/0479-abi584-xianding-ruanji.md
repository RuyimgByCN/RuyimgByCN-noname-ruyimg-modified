## 决策

旧 JavaScript 只作语义合同，不进入内容包或运行时。XIANDING 阮籍按上游元数据发布为魏势力、
3 体力，技能为【昭文】与【酒遁】。

【昭文】在出牌阶段开始可记录当时全部手牌。本回合内，仍在手牌区的已记录黑牌可作为任意普通
锦囊的实体材料，每种牌名限一次；使用已记录红牌时，按本次使用的已记录红色实体材料数摸牌。
转化声明复用普通锦囊合法性、无懈和完整结算管线。

【酒遁】把以拥有者为目标的【酒】原效果替换为获得一枚饮酒标记；其他角色用黑牌指定拥有者后，
未饮酒时可摸一张并视为对自己使用【酒】，已饮酒时可弃一张手牌令当前牌对自己无效。

ABI 584 新增 `resolve_ruanji(player, source, card, action)`、昭文/酒遁过滤器及 `dczhaowen`
source-free 成本。为避免长期追踪牌被一次转化材料覆盖，`SkillInstance` 将待消费的 source-free
实体材料从内容状态 blob 拆为独立、可序列化且参与状态哈希的字段；这是所有转换技能共用的状态
边界，不是阮籍特例。带目标的 `CardUsed` 作为替换时点，效果调度器先挂起剩余牌效果，再执行
目标触发，使【酒】改写和当前牌目标排除能直接修改权威尾队列。
