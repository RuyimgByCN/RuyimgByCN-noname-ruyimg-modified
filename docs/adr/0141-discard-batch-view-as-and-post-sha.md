# ADR 0141：整批弃牌视为与精确【杀】后置结果

## 决策

Rule VM ABI 51 增加完整的 `cards_moved` 事件牌列表，以及两个类型化效果：

```text
choose_discarded_black_basic_as_bingliang(player)
choose_discard_judge_use_virtual_sha_draw_if_no_damage(player, target)
```

第一个效果从本次移动事件的实体牌中筛选仍在弃牌堆的有效黑色基本牌。玩家可逐张选择，再选择一个
合法目标；每个选择屏障都重新校验牌区、有效颜色/类别、目标状态和重复延时牌。选中的实体牌进入
现有视为【兵粮寸断】管线，复用用牌事件、无懈窗口和延时区放置，仅按技能语义忽略距离。取消当前
牌选择会结束余下批次，不需要技能专用循环状态。

第二个效果先通过 `TargetCardScope::Judge` 选择并弃置目标判定区的一张牌，再生成无来源虚拟【杀】。
该牌复用普通目标合法性、响应和伤害结算，但不消耗普通【杀】次数。引擎按这张虚拟牌的精确
`CardId` 保存“未造成伤害则摸牌”的短期策略；整次【杀】结束时统一消费。不能合法使用、被完整闪避
或未提交伤害时摸一张，任一目标实际承受伤害则不摸。

两个效果都由宿主注入当前稳定技能定义 ID，不识别「慎断」「勇略」、韩浩史涣或包名。旧
JavaScript 只用于确认触发、选择和结算顺序，不进入内容包或运行时。
