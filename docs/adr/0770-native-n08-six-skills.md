## 实现

1. **急救（华佗，锁定）**：濒死结算桃判定扩面——持有者红色手牌
   （Heart/Diamond）可当桃（`is_tao_like` 谓词贯穿应答者过滤/
   全场再询/选项构建三处）。
2. **护驾（曹操，登记差异：不限魏将）**：出闪询问选项并入其他存活
   角色手中的闪；应答移除按牌实际所在区/持有者定位（跨玩家借闪）。
3. **流离（大乔）**：成为杀目标时（出闪判定前）询问转移——弃一张
   手牌，杀目标改为另一名其他角色（不含来源），八卦/铁骑判定对
   新目标重做。运行时标记不入快照：挂起恢复后重问一次（行为等价，
   登记为已知权衡）。
4. **结姻（孙尚香，出牌阶段限一次）**：弃两张手牌 + 一名装备区有牌
   的其他角色 → 双方各回复 1 点体力（登记差异：不限已婚男性）。
5. **反间（周瑜，出牌阶段限一次）**：目标获得周瑜一张手牌
   （目标看牌选牌承载官方花色选择，登记差异），随后受周瑜 1 点伤害。
6. **离间（貂蝉，出牌阶段限一次）**：弃一张手牌置于桌面作为载体，
   令两名其他角色决斗——载体牌直结算（内嵌 `DuelMachine` 委托，
   Jijiang 同款）；登记差异：不限男性角色。
