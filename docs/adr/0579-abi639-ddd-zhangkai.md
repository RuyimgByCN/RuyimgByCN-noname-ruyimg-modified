# ADR 0579：ABI 639 3D精选张闿【劫行/拜泪】

本批按武将闭包发布张闿（`ddd_zhangkai`，4228225358，群，初始 3/上限 4 体力）与
【劫行】（`dddjiexing`，3377566778）、【拜泪】（`dddbailei`，2689073031）。旧 JavaScript
只作语义证据，不进入 npack 或运行时。

【劫行】以限定技计数记录可用状态：可在其他角色回复前取消原回复并令张闿回复等量体力，或在
其他角色使用装备牌时取消该次使用，将仍在当前使用者手牌区或处理区、且张闿对应栏可用的本次实体装备牌依次置入其装备区，
同栏原装备按规则替换。截取动作自身产生的回复不会立即恢复【劫行】；之后张闿正常回复体力，或
使用装备牌完整结算后，才把限定技计数重置为可用。

【拜泪】在准备阶段只列出装备数严格唯一最多且有可获得手牌/装备牌的角色，以及当前体力为 1 的
角色。两种条件同时满足时，可取牌或取消取牌改为伤害；只满足唯一最多时必须取一张，只满足
1 体力时造成 1 点伤害。伤害经完整濒死链结算，目标因此死亡后移除【拜泪】。

验收：张闿 Golden 4/4、content-compiler 530/530、engine-api 4/4、engine-core lib 55/55、

`3b99eefa260df3ef3253d228885bb93c6fc401ad9355229752a93fefa1f3eed4`。
