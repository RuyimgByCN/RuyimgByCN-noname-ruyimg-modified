# ADR 0382：ABI 510 兵势张燕飞径、骁戈

旧 `bingshi/skill.js` 仅作为语义证据，JavaScript 不进入新运行时。

- `mbfeijing` 用声明式视为同时覆盖出牌与响应；复用悬挂中杀的追加目标管线，只新增座次
  路径、秘密弃牌和颜色选择的可恢复结算。
- 飞径在技能实例中以 `FJG1` 临时绑定杀、追加目标及各自弃牌，骁戈据此只阻止本次杀对
  飞径目标的伤害，并复用回血、弃牌区取回与虚拟决斗原语。
- `mb_zhangyan.skill` 与角色索引进入 bingshi 包；Golden 覆盖伤害锦囊转杀、路径弃牌、
  同色追加目标及骁戈防伤回血取牌闭环。
