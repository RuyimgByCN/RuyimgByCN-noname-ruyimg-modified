# ADR 0406：ABI 529 兵势桓阶（共谋/正朔）

本批发布兵势桓阶（`pot_huanjie`，2873796786）及「共谋」
（`potgongmou`，3894451488）、「正朔」（`potzhengshuo`，2346184405）。
旧 JavaScript 仅作为语义合同，不进入 npack 或运行时。

## 决策

- 「共谋」在准备阶段选择一名双方手牌总数大于零的其他角色，原子交换双方全部
  手牌；拥有者获得 YIJIANG「奇策」，目标获得 SHENHUA「看破」，均持续至当前
  回合结束。兵势包以显式依赖引用原技能定义，不复制跨包技能。
- 「正朔」为限定主动技：所有存活角色按座次弃置全部手牌，待移动事件结算后把
  弃牌堆洗回牌堆，再按座次各摸四张。
- 同批补齐原属 YIJIANG 的「奇策」（`qice`，3567101194）：出牌阶段限一次，把
  全部手牌作为任意普通锦囊牌使用；复用现有多实体材料用牌管线，使所有材料共同
  进入用牌历史并在完整牌结算后收尾。
- ABI 529 仅新增一个 typed effect 和 `all_hand` 源免费转化成本；整手交换、临时
  技能、实体牌移动、洗牌及摸牌均复用既有实现。

## 验证

- 势桓阶 Golden 覆盖包合同、共谋交换与临时技能、正朔全场重发、奇策全手材料。
- 本批产出的 `yijiang` 与 `bingshi` npack 均要求 ABI 529；后续兵势批次会按新增
  原语提高整个 `bingshi` 包的 ABI，下游仍以包内 manifest 为准。
