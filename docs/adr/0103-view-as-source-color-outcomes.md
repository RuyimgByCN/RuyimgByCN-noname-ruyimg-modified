# ADR 0103：视为牌的来源颜色结算策略

## 背景

旧版 KEY「求略」允许非基本牌转化为【杀】：红色来源令该次【杀】不可响应，黑色来源令该次【杀】不计入普通使用次数。旧实现依赖 `useCard1` 中的技能来源判断与 `addCount` 改写，不能直接执行，也不能扩大成影响普通【杀】的全局修正器。

## 决策

- `view_as` 新增 `non_basic` 来源过滤器，以及仅适用于转化【杀】的 `red_unrespondable`、`black_no_use_count` 合同。
- 服务器在选定实体来源牌后读取有效花色；红色策略只覆盖本次转化牌的响应标志，黑色策略只跳过本次普通【杀】次数校验与计数增加。
- 距离、目标合法性、用牌、响应、伤害和实体牌移动继续走普通用牌管线；合同不保存旧技能名，也不添加 KEY 专用分支。
- 新引擎当前可用的个人牌区为手牌与装备区，因此旧 `hes` 在该技能中映射为 `hand_equip`；未来若引入独立可使用的特殊牌区，应扩展通用来源区枚举而非修改本技能。

## 兼容性

该能力提升 Rule VM ABI 至 14、Rule IR 至 24、Engine Semantics 至 99。旧包字段缺省为关闭，不改变既有 view-as 结果。
