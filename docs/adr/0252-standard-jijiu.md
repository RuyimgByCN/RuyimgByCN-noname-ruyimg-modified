# ADR 0252：标准急救回合外视为桃

## 决策

ABI 176 增加视为牌过滤器 `owner_outside_turn_red`。STANDARD「急救」在技能拥有者的回合外，
允许把一张红色手牌或装备牌当【桃】用于响应/救援；拥有者自己的回合内不提供该转换。

## 实现

过滤器复用权威回合状态、有效花色、普通视为牌来源区校验和濒死救援管线，不增加 HOST_EFFECT、
`EffectRequest` 或 continuation。旧 JavaScript 的音频与 AI 牌值排序不进入运行时；旧引擎
`hes` 中的特殊客户端牌区在当前权威模型中没有对应持久区，支持的实体来源为手牌和装备区。
