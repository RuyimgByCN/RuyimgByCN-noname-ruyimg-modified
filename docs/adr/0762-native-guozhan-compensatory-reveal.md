# ADR 0762：国战补偿明置时机

日期：2026-09-22（第六十三批）
状态：已采纳
上游：[0757](0757-native-guozhan-reveal-gating.md)

## 决策

1. **补偿明置窗口**：`RevealGeneral` 的时机门控由「自己回合出牌阶段」
   扩展为「或结算栈中存在以自己为目标的牌」（扫描栈帧
   `EventData::CardUsed.targets`）——成为杀/锦囊目标时即使非自己回合
   亦可明置。
2. **并行提交通道**：补偿窗口与挂起询问（如出闪询问）天然重叠，而
   引擎在询问挂起期拒绝一切非 Answer 命令。为此 `RevealGeneral` 获得
   ChoicePending 拦截豁免，并走专用提交路径：只应用明置状态变更、
   **不推进结算**，原询问以 Pending 原样保留（choice id 不变，
   revision +1，去重键消耗，配额记账）。结算轨迹零扰动。
3. 非目标玩家借并行通道发明的置：不满足补偿窗口 → 回退常规时机
   校验（回合/阶段）照常拒绝，无越权窗口。

## 验收

- `guozhan_compensatory_reveal_during_targeting`：出闪询问挂起中
  补偿明置成功、明置状态入快照、原询问 id 不变且结算照常
  （放弃出闪 1 伤）、非目标玩家被拒。
- 全量 **208 passed / 0 failed**；纯校验与提交路径扩展，无编码变化。

## 后果

国战明置时机扩展（补偿明置）闭环；N11 剩余仅「武将配置宿主装配」
（将池分发/换将流程，属宿主侧装配工作）。
