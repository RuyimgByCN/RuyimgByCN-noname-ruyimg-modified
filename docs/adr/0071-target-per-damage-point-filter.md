# ADR 0071：受伤者按伤害点触发过滤器

## 决策

新增通用过滤器 `owner_is_target_other_source_alive_per_damage_point`。它仅在技能拥有者是受伤角色、伤害来源为另一名存活角色且伤害值为正时匹配，并沿用现有伤害触发队列按 `event_amount` 生成独立结算。

同时新增 `owner_source_target_alive_has_hand_or_equip`，用于精确表达伤害来源仅在存活目标有可获得区域牌时触发的技能。

## 原因

旧版 `spmingshi` 使用 `getIndex: event => event.num`，必须逐点要求伤害来源弃牌。已有双端点过滤器会错误地同时匹配伤害来源，普通受伤过滤器又只结算一次。旧版 `goblin_lingruo` 则在目标无牌时完全不触发，不能仅依赖取牌效果事后空操作；两个窄而通用的过滤器是最小的精确表达。

## 兼容性

枚举项追加在末尾以保持既有序列化序号。引擎语义修订号递增到 56；标准武将池不变，只有显式声明该过滤器的外部包受影响。
