# ADR 0073：ABI 4 的通用虚拟【杀】

## 决策

新增 `choose_use_virtual_sha` DSL 效果。引擎为其创建 `CardDefId::NONE`、无花色的稳定虚拟牌，先放入处理区，再复用普通【杀】的目标合法性、次数、响应、伤害、触发与历史管线，结算或取消后移入移除区。`ignore_distance` 只忽略距离，不绕过存活、自身、目标保护等其他约束。

旧版 JS 只作为行为语义依据，不进入新运行时；“影箭”也不增加技能名特判。

## 原因

把“视为使用【杀】”直接改成伤害会丢失响应、触发和历史语义。公共虚拟牌原语既完整复用出牌管线，也能供后续同类技能使用。

## 兼容性

新增宿主效果后，规则 VM ABI 升至 4，Rule IR 与清单 VM ABI 轴升至 2，引擎语义修订号升至 58。编译器按实际使用的效果写入最低 ABI：未使用新效果的包仍稳定产出 ABI 3，使用虚拟【杀】的包产出 ABI 4。ABI 4 是 ABI 3 的加法超集：ABI 4 主机可加载 ABI 3 或 ABI 4 包；ABI 3 主机必须拒绝 ABI 4 包。无花色枚举追加在末尾，以保留既有序列化序号。
