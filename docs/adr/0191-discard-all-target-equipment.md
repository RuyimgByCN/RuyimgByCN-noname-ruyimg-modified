# ADR 0191：弃置目标全部可弃装备

## 背景

旧版 `mobile:ly_piliche` 在拥有者对其他角色造成伤害后，先检查目标手牌区或装备区是否有
可弃牌；玩家确认后，弃置目标装备区内的全部牌。检查范围与最终效果范围并不相同：目标只有
可弃手牌时仍能确认，但最终不会弃置手牌。

## 决策

新增 Rule VM ABI 118 原语：

`discard_all_target_equipment(actor, target)`

原语不保存预选牌列表。执行时使用统一弃置保护查询重新取得 `actor` 可从 `target` 装备区
弃置的全部牌，再以一次批量弃置移动完成结算。任一角色已死亡或当前没有合法装备时空操作。

同时新增
`owner_source_other_target_alive_has_discardable_hand_equip`，仅匹配拥有者对另一名存活角色
造成伤害，且目标手牌或装备区至少有一张当前可由拥有者弃置的牌。

## 结果

- 旧 JavaScript 只作为语义参考，不进入运行包。
- 保留旧实现“检查 hand/equip、实际只弃 equip”的边界行为。
- 装备弃置保护统一由引擎查询执行，确认与效果之间的状态变化不会使用陈旧牌引用。
