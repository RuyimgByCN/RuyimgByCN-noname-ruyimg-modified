# ADR 0129：按事件点数重复选择其他角色并按空手状态摸牌

## 背景

旧「淑慎」在拥有者实际回复每一点体力后，都允许其独立选择一名其他角色；目标有手牌时摸一张，
没有手牌时改为摸两张。旧实现用 `getIndex(event)` 把一次多点回复拆成多个异步目标选择，不能在
确定性运行时保留 JavaScript 的事件对象、Promise 或界面选择器。

## 决策

- Rule VM ABI 39 追加
  `choose_other_draw_by_hand_count(player, normal_count, empty_count, times)`，host effect tag 为 57。
- 效果使用有界续体保存选择者、两种摸牌数、剩余次数和来源技能。每次选择都可独立取消；取消一
  次只消耗当前次数，不会吞掉后续次数。
- 候选集合只包含除选择者外的存活角色。续体恢复时重新校验选择者、目标和剩余次数，并按提交时
  的目标手牌状态决定摸牌数；伪造自己、死亡目标或错误选择数量均原子拒绝。
- 实际摸牌使用携带来源技能的类型化效果，保证后续摸牌触发仍能识别准确的技能来源。
- `stdshushen` 直接以 `event_amount` 作为 `times`，因此一次实际回复两点与两次各回复一点在选择
  权利上等价。旧 JavaScript 只保留为语义与溯源证据。
- 甘夫人的另一个技能「神智」归属 SP 包；在基础 `standard` 与可选扩展的依赖/覆盖模型统一前，
  本 ADR 只发布「淑慎」，不把甘夫人武将条目错误标记为完整迁移。
