# ADR 0114：改判来源区域与多人响应顺序

## 决策

保留已有 `judgment_rewrite` 作为仅手牌改判通道，新增
`judgment_rewrite_hand_equip`，允许技能拥有者从手牌区或装备区选择一张牌改判。候选牌必须
同时通过当前引擎可表达的通用 `cardEnabled2` / `cardRespondable` 对应查询，包括全局响应禁用、
按牌禁用、手牌使用/响应禁用和【杀】响应禁用。

一次判定会从判定角色开始按存活座次依次询问所有拥有改判通道的角色。每人可以选择一张
当前合法的牌，或放弃本次机会；无合法牌者自动跳过。前一名角色替换后的花色与点数成为
后一名角色看到的当前判定结果，全部窗口结束后才应用延时锦囊效果。

运行时只解释通用 modifier 与 Choice continuation，不按 `reguicai` 或角色 ID 分支。
因此经典鬼才继续保持仅手牌语义，界鬼才以及后续同类技能直接复用手牌/装备区通道。

## 版本与兼容

该能力要求 Rule VM ABI 24、Rule IR 35、引擎语义修订 110。ABI 24 主机继续按加法兼容规则
加载 ABI 3–23 包。`RewriteJudgment` continuation 的内部 payload 随语义修订更新；匹配清单会
阻止旧语义中的进行中快照在新语义下恢复，因此内容 Schema、网络协议、回放 Schema、快照
Schema 与包格式均不变。
