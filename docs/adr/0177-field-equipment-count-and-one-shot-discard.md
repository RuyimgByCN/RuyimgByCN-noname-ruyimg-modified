# ADR 0177：场上装备类别计数与一次性动态弃牌

## 状态

已接受（2026-07-23）。

## 背景

旧版「溃围」在结束阶段按场上武器数摸牌，并添加一个辅助技能；该辅助技能在拥有者的下个摸牌
阶段重新统计武器数，强制弃置等量手牌或装备，数量不足时全弃，然后移除自身。既有公开牌堆类别
查询不统计装备区，既有单张弃牌效果也不能表达动态数量及 Choice 后清理。

## 决策

Rule VM ABI 102 增加两项通用能力：

1. `field_equipment_kind_count(card_kind)` 只读查询遍历存活角色的装备区，统计指定物理牌类别；
2. `choose_discard_hand_equip_then_remove_self_skill(player, count)` 强制弃置
   `min(count, 当前可弃手牌装备数)` 张牌；
3. 需要选择时，续体只保存玩家、来源技能、冻结的数量和合法牌 ID；恢复时重新验证所有选择；
4. 一次性技能移除进入权威延后尾队列，等待弃牌移动、失牌触发及嵌套 Choice 全部完成。

## 后果

- 发动时与延迟结算时可分别重算场面，不缓存旧事件或武器列表。
- 以后所有“按场上某类装备计数”和“动态强制弃牌后消费一次性技能”的技能可复用同一能力。
- ABI 101 主机拒绝 ABI 102 包；ABI 102 主机继续加载 ABI 3–101 的加法式内容包。
