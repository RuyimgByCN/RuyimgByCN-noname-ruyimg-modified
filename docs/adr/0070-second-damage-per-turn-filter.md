# ADR 0070：技能实例的每回合第二次受伤过滤

## 决策

- DSL 增加 `owner_is_target_second_damage` 过滤器。
- 过滤器要求技能拥有者是伤害目标，并且该技能实例本回合恰好已处理一次伤害事件。
- 与第一段、后续段过滤器共用 `SkillInstance.turn_fire_count`；回合切换沿用既有统一清零。
- 新枚举成员追加在末尾，保留既有 npack 序列化序号。

## 理由

旧 `dcshibei` 只处理每回合第一、第二次受到伤害，第三次及以后不触发；它与“第一次后全部触发”
的 `shibei` 不同。使用技能实例计数能准确区分两者，也能复用到其他按伤害事件序号结算的技能，
无需运行旧 JavaScript 或按技能 ID 写引擎分支。

## 兼容性

引擎语义修订号递增到 55。标准武将池和既有对局起始状态不变；新增的界沮授只由 refresh
扩展包发布。
