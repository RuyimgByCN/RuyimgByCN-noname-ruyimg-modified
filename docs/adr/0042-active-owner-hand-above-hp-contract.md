# ADR 0042：主动技拥有者手牌数高于体力前置条件

- 状态：已接受
- Engine semantics：26

## 背景

「熟虑」继承制衡的弃牌摸牌流程，但仅在拥有者手牌数大于当前体力时可发动。把条件留在技能效果中会允许非法激活、消耗次数或打开无效选择窗口。

## 决策

- 主动技 DSL 增加通用 `hand_gt_hp` 契约；
- 编译产物以默认关闭的布尔字段携带该契约，旧包保持兼容；
- 权威命令入口在打开选牌窗口和执行效果前比较技能拥有者的手牌数与当前体力；
- 逻辑哈希仅在契约启用时加入 `active-owner-hand-gt-hp/v1`，不依赖技能名。

## 结果

「熟虑」可复用现有主动技限次、手牌/装备选牌、弃置与摸牌能力；后续同类技能也无需新增技能名分支。
