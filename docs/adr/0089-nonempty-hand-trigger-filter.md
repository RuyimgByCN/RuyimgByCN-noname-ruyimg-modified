# ADR 0089: 手牌非空条件进入通用触发过滤器

## 决策

在声明式触发过滤器末尾追加 `owner_is_target_hand_nonempty`，并增加参数化的
`owner_is_target_mark_positive_<id>`。前者只在技能拥有者是事件角色且当前至少有一张手牌时
创建触发记录；后者再要求后缀指定的稳定标记为正，避免其他角色的同名阶段误触发。

SP「神智」使用该过滤器，并在 VM 中先冻结发动时的手牌数，再弃置全部手牌，最后按冻结值
判断是否回复。旧 JavaScript 只作为语义证据，运行时只加载编译后的触发索引与字节码；能力
没有技能专用 Rust 分支，可直接复用于其他准备阶段、事件角色或跨阶段状态技能。

声明式触发过滤器词汇扩展后，Rule IR 从 15 提升至 16，Engine Semantics 从 73 提升至 74；
Rule VM ABI 保持 8。Native/WASM 与 conformance 哈希门禁必须在本变更后重新执行。
