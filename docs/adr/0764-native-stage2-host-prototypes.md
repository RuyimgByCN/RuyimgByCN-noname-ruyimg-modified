# ADR 0764：阶段 2 宿主装配器与渲染器的引擎侧原型

状态：已采纳
上游：[0761](0761-native-n10-presentation-render.md) / [0762](0762-native-guozhan-compensatory-reveal.md) / [0763](0763-native-n08-snatch-lianying-jijiang.md)

## 独立复核更正（2026-09-22）

两个示例本轮均退出 0。host_assembler 4 人 8 个将槽有名称，但 core.skills=0；RevealGeneral 仅改明置标志，不授予技能或配置体力。
因此证明的是元数据分发/视图/确定性，不是完整可玩武将装配。render_host 是文本帧与增量表现事件消费，没有图形呈现链路。
按目标架构 §12，正式渲染/AI 与完整平台分别属于第三、第四阶段；本文件“阶段 2 平台侧”是历史局部称呼。

当前反例、优先级与证据见 [进度主稿](../architecture/native-progress.md)。以下保留当批设计/记录，不作为当前完整验收结论。

## 背景

进度文档剩余的「武将配置宿主装配」「宿主渲染器接入」属阶段 2 平台侧
工作，但其引擎侧形态可在会话内以 examples 层宿主原型落地，验证宿主
集成的最小契约。

## 决策

1. **宿主装配器原型**（`examples/host_assembler.rs`）：官方将池
   （剔除样例条目，26 名）按宿主种子独立确定性洗牌（Fisher-Yates，
   宿主 RNG 与对局 RNG 分离），为每座位发主/副将（全暗置）经存档
   快照注入国战局；装配校验三件套——`declared_faction` 消费声明、
   观战者帧零将领名泄露（本人帧含自己暗置主将）、同种子重装配逐
   哈希一致。同款契约锁定进套件
   （`host_assembler_prototype_contract`）。
2. **宿主渲染器原型**（`examples/n10_render_host.rs`）：全座位
   AiSession 自动化驱动整局（询问按 min 选项应答、进攻尝试、阶段
   推进兜底；行动座位 = 开放选择 observer 优先），**增量消费**
   `PresentationEvent` 流（只投影上次消费位置之后的新增日志段——
   真实宿主形态），按出牌阶段开始产出渲染帧，终局打印观战者帧
   （含胜负横幅/阵亡/凶手归属）；运行时断言观战者事件流零摸牌牌名。
3. 两原型均为 examples 层可运行程序（无网络、无平台依赖），作为
   阶段 2 正式接入（web/canvas 宿主、正式客户端）的契约参考实现。

## 验收

- `host_assembler -- 4 42 7`：装配输出、势力查询、隔离校验、确定性
  校验全部通过。
- `n10_render_host -- 3 99`：3 局全部打出真实终局（胜负横幅/阵亡/
  凶手归属），增量事件消费与观战者契约成立。
- 全量 **211 passed / 0 failed**（+1）；纯 examples 与测试增量，
  无版本变化。

## 后果

进度文档中「武将配置宿主装配」「宿主渲染器接入」的引擎侧形态闭环；
剩余为真正平台接入（正式客户端/web 宿主，需会话外环境）与 N12
旧线驱动器闭环及真机验证（需本地回环网络与真机载体）。
