## 背景

N06（逐条确认规则语义与身份局覆盖）要求固定规则来源并逐条核对挂账。
本批对旧线实现做了定向代码对照，得到四项事实并据此对齐/登记：

1. **无懈询问起点**：旧线 `begin_wuxie_window(tx, actor, …)` +
   `alive_from_seat(actor)`——队列自**使用者本人**起（含本人）。
   原生线此前自来源下家起（排除来源）→ 差异。
2. **延时锦囊无懈时点**：旧线在**使用时**开窗——牌先弃置、未被无懈才移入
   判定区（play.rs「Leave hand into discard first; after 无懈, move into
   judge」）。原生线在判定阶段才开窗 → 差异。
3. **闪电去向**：旧线 `pass_lightning`——传给**下一位存活玩家**；其判定区
   已有闪电则**直接弃置**（不绕行扫描）。原生线此前扫描首个无同名牌者
   （可能绕行/回到自己）→ 差异。
4. **身份局**：旧线 `STANDARD_IDENTITY_TABLE`（主公固定座位 0、2–8 人表）
   与 `check_identity_victory`（主公死 → 内奸唯一存活则内奸胜否则反贼胜；
   反贼内奸全灭 → 主公方胜）在上述配置和分支上与原生实现一致；这不涵盖所有终局边界。
   旧线另有 2/3 人特殊表，原生维持 4–8 人约束。

另：身份局长流程测试暴露**每段预算缺陷**——预算作为状态燃料跨段累计
递减，长对局必然在合法命令上耗尽（4000 步在数百个阶段后耗光）。

## 决策

### 1. 延时锦囊无懈窗口前移至使用时（对齐旧线）

- Le/Bing/ShanDian 出牌提交后**先置桌面**，`Intrinsic` 阶段开启无懈窗口
  （与南蛮/万箭/决斗/铁索同一机制）；未抵消由 `PlaceDelayedMachine` 置入
  目标判定区（目标窗口期死亡则弃置）；被无懈则直接弃置、永不入判定区。
- 判定阶段（`JudgePhaseMachine`）恢复直判，不再开窗；保留判定中死亡时
  队列逐张弃置（N02）。
- `JudgeTrickMachine` 移除；新增 `PlaceDelayedMachine`（快照五处联动同步）。

### 2. 无懈窗口询问起点对齐

所有锦囊窗口（南蛮/万箭/决斗/铁索/延时锦囊置入）队列改为
`seat_order_from(source)`——自来源本人起、含本人。持有者过滤语义不变。

### 3. 闪电去向对齐

未命中 → 传给下一位存活玩家；其判定区已有闪电 → **弃置**（不绕行）。
「被无懈的闪电」在使用时窗口即被弃置，不存在进入判定区后的去向问题；
在仍有其他存活玩家的所测转移路径中，不再绕行扫描回原持有者。

### 4. 每段预算重置（长流程测试暴露的缺陷修复）

`submit`/`debug_deal_damage` 段开始时将 `resolution.budget` 重置为
`DEFAULT_BUDGET`（或 `debug_set_budget` 覆盖值）：硬预算是**每段**上限，
不跨段累计。旧语义（状态燃料全局递减）使长对局必然在合法命令上失败。
覆盖值改存引擎侧 `debug_budget`（不入状态/哈希/快照）；`resume()` 不重置
（暂停段燃料延续）。预算仍入哈希（提交态含段内剩余，确定性）。
**14 个 golden 因 budget 语义变化全量重录**（原因登记于清单维护约定）。

### 5. N06-3 身份配置矩阵与长流程测试

- `identity_matrix_for_supported_seats`：4–8 人身份人数表（对齐旧线表）、
  主公座位 0 与体力上限 +1、同种子身份分布确定；2/3/9 人通过 catch_unwind
  检查构造器 panic，尚不是外部接口返回错误的校验。
- `identity_full_match_replay_reaches_lord_side_victory`：五人 seed 321，
  每名待击杀反贼/内奸前推进 200 次阶段；再调试清手、改血和直接伤害。
  检查 `LordSide` 与最终牌区守恒；证明长流程预算与该终局路径，
  没有逐步守恒断言，也不是仅以游戏命令完成的完整对局。

## 验证（2026-09-16，`cargo test --offline -p engine-native`，共 100 passed / 0 failed）

- 机制测试 52→54：新增 N06 配置矩阵与长流程两项；闪电/延时锦囊相关 4 项
  按对齐语义重写。
- 边界/快照 41 项、场景 2 项（14 个 golden 重录后）、调试 1 项、单元 2 项
  全绿。

## 限制与后续

- 判定顺序差异（旧线「非闪电先、闪电后」分组 vs 原生「后放入先判」）已
  核对为真实差异，登记保留，对齐需改判定排序（另批处理）。
- 奖惩与终局顺序：旧线引擎层未见统一奖惩实现，原生维持奖惩先于终局，
  内容迁移时再核对。
- 固定玩法规则来源/版本及差异决策；补真实命令身份对局、逐步守恒、各阵营终局及装备惩罚断言。
- N07 分片预算失败仍会卡住（见 ADR 0707 补注），每段重置不能修复同一分片段内的失败处理。
- 先收敛上述验收，再推进 N08（实例模型与首组官方技能）、N09（新线性能基线）。
