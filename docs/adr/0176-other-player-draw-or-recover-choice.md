# ADR 0176：其他角色摸牌或回复的双层选择

## 状态

已接受（2026-07-23）。

## 背景

旧版「淑慎」在拥有者每回复一点体力后，先由拥有者选择另一名角色，再由该角色强制选择摸两张牌
或回复一点体力。已有 `choose_draw_or_recover` 只能让同一角色作选择并获得效果，已有
`choose_other_draw_by_hand_count` 则不能表达目标的第二次决策。

## 决策

Rule VM ABI 101 增加通用效果
`choose_other_draw_or_recover(player, draw_count, recover_count, times)`：

1. `times` 次目标选择彼此独立且均可取消，目标必须是另一名存活角色；
2. 选定受伤目标后，由目标本人不可取消地选择摸牌或回复；满血目标直接摸牌；
3. 两层 Choice 使用同一可序列化续体，以阶段标签和整数载荷保存参与者、次数、数值与来源技能；
4. 摸牌携带来源技能，回复继续走权威 `RecoverHp`、触发队列和确定性哈希。

## 后果

- 以后所有“我选别人、别人再选摸牌或回复”的技能复用同一能力，不增加武将专用宿主函数。
- 每次选择恢复时重新校验角色存活状态；非法、越权或不可取消的取消请求会被拒绝。
- ABI 100 主机拒绝 ABI 101 包；ABI 101 主机继续加载 ABI 3–100 的加法式内容包。
