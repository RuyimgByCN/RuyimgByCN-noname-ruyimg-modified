# ADR 0079：视为技拥有者濒死过滤器

## 决策

新增通用 `owner_dying_club` 视为牌过滤器：仅技能拥有者当前体力值不大于 0 且实体牌的有效花色为梅花时匹配。过滤器继续复用既有 `response` 窗口、来源区域、有效花色和濒死救援消耗管线。

DIY「割发」据此把一张手牌或装备区的梅花牌当【桃】自救；旧 JavaScript 只作语义证据，不进入包或运行时。旧版额外的 `special` 选牌区在新引擎中不存在，因此新引擎全部可选实体区由 `hand_equip` 完整覆盖。

## 原因

“仅自己濒死”是牌条件与拥有者状态的组合，不应写成技能 ID 特判。稳定的组合过滤器能继续服务同语义技能，并确保健康角色不能借该技能救援他人。

## 兼容性

`owner_dying_club` 沿用加法兼容的 Rule VM ABI 5，内容 Schema 保持 3；Rule IR 版本升至 7，引擎语义修订号升至 64。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
