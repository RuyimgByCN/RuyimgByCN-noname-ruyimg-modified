# ADR 0288：EXTRA 神诸葛亮、公共技能牌堆与多来源天气

## 决定

旧 JavaScript 只作为语义合同，运行时不加载或执行它。神诸葛亮重写为三个内容技能：

- `qixing` 复用现有公开扩展牌堆，开局移入牌堆顶七张牌，并在开局及摸牌阶段结束后提供
  手牌与“星”的等量交换。
- `kuangfeng`、`dawu` 复用同一选牌/选目标状态机，先弃置“星”，再向等量存活目标授予
  目标侧辅助技能。
- 临时辅助技能使用通用的来源集合状态；同一目标可同时记录多个来源，每个来源只在自己的
  下回合实际开始时从集合移除，集合为空才移除技能。
- `dawu2` 通过通用伤害取消修改器防止非雷电伤害，`kuangfeng2` 通过通用目标侧火焰伤害
  加值修改器实现。

神诸葛亮进入 EXTRA 角色闭包。npack 只包含编译后的规则模块、索引和角色数据。

## 兼容性

新增 HOST_EFFECT 210–211、`EffectRequest` 稳定哈希标签 250–251、续体标签 147–150。
Rule VM ABI 为 212，Rule IR 为 98，Engine semantics revision 为 186；内容 schema、
包格式、网络、回放与快照 schema 不变。
