# ADR 0099：全局受伤伤害光环

## 决策

为类型化 modifier 增加普通受伤阶段与最终受伤阶段的全局光环通道。查询时显式区分技能拥有者、被查询的受伤角色和另一名伤害参与者；全局光环仅从存活的技能拥有者收集，并与目标自身的 modifier 按既有稳定顺序合并。

`stdhuoshui` 使用普通受伤阶段，保持旧版 `damageBegin3` 在装备与最终修正前加伤的顺序。`jyyuhuo` 使用最终受伤阶段，保持旧版 `damageBegin4` 在普通及装备修正后按普通/属性伤害增减的顺序。失去体力不进入任一通道。

## 原因

旧 JavaScript 的全局 trigger 可以由多名存活拥有者逐个结算，并且筛选条件读取的是本次受伤者而非技能拥有者。把两者继续塞进含义模糊的 `other` 参数会在千级技能规模下增加误用风险；显式查询主体让同类光环可以复用索引、稳定排序和 explain 来源，而无需为每个技能新增事件脚本。

## 兼容性

新枚举成员只追加，不改变现有序列化序号。已有 owner-local modifier 仍只对目标自身生效；旧的另一参与者上下文接口保留。此次规则语义变化将引擎语义修订号从 83 提升到 84，Rule IR 与 Rule VM ABI 不变。
