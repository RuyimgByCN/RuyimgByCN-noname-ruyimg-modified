# ADR 0113：主动技目标的无来源用牌合法性

## 决策

主动技的 `targets` 约束新增 `can_use_on_owner <card_kind>`。它要求每个被选角色在当前权威状态下都能把指定的无来源虚拟牌用于技能拥有者；检查包括使用者存活且非濒死、按牌名的用牌禁用、手牌使用禁用、目标禁用、自身目标规则和目标数修正。首个支持的牌名为 `juedou`。

该约束只负责主动技输入合法性。真正结算继续使用通用 `use_virtual_card_on` 效果和普通用牌流水线，不为单个技能增加 Rust 旁路。包中保存可选的牌名字符串并进入逻辑哈希，旧包缺少字段时按无额外约束解释。

## 版本与兼容

该能力要求 Rule VM ABI 23、Rule IR 34、引擎语义修订 109。ABI 23 主机继续按加法兼容规则加载 ABI 3–22 包；内容 Schema、网络协议、回放 Schema、快照 Schema与包格式均不变。
