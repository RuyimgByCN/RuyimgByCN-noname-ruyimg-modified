# ADR 0286：EXTRA 神周瑜与弃牌阶段结束语义

## 决定

旧 JavaScript 只作为语义合同，神周瑜的 `yeyan`、`qinyin` 重写为 DSL 和类型化效果：

- 业炎复用限定主动技计数。发动后选择小业炎或大业炎；大业炎仅在手牌存在四种有效花色时
  可选，并在每个选择屏障恢复时重新验证实体牌、花色、目标和分配。
- 小业炎选择一至三名存活角色，各造成一点火焰伤害；大业炎弃置四种花色各一张手牌，
  选择一至两名角色，失去三点体力后按旧规则分配三点火焰伤害。
- 琴音新增精确的弃牌阶段结束事件。仅在加载对应过滤器时累计当前回合角色于弃牌阶段因
  `Discard` 原因从手牌/装备区移出的实体牌；达到两张时可取消，或令当前全部存活角色依
  座次各失去/回复一点体力。

## 兼容性

HOST_EFFECT、`EffectRequest`、事件、过滤器、续体和稳定哈希标签只在尾部追加。
Rule VM ABI 为 210，Rule IR 为 96，Engine semantics revision 为 184；
内容 schema、包格式、网络、回放与快照 schema 不变。
