# ADR 0098：伤害 modifier 显式比较双方横置状态

## 决策

追加上下文值 `owner_linked_diff_other`。在伤害意图阶段，它比较技能拥有者与另一名伤害参与者的连环标记；双方均存活且横置状态不同时贡献一，否则贡献零。

## 原因

旧版 `stdzhongshi` 在来源侧伤害生效前比较伤害来源与受伤角色的 `isLinked()`，状态不同时令伤害加一。复用既有逐目标 `damage_amount` 通道后，多目标和连环伤害均按各自参与者的当前状态计算，不需要技能名特判或临时触发状态。

## 兼容性

新 modifier 值追加在枚举末尾，既有序列化序号稳定。Rule IR 与技能 VM ABI 不变；引擎语义修订号递增到 83，未使用新值的内容包行为不变。
