# ADR 0550：ABI 626 3D精选向朗【恰化/恂恂/腹笥/拓籍】

本批按武将闭包发布向朗（`ddd_xianglang`，3804731975）、【恰化】（891363178）、临时
【恂恂】（1673829014）、【腹笥】（1632230116）、全局借牌入口（2198174483）与【拓籍】
（1700500735）。旧 JavaScript 只作语义证据，不进入 npack 或运行时。

【恰化】在其他角色回合开始时按其当前体力值精确选择此前未明置的手牌，公开后仍保留在向朗
手牌，并为当前回合角色临时授予【恂恂】。【恂恂】直接复用既有摸牌阶段观看牌堆顶四张、任意
排序为两张牌堆顶与两张牌堆底的修饰器，不建立第二套观星流程。

【腹笥】以实体牌 `face_up` 作为唯一明置事实：明置手牌不计入手牌上限，因此弃牌阶段也不会
要求弃置这些牌。全场角色获得一个不可获得的无牌来源声明入口；候选只扫描其他存活【腹笥】
拥有者的明置手牌，声明牌名必须与实体牌一致。借牌者选定实体牌后，牌主可“同意/拒绝本次”或
“本回合总是同意/拒绝”；同意后才恢复原用牌或响应 continuation，实体牌按通常使用/打出原因
离开牌主手牌。拒绝会结束本次声明，调用者可重新发起其他合法用牌。向朗自己的回合内，若其
没有未明置手牌，其他角色自身手牌来源被封锁；source-free 腹笥来源、装备和其他非手牌来源不受
影响。【拓籍】在腹笥实体牌完整结算后重新检查向朗手牌，若仍无未明置牌则询问是否摸三张。

ABI 626 增加 `resolve_ddd_xianglang(player,actor,action)`、恰化精确过滤器、`face_up` 实体牌
selector、受限 `dddfusi` source-free 成本及借牌确认/归属状态。实现复用公开手牌、标准 Choice、
临时技能、观星 modifier、既有用牌/响应 continuation 与结算尾效果；没有引入新的通用借牌框架。

验收：向朗 Golden 3/3，DDD 十个武将累计 30/30，content-compiler 522/522、engine-api 4/4、
Rule VM 10/10 与 5/5、engine-core lib 55/55、conformance 8/8，以及 31 个扩展空 store 冷导入
均通过，内容锁为 `8213277d8fd23d292e75d1324fc794fdd5cdf41a5afede75f46858856052b8a7`。

`official/ddd@0.1.0` 更新为 ABI 626，累计含 10 名武将、22 项技能、24 个模块、22 个触发、
2 项主动规则、5 项视为规则、3 项修正器和 10 项立绘资源；logic hash 为
`56d89db93507e067df1b4c8db9df269774f196068a39c966835fa64fb2c8a88e`，asset hash 为
`33e33c1376a5bad5674999c77350689c2aea6551d045dcb4f7dcd4b89a0692fe`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`b7849aa28c8157bb0ca8061fce99aef9f2dff796663021e0396f2cf1bf458030`；两份向朗立绘 SHA-256
均为 `23fc8f605564902b1f932cccf6f8e61da5c8c841421d5a406a8674b951a8a6b1`。

按架构计划 §37.10，本批门禁结束后只删除 Rust/Cargo 编译产物：外部 target 清理 8,309 个
文件（Cargo 统计 5.9 GiB）；工作区 `target/` 与外部 `/private/tmp/noname-next-cargo-target`、
`/private/tmp/noname-next-cargo-target-root` 验收时均不存在；
`.npack`、`extensions/`、立绘、许可证、源码及文档全部保留并复核哈希，防止编译缓存无限累积。

本 ADR 只证明 3D精选第十个武将闭包，不代表整个扩展迁移完成。
