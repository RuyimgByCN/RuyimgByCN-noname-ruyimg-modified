# ADR 0556：ABI 629 3D精选鲍三娘【枝连/赍剑】

本批按武将闭包发布鲍三娘（`ddd_baosanniang`，2205386058）、【枝连】
（`dddzhilian`，3056536406）与【赍剑】（`dddjijian`，887278272）。旧 JavaScript 只作
语义证据，不进入 npack 或运行时。

【枝连】在任意角色回合结束时统计本回合所有用牌或响应记录，包括已死亡或离场角色；只有记录
恰好来自两人、两人仍存活、其中一人为鲍三娘且另一人为男性时才可发动。鲍三娘可取消，或令双方
按当前回合角色座次各摸一张、各弃置一张手牌/装备牌；没有牌的一方跳过弃置。随后获得本回合进入
且结算时仍留在弃牌堆的全部普通、火、雷【杀】，因此本分支刚弃置的【杀】也可被收回。

【赍剑】出牌阶段限一次，选择一张手牌【杀】和一名其他男性角色，展示并交给目标。目标必须展示
一至两张同色手牌，候选只允许【杀】或普通锦囊；赠予的【杀】保证至少有一张合法牌。双方按当前
阶段角色座次依次选择一个仍合法的展示牌名进行虚拟使用，展示实体牌不作为消耗；同一逻辑牌名
不可重复，普通/火/雷【杀】统一占用“杀”，无合法选项时立即结束。成对目标锦囊沿用现有目标管线。

ABI 629 增加 `resolve_ddd_baosanniang`、【枝连】触发过滤器和可恢复的座次队列/已用牌名状态。
实现复用逐角色回合用牌/响应计数、进入弃牌堆实体牌历史、标准 Choice、有效颜色查询、实体赠牌
和虚拟牌合法目标结算，没有引入第二套牌史或用牌系统。

验收：鲍三娘 Golden 3/3，DDD 十三个武将累计 40/40，content-compiler 522/522、engine-api
4/4、engine-core lib 55/55、Rule VM 10/10、conformance 可执行门禁 8/8，以及 31 个扩展空 store
冷导入均通过，内容锁为 `96a3fa0300dde98f50f6bf0f69a9dadb0e369410f50640b6b3fe31ae07374d61`。

`official/ddd@0.1.0` 更新为 ABI 629，累计含 13 名武将、27 项技能、35 个模块、32 个触发、
3 项主动规则、5 项视为规则、3 项修正器和 13 项立绘资源；logic hash 为
`2d3f6b8df3aff6c0c35de92b0e5391f38736f979ea21d31b89bd53d2ef0e04d7`，asset hash 为
`978eaa09ade147528dce59ffbd7e56bfd649f56f949e6622898fcd41a083abae`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`efd8bc71cffa4803c10358bca1054900cb9b0af8113bb973d4a9ee6f8f90cecd`；两份鲍三娘立绘
SHA-256 均为 `5dee84b601191a2eea3e22b21b2601cd1dc37a2521c9590bc975881911785878`。

按架构计划 §37.10，本批门禁结束后只清理 Rust/Cargo 编译产物与增量缓存：工作区 `target/`
原本不存在，外部 target 删除 8,762 个文件（Cargo 统计 5.9 GiB）；工作区 `target/`、外部
`/private/tmp/noname-next-cargo-target` 与旧临时目录 `/private/tmp/noname-next-cargo-target-root`
验收时均不存在。冷导入临时 store 也已删除；`.npack`、`extensions/`、立绘、许可证、源码和文档
全部保留，清理规则用于防止编译产物随迁移批次无限累积，不清理发布物。

本 ADR 只证明 3D精选第十三个武将闭包，不代表整个扩展迁移完成。
