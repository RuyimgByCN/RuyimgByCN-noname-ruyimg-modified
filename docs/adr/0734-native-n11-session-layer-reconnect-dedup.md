# ADR 0734：N11 服务层续批——重连/乱序/去重会话层回归

日期：2026-09-16
状态：已实施（engine-native）
关联：[0733](0733-native-n11-auth-bytes-archive.md)、进度文档 N11

## 背景与决定

[0733](0733-native-n11-auth-bytes-archive.md) 就位的认证令牌与 NGSA 字节存档
是服务层的两块基石。本批以其组合落地服务层会话回归：
`session_layer_reconnect_out_of_order_and_dedup`——在一条测试内覆盖服务端
最常见的四类会话异常与恢复路径。

### 场景与断言（单一确定性测试）

1. **去重**：同一命令（同 dedup_id + 同修订）重复投递 → `DuplicateCommand`，
   状态哈希不变（幂等）；
2. **乱序**：持过期修订号新命令 → `StaleRevision`（乱序到达不作用于已前进
   的状态）；
3. **重连**：座位重连重签令牌 → 旧令牌 `NoSuchSession`（吊销）、新令牌通过
   会话校验；
4. **存档重连**（服务重启）：NGSA 落盘 → 解码恢复 → 状态哈希一致 →
   恢复件上旧令牌失效（会话数据不入存档）→ 重签后与不停机线执行同一
   确定性脚本（20 条命令），脚本形状与终态哈希完全一致。

### 脚本驱动器（`record_script`）

确定性命令记录器：开放选择按「牌选项优先、无牌取首选项」应答（覆盖
Confirm/弃牌/出闪/改判窗口），否则推进阶段；返回实际提交的命令序列与终态哈希，
供重启线复跑对照。会话数据（令牌/配额）不入存档的契约由 0733 锁定并在本批
回归中再次验证。

## 影响

- 测试 162 项（auth_archive 6 项），净增 1。规则版本不变（8）；golden 不变。
- N11 剩余：完整模式/内容；N12 跨进程/真机验证（存档格式已就位，
  跨进程进程对验证待做）。
