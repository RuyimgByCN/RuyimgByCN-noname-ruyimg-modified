# ADR 0110：观察者可见性修正器

## 决策

DSL 新增 `observer_foreign_hand_faces_visible override 1` 与
`observer_hidden_identities_visible override 1`。两者都是技能拥有者局部的投影权限：前者允许服务器
在拥有者的 `ObserverSnapshot` 中包含其他角色手牌的牌面，后者允许包含原本隐藏的身份。相同权限
适用于该玩家的私有回放导出；其他玩家、公开旁观、公开回放仍按公共信息投影，裁判与完整回放维持
全量可见。

权限只改变由完整权威状态派生视图的过程，不复制牌、不修改身份、不向客户端发送可执行函数，也不
进入客户端本地存储。技能卸载或失效后，下一份投影立即恢复默认裁剪。核心只识别通用 modifier，
不识别「洞察」或任何技能定义 ID。

该能力要求 Rule VM ABI 20、Rule IR 31、引擎语义修订 106。ABI 20 主机继续按加法兼容规则加载
ABI 3–19 包；内容 Schema、快照 Schema 与网络协议 5 均不变。`ModifierTarget` 新枚举项追加在末尾，
保留既有序列化序号。

## 理由

旧实现通过 `player.send(func)`、`game.me` 与 `storage.zhibi` 在客户端特判可见信息，这既无法由服务器
审计，也容易向旁观者或其他玩家泄露隐藏状态。把“谁能看见什么”收口到服务器投影层后，后续上千
技能只声明权限差异，扩展包仍可独立安装，所有网络和回放出口则共享同一隐私边界。
