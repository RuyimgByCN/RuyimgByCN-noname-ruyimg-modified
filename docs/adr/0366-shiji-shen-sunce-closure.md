# ADR 0366：SHIJI 神孙策既有三技能闭包

本批发布 SHIJI 神孙策（`shen_sunce`，2662599370）。其三个技能「英霸」
（`yingba`）、「覆海」（`scfuhai`）和「冯河」（`pinghe`）均已完成 DSL 重写，旧
JavaScript 仅作为角色数据语义来源，不进入运行时。

## 决策

- 直接复用既有三个技能定义，不新增原语或 ABI。
- 保留旧角色的 6 点体力上限与 1 点初始体力，势力为 `shen`。
- 将角色加入 SHIJI 包并同步 `extensions/shiji/`。

## 验证

黄金测试解析生成包，校验角色定义、初始/上限体力和三个技能 ID 的完整闭包。
