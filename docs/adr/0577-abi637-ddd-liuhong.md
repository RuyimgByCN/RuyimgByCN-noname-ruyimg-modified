# ADR 0577：ABI 637 3D精选刘宏【失兴/党锢/覆宗】

本批按武将闭包发布刘宏（`ddd_liuhong`，425801473）与【失兴】（`dddshixing`，42478118）、
【党锢】（`ddddanggu`，1734030406）、【覆宗】（`dddfuzong`，1289813886）。旧 JavaScript
只作语义证据，不进入 npack 或运行时。

【失兴】按场上是否存在未受伤女性与当前回合是否已使用锦囊牌，动态授予现有【享乐】、
【酒诗】或【制衡】技能定义，只移除本技能自身授予的实例。【党锢】在结束阶段选择任意名
未连环角色，至少补足至存活群势力人数；其他已连环角色的弃牌阶段把装备区计入超限弃牌。
【覆宗】开局按存活群势力人数摸牌；群势力角色死亡时，由死者从刘宏手牌或装备区强制选择
并弃置一张牌，死亡选择者仍可完成可恢复 Choice。

复用审计发现原 `yijiang`【酒诗】仍是“手牌【酒】当【酒】”近似，会使【失兴】的动态授予
名义正确但行为错误。本批在同一 ABI 修复根实现：正面朝上时翻面并使用一张无实体牌【酒】，
背面朝上受到伤害后可选择翻回；曹植显式引用两个运行时子技能，普通持有与动态授予共用同一
实现。未增加第二套兼容层。

验收：刘宏与继承【酒诗】Golden 4/4、content-compiler 528/528、engine-api 4/4、engine-core
lib 55/55、Rule VM 单元 10/10 与集成 5/5、conformance 3/3、31 个扩展空 store 冷导入均
通过；最终内容锁为 `74c76b69465349e8d118b459685698213f6e732a4690ca8eb57e58decdbc0050`。

`b6148b8525e7119bf4b10b2097c05272ae2bb6d85faa1ef9056dc2a9d70a205d`；两份刘宏立绘 SHA-256
