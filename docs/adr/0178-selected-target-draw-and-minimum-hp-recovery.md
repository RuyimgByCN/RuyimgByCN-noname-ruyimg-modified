# ADR 0178：主动目标列表摸牌与结算时最低体力回复

## 状态

已接受（2026-07-23）。

## 背景

旧版「雄异」在出牌阶段选择一至任意名角色，令这些角色各摸三张牌；所有摸牌完成后，若技能
拥有者的体力值为全场最低则回复一点体力。已有固定双目标摸牌效果不能消费可变长度的主动技目标
列表；在 VM 查询最低体力又会把判断提前到效果真正执行之前。

## 决策

Rule VM ABI 103 增加两项通用能力：

1. `draw_selected_targets(count)` 只允许用于声明了至少一个目标的主动技；VM 从权威主动技命令
   捕获目标列表，引擎重验目标互异且存活后按座次逐一摸牌；
2. `recover_if_min_current_hp(player, amount)` 在效果实际执行时读取所有存活角色的当前体力，
   仅当 `player` 并列最低时走普通回复流程；
3. 摸牌请求携带来源技能，继续进入既有 CardsDrawn、嵌套触发、确定性队列与状态散列；
4. `once_per_game`、目标数量、目标存活与目标互异继续由主动技运行时权威校验，不在技能专用
   Rust 分支重复实现。

## 后果

- 以后所有“对本次主动技已选目标统一执行摸牌”和“效果结算时按最低体力条件回复”的技能可
  复用同一能力。
- 旧 JavaScript 只作为语义合同，不进入 npack、回放、网络协议或运行时。
- ABI 102 主机拒绝 ABI 103 包；ABI 103 主机继续加载 ABI 3–102 的加法式内容包。
