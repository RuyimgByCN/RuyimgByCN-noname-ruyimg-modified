# ADR 0130：弃牌成本后按装备槽获得目标装备

## 决策

Rule VM ABI 40 增加通用类型化效果：

```text
choose_discard_one_then_gain_target_equipment(player, target, slot)
```

`slot` 使用稳定装备槽标签（武器、防具、防御坐骑、进攻坐骑、宝物）。效果向 `player`
开放一次可取消的手牌/装备牌选择；取消时无事发生。选择后在同一事务内重新验证并弃置成本，
随后重新读取 `target` 的装备区，将该槽仍存在的全部装备移入 `player` 手牌。

## 原因

旧版「夺刀」把弃牌选择本身作为是否发动技能的决定，且获得武器发生在成本支付之后。把现有
“强制弃一张”和普通移动效果直接串联，会引入额外确认框，并可能在取消、伪造选择或状态变化时
错误获得装备。复合类型化效果把选择屏障、成本和后续获得绑定在一个可回滚事务中，同时可复用于
后续按防具、坐骑或宝物槽结算的技能。

## 版本

- Rule VM ABI：40
- Rule IR：51
- Engine semantics：126
