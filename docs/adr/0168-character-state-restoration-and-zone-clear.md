# ADR 0168：武将牌状态复原与角色区域清空

## 状态

已接受（2026-07-23）。

## 背景

旧版「涅槃」在濒死时执行两类此前 DSL 无法精确表达的通用操作：

- 强制弃置拥有者手牌、装备区和判定区的全部牌；
- 将武将牌复原为未横置且正面朝上，而不是无条件切换翻面状态。

直接复用 `discard_all_hand_and_equip` 会漏掉判定区；直接复用 `turn_over` 会把已经正面朝上的
角色错误翻至背面。为单个技能增加专用宿主函数也不利于后续数千技能迁移。

## 决策

Rule VM ABI 93 增加两个可组合的通用效果：

- `discard_all_hand_equip_judge(player)`：强制将指定存活角色手牌、装备区和判定区的全部实体牌
  移至弃牌堆，不受“选择可弃置牌”过滤影响；
- `restore_character_state(player)`：若角色横置则解除横置，若角色背面朝上则翻回正面；已经正常
  的状态保持不变。

两者分别映射到稳定的 HOST_EFFECT 标签与 `EffectRequest` 变体。区域移动、标记变化和翻面变化
继续走现有事务、领域事件、触发调度和 canonical hash 路径。

旧版「涅槃」只用声明式组合表达：限定技消耗、区域清空、状态复原、摸三张和回复至三点。archive
中的 JavaScript 只作为语义证据，不进入运行时或 npack。

## 后果

- 后续具有“弃置区域内所有牌”或“复原武将牌”语义的技能可直接复用，无需专用硬编码。
- 旧的 `discard_all_hand_and_equip` 与 `turn_over` 语义保持不变，避免破坏已迁移技能。
- ABI 92 主机拒绝加载使用这些效果的 ABI 93 内容包；ABI 93 主机继续兼容旧的加法式内容包。
