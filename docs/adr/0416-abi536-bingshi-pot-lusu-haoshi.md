# ADR 0416：ABI 536 兵势鲁肃「好施」

本批将旧 JavaScript 中的兵势鲁肃「好施」（`pothaoshi`，3050076876）重写为
DSL/Rust 规则，与已完成的「缔盟」一起发布完整武将；旧 JavaScript 只作语义证据，
不进入运行时。

## 决策

- 把授权收敛在通用「可用手牌」查询：被授权角色可以正常使用、打出授权者手牌，
  view-as、救濒和无懈响应复用同一来源校验，不为单张牌绕过权威管线。
- 授权状态保存在好施技能实例中：同一目标再次授权重置为两次，额外结束阶段可与
  其他目标并存，拥有者下个回合开始统一清除。
- 借牌移出导致授权者失去最后手牌时，在用牌/响应事件前消耗一次配额并补至三张；
  同一次复合转化仅结算一次。
- 授权者的手牌牌面仅向被授权角色投影，其他观察者继续只见隐藏手牌。

## 验证

- Golden 覆盖借用手牌、借【闪】响应、两次空手补至三张、第三次不再补牌、
  授权视图和下回合清理；兵势 21 个测试二进制共 68 项全部通过。
- content-compiler 475/475、engine-api 4/4、rule-vm 10+5、conformance 8/8 全部通过。
- `bingshi.npack.json` 为 ABI 536、22 名武将、51 项技能，logic hash
  `742241ab1b100e120a247bdec088c5594b5e439a0d55a5a9d0309bcaf6abca91`，SHA-256
  `7afedabf2a16d6d75509dad917b56710129cdf5e844fe2e0199e0bbfc4b4520e`；三份包已同步且不包含 JavaScript。
- 完整 `extensions/` 冷导入激活 26 个包，ContentLock
  `004a430125b57ea02ca5b8676e618b877b830fcc2b2e600fb8df5eaa19682438`。
- 编译使用独立外部 target，门禁后按架构计划 §37.10 删除外部 target 和工作区 `target/`。
