# ADR 0046：弃置全部手牌与装备牌契约

- 状态：已接受
- Engine semantics：30

## 背景

「挥泪」要求击杀者一次性弃置手牌区和装备区中的全部牌。既有原语只能弃置固定数量手牌，或让角色从两个区域中选择一张，不能完整表达旧 JS 的 `discard(getCards("he"))`。

## 决策

- DSL 新增通用效果 `discard_all_hand_and_equip(player)`；
- 效果按稳定区域与牌序将指定角色手牌区、装备区的全部牌移入弃牌堆；两个区域均为空时无操作；
- 复用既有显式弃牌校验和移动事件，不增加技能名分支或选择流程；
- 新效果追加到 IR、VM 与类型化效果协议尾部，保持既有序列化序号稳定。

## 结果

「挥泪」及后续同类技能可直接声明一次性全弃效果，服务端权威执行并产生统一的移动事件。
