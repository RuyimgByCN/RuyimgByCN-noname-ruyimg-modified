# ADR 0094：伤害双方翻面状态比较值

## 决策

为现有伤害 modifier 增加通用上下文值 `owner_turned_over_diff_other`。来源侧 `damage_amount` 的 `other` 是受伤角色，受伤侧 `damage_taken_amount` 的 `other` 是伤害来源；任一方不存在或已死亡时贡献为零，否则双方翻面状态不同时贡献一。

## 原因

旧版 `lxzhuixi` 分别在造成伤害与受到伤害的时点比较伤害双方的翻面状态并令伤害加一。现有来源侧、受伤侧 modifier 管线已经提供另一端角色上下文，复用该管线可以保留双方都拥有技能时分别叠加的行为，也无需新增修改当前伤害事件的技能专用宿主效果。

## 兼容性

新枚举项追加在末尾以保持既有序列化序号稳定。引擎语义修订号递增到 79；未使用新值的内容包行为不变。
