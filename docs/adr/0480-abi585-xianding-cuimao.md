## 决策

旧 JavaScript 只作语义合同，不进入内容包或运行时。XIANDING 崔琰毛玠按上游元数据发布为魏势力、
3 体力，技能为【征辟】与【奉迎】。

【征辟】在出牌阶段开始可选择一名其他角色并选择一项：其本阶段获得牌后，阶段结束时拥有者获得
其手牌区与装备区各一张可获得的牌；或立即交给其一张基本手牌，随后其交回一张非基本手牌/装备牌，
或交回两张基本手牌，无法支付时交出全部手牌。阶段结束会消费挂起目标，避免状态跨阶段残留。

【奉迎】为限定技，拥有者弃置全部手牌（零张也可）并在当前回合后获得一个额外回合；该额外回合
开始时，若其体力值并列全场最少，则把手牌摸至体力上限。一次性辅助技能只标记本技能新排入的
额外回合，不会误命中队列中更早的同角色额外回合。

ABI 585 新增 `resolve_zhengbi(player, target, action)` 与
`resolve_fengying(player, helper_def, action)` 两段通用结算状态机，复用既有出牌阶段获牌历史、
实体牌选择/赠予、移动后的延迟恢复、额外回合队列和辅助技能状态。
