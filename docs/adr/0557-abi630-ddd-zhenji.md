# ADR 0557：ABI 630 3D精选甄宓【淼形/浮世】

本批按武将闭包发布甄宓（`ddd_zhenji`，1560511018）、锁定技【淼形】
（`dddmiaoxing`，505834181）、两组水相区域定义（919529013、2949101455）与【浮世】
（`dddfushi`，1483827339）。旧 JavaScript 只作语义证据，不进入 npack 或运行时。

【淼形】把起始手牌数量乘三，而非开局后额外摸牌。开局时按当前手牌顺序以三分之一向上取整
切组，甄宓保留一组，其余两组依次暗置为水相一、水相二。摸牌阶段结束后，数量与当前手牌数
不同的水相成为候选；两组都不等时至少选择一组，只有一组不等时允许取消。选中水相不足则从
牌堆顶补足，超出则由甄宓精确选择超出数量弃置，按一、二顺序结算。

【浮世】每回合限一次，在甄宓使用的基本牌完整结算后或以基本牌响应后可发动。发动后必须选择
一组可交换水相，将甄宓全部手牌与该水相完整交换；随后可选择一名存活男性角色，该角色可取消，
或选择任一可交换水相，将其全部手牌与该水相完整交换。水相始终对非拥有者保持暗置。

ABI 630 增加 `resolve_ddd_zhenji(player,target,action,stage,piles,cards)`、浮世精确触发过滤器及
可恢复自定义 Choice。实现复用起始手牌修正器、标准技能牌堆、实体移牌、牌堆补牌和事务续体；
同时补齐编译器已经由运行时和 LSP 支持但白名单遗漏的 `multiply` modifier 模式。

验收：甄宓 Golden 3/3，DDD 十四个武将累计 43/43，content-compiler 522/522、engine-api
4/4、engine-core lib 55/55、Rule VM 单元 10/10 与集成 5/5、conformance 测试及可执行门禁均
通过，31 个扩展空 store 冷导入通过，内容锁为
`07cac8ed19c5848ff1730aeca98959b9f8f7581e1bcb4daf497af189c6b0b148`。

`official/ddd@0.1.0` 更新为 ABI 630，累计含 14 名武将、31 项技能、39 个模块、36 个触发、
3 项主动规则、5 项视为规则、4 项修正器和 14 项立绘资源；logic hash 为
`ba4fb663347f75c482d60ee414d30f6fea5af277d6ae36e2a13439945e78f482`，asset hash 为
`99ed4610b375db0cd5532ba43f16a47023f58a8859646a03f1261ddf3d927a39`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`2c028ce8e39ef3ff93f8293eaba4a7b7cfb429d989cd5f3c0d039658a3a125fe`；两份甄宓立绘
SHA-256 均为 `e30d596a53751f9e7d43a9572e3e560e29bd078862f17b1dc3fa4b5a97bacdac`。

按架构计划 §37.10，本批门禁结束后只清理 Rust/Cargo 编译产物与增量缓存：工作区 `target/`
原本不存在，外部 `/private/tmp/noname-next-cargo-target` 删除 7,159 个文件（Cargo 统计 4.9 GiB）。
工作区 `target/`、外部 target 与旧临时目录验收时均不存在；`.npack`、扩展、立绘、许可证、源码
和文档全部保留，避免编译产物随迁移批次无限累积。

本 ADR 只证明 3D精选第十四个武将闭包，不代表整个扩展迁移完成。
