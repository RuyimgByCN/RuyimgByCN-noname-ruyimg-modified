# ADR 0166：多人濒死救援队列与回合拥有者的【桃】限制

## 决策

引擎濒死流程改为可序列化的多人救援队列。队列优先从当前回合角色开始；若其无效，则依次回退到
伤害来源、濒死角色和首个存活座位，再按顺时针座次询问所有存活角色。普通角色只能用【桃】救援，
濒死角色本人还可以使用【酒】；没有合法救援来源的角色直接跳过。一次救援只回复一点体力，若仍未
脱离濒死，同一救援者可继续使用下一张牌；其放弃后才轮到下一人。全部角色放弃或无牌后死亡。

Rule VM ABI 91 同时增加通用 modifier
`tao_use_save_cancel_for_non_dying_others_during_owner_turn`。在 modifier 拥有者的当前回合内，其他
角色不能主动使用【桃】，也不能用【桃】救援；回合拥有者本人及当前被救的濒死角色不受救援限制，
处于濒死状态的角色仍保留主动自救入口。

## 原因

旧「完杀」的全局 `cardEnabled` / `cardSavable` 语义作用于每一名救援者。此前引擎只询问濒死者本人，
即使增加一个禁桃 modifier，也无法表达“阻止第三者救人”，更无法证明旧技能语义等价。旧 `_save`
流程还允许同一角色连续使用多张【桃】，因此不能用“一张牌直接回复到一点体力”的简化替代。

## 结果

- 濒死救援者、剩余座次和被中断的牌/技能 continuation 都进入权威状态、状态哈希与录像。
- 「完杀」仅由声明式 modifier 表达，不按技能 ID 修改救援队列。
- Golden 覆盖从当前回合角色开始、多人接力、每张牌回复一点、完杀跳过非濒死第三者，以及拥有者和
  濒死者例外。
- 「乱武」造成的失去体力可以在救援完成或死亡后恢复其剩余角色队列，贾诩技能闭包由此完成。
