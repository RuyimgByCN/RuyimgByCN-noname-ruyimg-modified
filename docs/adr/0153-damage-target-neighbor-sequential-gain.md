# ADR 0153：伤害目标与上下家的顺序获得续体

## 决策

Rule VM ABI 63 增加
`draw_then_choose_gain_one_from_damage_target_and_neighbors(player, target)`，只允许 `damage`
触发器调用。引擎先摸一张牌，并在摸牌及嵌套触发结束后计算旧版顺序：受伤角色、其上家、其下家。

该顺序是可序列化快照，故二人局重复的上下家不会去重。每项实时检查角色与可获得牌；遇到技能
拥有者时只允许选择装备。一次选择产生的移动和嵌套移动触发全部结束后，才恢复下一项。

## 原因

旧实现依赖多个 `await` 和运行时座次查询。把它压成一次批量移动会改变摸牌触发、移牌触发、死亡
和二人局重复座次的可观察顺序；执行旧 JavaScript 又违反确定性内容边界。显式续体保留旧语义，
同时让选择、快照校验、回放和 Native/WASM 哈希保持一致。

## 边界

核心只实现通用的伤害目标邻座顺序与逐项获得语义，不识别「突袭」、欧陆张辽或 OFFLINE 包。
