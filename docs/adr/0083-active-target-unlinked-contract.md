# ADR 0083：主动技未横置目标约束

## 决策

为主动技目标声明增加通用 `unlinked` 约束：

```text
active play_phase targets 1 1 other unlinked { ... }
```

该字段由 DSL 解析进入 `ActiveTargetsIr` 和包内 `PackageTargetSpec`，并在主动技 VM 执行前由权威引擎校验。目标持有正数连环标记时，发动命令直接拒绝。

限定「断绁」据此重写：每回合限一次、恰好选择一名未横置的其他角色，再复用现有标记效果把目标与拥有者设置为横置。旧 JavaScript 只用于核对继承后的目标过滤、次数与结算顺序，不进入内容包或运行时。

## 原因

旧 `duanxie` 的 `filterTarget` 明确排除已横置角色；只声明 `other` 会错误接受已横置目标并继续横置拥有者。目标合法性属于命令入口的公共规则，不能依赖技能体事后补救，也不能为单技能增加 Rust 分支。

`unlinked` 是可组合的目标契约，后续技能可与人数、`other`、`lowest_hp` 等现有约束共同使用。横置结果继续复用现有连环标记，不新增效果类型或 VM 指令。

## 兼容性

包字段反序列化缺省为 `false`，既有包语义不变。没有新增 VM 指令或宿主效果，Rule VM ABI 维持 5，内容 Schema 维持 3；Rule IR 版本升至 11，引擎语义修订号升至 68。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
