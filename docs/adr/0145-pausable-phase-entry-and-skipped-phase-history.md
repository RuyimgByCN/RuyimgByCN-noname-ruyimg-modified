# ADR 0145：可暂停阶段入口与规范跳阶段历史

## 决策

旧版 JavaScript 只作为技能语义证据，不进入内容包，也不在运行时执行。引擎为摸牌阶段入口增加
可序列化续体：阶段开始触发因可选选择而暂停时保存“继续已进入的摸牌阶段”；拒绝触发后恢复普通
摸牌，技能已跳过阶段时恢复为幂等空操作。阶段机不依赖具体技能 ID。

所有规则来源造成的判定、摸牌、出牌和弃牌阶段跳过统一写入 `PhaseSkipped` 领域事件，并累加当前
回合的规范跳阶段计数；新回合开始时清零。`skip_current_phase` 只允许当前存活角色跳过正在进行的
摸牌、出牌或弃牌阶段，并复用同一阶段推进路径，包括回合开始时的额外出牌阶段。

`choose_other_targets_by_skipped_phase_count_damage` 只在当前角色的结束阶段开放强制多目标选择；目标
上限取本回合规范跳阶段计数，并在选择恢复时重新验证阶段、来源技能、数量、去重、存活和排除自身。
合法目标按客户端提交的确定顺序逐一造成伤害。声明式过滤器提供包含并列的全场最大手牌、最大当前
体力和最大非空装备数判断，以及跳阶段计数大于零判断。它们只比较存活角色；装备判断要求拥有者
至少有一件装备。核心不识别「奋励」「平寇」或朱桓。

## 兼容性

`EffectRequest`、`ContinuationKind`、触发过滤器、Rule IR 语句和 VM host effect tag 均只在末尾追加，
保留已有序列化序号。Rule VM ABI 升至 55，Rule IR 升至 66，Engine Semantics 升至 141。旧包不获得
新能力，仍按其原最低 ABI 加载。
