# ADR 0358：ABI 495 矜伐复合结算

## 决策

新增通用效果 `resolve_gzjinfa(player, target)`，由 VM 捕获主动技所选成本牌；引擎先通过
标准弃牌管线支付成本，再让目标选择交出一张装备牌或取消。取消时拥有者从目标可获得的
手牌/装备牌中选择一张；交出装备按目标视角为黑桃时，复用无距离虚拟【杀】管线，且不
受目标与响应合法性约束；因目标在他人回合被强制使用，绕过其出牌阶段次数计数。

## 理由

旧 JavaScript 的两个选择和嵌套移牌触发必须串行完成。单一最小状态机保留这些结算边界，
同时复用现有实体牌移动、可获得牌校验、公开牌与虚拟牌规则，不引入技能专属运行时。
