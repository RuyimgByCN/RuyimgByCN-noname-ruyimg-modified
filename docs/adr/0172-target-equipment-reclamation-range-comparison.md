# ADR 0172：目标装备收回与移动后攻击范围比较

## 状态

已接受（2026-07-23）。

## 背景

旧版「安国」在出牌阶段限一次：选择另一名角色装备区的一张牌，令该角色获得此牌；若该角色攻击
范围内的角色数因此减少，技能拥有者摸一张牌。把这段 JavaScript 原样作为扩展执行会绕过确定性
命令、Choice 屏障、快照和包 ABI；只在移动前推断装备类型也不正确，因为普通移牌事件的嵌套触发
可能在结算过程中再次改变装备或距离。

## 决策

Rule VM ABI 97 增加主动目标约束 `has_equip` 和
`choose_target_reclaim_equipment_draw_if_range_reduced(player, target, self_skill)`：

1. 编译器只允许该效果出现在精确声明 `targets 1 1 other has_equip` 的主动技中；
2. 命令层在发动时验证目标存活、不是拥有者且装备区非空；
3. 宿主打开不可取消的装备牌 Choice，并保存拥有者、目标、技能实例和确定排序的实体牌候选；
4. Choice 恢复时重新校验技能、目标和实体牌，并在移动前记录目标攻击范围内的存活角色数；
5. 所选装备通过普通移牌流程进入目标自己的手牌；移动及其嵌套触发完成后，延后效果重新计算该
   数量，只有新值更小时才令技能拥有者摸一张牌；
6. 选择、提交和移动后比较均使用通用类型化请求、序列化续体和确定性哈希。

OLD 包中的旧朱治只引用 YIJIANG 包的稳定「安国」技能 ID，不复制实现。archive JavaScript 只
保留为语义合同，不进入 DSL 包或运行时。

## 后果

- 非武器装备或未实际降低攻击范围时不会误摸牌。
- 目标装备在 Choice 等待期间离开装备区会原子拒绝，不消费过期选择产生的移动。
- 移牌触发导致的二次装备或距离变化会在最终比较中体现。
- ABI 96 主机拒绝 ABI 97 包；ABI 97 主机继续加载旧的加法式内容包。
