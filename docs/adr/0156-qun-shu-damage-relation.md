# ADR 0156：伤害参与者势力条件作为 modifier value source

## 决策

ABI 81 增加 `owner_qun_other_shu` 查询时值源。它仅在技能拥有者是存活群势力角色，且当前伤害的另一参与者是存活蜀势力角色时返回 1，否则返回 0。

旧版 OFFLINE「惑乱」用同一个条件分别挂在 `damage_amount` 与 `damage_taken_amount`，覆盖拥有者造成及受到伤害两个方向。实现不执行旧 JavaScript，也不为技能定义 ID增加 Rust 特判。

## 原因

伤害 modifier 已经把“另一伤害参与者”作为通用查询上下文，用同一值源组合两个既有通道，比新增技能专用触发器、状态或效果更小，也保持伤害准备阶段的统一结算顺序。

## 验证

Golden 覆盖群到蜀、蜀到群、群到魏、魏到群，以及完全不涉及技能拥有者的伤害。
