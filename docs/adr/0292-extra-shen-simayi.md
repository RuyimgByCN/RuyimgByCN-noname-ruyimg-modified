# ADR 0292：EXTRA 神司马懿

神司马懿只迁移旧 JS 的规则语义；运行时不加载、执行或打包旧 JS。

- 忍戒使用稳定标记 `3085167840`；弃牌阶段计数复用回合状态。
- 拜印由 DSL 完成减体力上限、授予极略五分支并移除自身。
- 鬼才复用判定改写窗口，仅增加“消耗一枚指定标记”的通用修正器。
- 放逐复用现有选人、摸已损失体力牌并翻面效果。
- 集智、制衡、完杀共用一个带模式的确定性宿主效果；选择结果仍由 continuation 验证。
- 连破复用统一回合结束出口。额外回合以队列插入，并保留原回合锚点，结束后继续原顺序。
- 当前回合角色死亡不再直接切换下家；死亡触发结算后先发布 `TurnEnded`，再执行额外回合或正常推进。

版本：Rule VM ABI 218、Rule IR 102、引擎语义 190。
