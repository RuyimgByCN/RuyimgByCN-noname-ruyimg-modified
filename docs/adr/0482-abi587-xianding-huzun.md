## 决策

旧 JavaScript 只作语义合同，不进入内容包或运行时。XIANDING 胡遵按上游元数据发布为魏势力、
4 体力，技能为【斩涛】与【安境】。

【斩涛】在自己受到伤害，或攻击范围内角色受到伤害后，若伤害牌有点数且伤害来源不是自己，
可判定。普通实体牌以其点数为阈值；转化牌以全部实体材料的点数和为阈值。判定点数更大时，
按普通距离规则、但不计次数地视为对伤害来源使用【杀】；判定完成后重新验证来源存活和目标合法性。

【安境】每回合限一次，在自己造成伤害后可发动。整局第 X 次发动时可选择一至 X 名受伤角色，
按从当前回合角色开始的座次顺序各摸一张牌，再由权威 RNG 在其中当前体力值最小的角色里随机
选择一名回复 1 点体力。发动次数保存在技能实例状态中，不依赖旧 JS 事件对象。

ABI 587 新增 `resolve_huzun` 和两个精确触发过滤器。逻辑牌结算记录统一保存全部实体材料，
`CardUsed`、目标和伤害触发共享该来源，补齐【析察】及后续转化牌技能的公共语义；新效果请求的
全部参数进入确定性状态哈希。虚拟【杀】继续复用既有处理区分配和完整用牌管线。
