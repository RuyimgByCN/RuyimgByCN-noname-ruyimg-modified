# ADR 0024: 濒死者以桃或酒自救

- 状态：接受
- 日期：2026-07-14

## 决策

濒死自救窗口按有效牌名依次寻找【桃】、【酒】，并在救援成功时消耗实际牌。`card_save_cancel(selector)` 支持 `tao` 与 `jiu`，救援合法性按具体牌种查询；全局救援禁用和手牌使用/响应禁用仍优先生效。

MOBILE `tiansuan2_4` 组合普通伤害值 `+1`、【桃】/【酒】使用禁令和两种自救禁令，完整表达旧 `cardEnabled` 与 `cardSavable` 规则。

## 兼容性

该修正补齐标准规则中濒死者可用【酒】自救的基础语义，并令不存在合法救援牌时只提供死亡选项。`EngineSemanticsId` 从修订 7 升至 8；Native 与浏览器 WASM 哈希必须重新一致通过。
