# ADR 0565：ABI 633 3D精选蹇硕【分野/逝潮】

本批按武将闭包发布蹇硕（`ddd_jianshuo`，3486489097）与【分野】（`dddfenye`，
1190748172）、【逝潮】（`dddshichao`，219219058）。旧 JavaScript 只作语义证据，不进入
npack 或运行时。

【分野】在出牌阶段限一次选择一名可拼点的其他角色。双方强制各选一张手牌，其余存活且有
手牌的角色依蹇硕起始座次顺序可加入任一方并扣置一张手牌；全部选择通过可恢复 Custom Choice
冻结。结算时统一公开并弃置实体拼点牌，以整数交叉相乘精确比较两方点数均值，不使用浮点数。
严格胜方依座次各可对一名尚未被选择、当前满足共享【杀】目标规则的败方使用一张无距离且不计
次数的虚拟【杀】；平局无胜方且不使用【杀】。

【逝潮】准备阶段清除上一目标，按技能标记加一得到名次 N，选择手牌数为全场第 N 个不同降序
档位的角色；不同档位不足 N 时选择最少档。蹇硕把手牌调整至该角色手牌数且不超过存活主公的
体力上限，并记录该角色至下次准备阶段。其间该角色对蹇硕造成伤害时，可在当前伤害窗口防止
该伤害；成功防止后逝潮标记永久加一。

ABI 633 增加 `resolve_ddd_jianshuo(player,target,action)` 及对应可恢复 Choice。实现复用实体
牌移动、有效点数查询、座次顺序、虚拟【杀】合法性与完整结算、主公身份、手牌调整和当前伤害
防止管线，不引入第二套拼点或扩展加载器。

验收：【分野/逝潮】Golden 2/2、content-compiler 523/523、engine-api 4/4、engine-core lib
55/55、Rule VM 单元 10/10 与集成 5/5、conformance 8/8、31 个扩展空 store 冷导入均通过；
内容锁为 `0d0c44388de572c7edce82b9c9e4fe10b68fb386ccb1216d954863707b99a133`。

`official/ddd@0.1.0` 更新为 ABI 633，累计含 17 名武将、37 项技能、49 个模块、44 个触发、
5 项主动规则、5 项视为规则、4 项修正器和 17 项立绘资源；logic hash 为
`0683cac85bb8c1b6674920bf5173e352b3d83c09eda82619c6dfc9af7bcf9718`，asset hash 为
`d9a94c6d76c0ea1e4b9ef9c68f0442a2c8e16b1d6f63b2a1223ecb61d5312a3d`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`04d39597c7926b9a67ef1776a7920746edaba847fa92aa8726e39b516d7151f0`；两份蹇硕立绘 SHA-256
均为 `2e447632cd6506f72f66380d233690a4fb69a96e66771fc474eb98690b281ecc`。

编译产物按架构计划 §37.10 在本批门禁结束后清理；`.npack`、扩展、立绘、许可证、源码和
文档属于交付物并保留。本 ADR 只证明 3D精选第十七个武将闭包，不代表整个扩展迁移完成。
