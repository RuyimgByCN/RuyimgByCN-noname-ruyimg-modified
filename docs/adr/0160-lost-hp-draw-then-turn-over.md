# ADR 0160：按拥有者已损失体力摸牌后翻面

## 决策

ABI 85 增加触发过滤器 `owner_is_target_other_alive`：拥有者必须是事件角色，且至少还有一名其他
存活角色。DSL 同时增加 `choose_other_draw_owner_lost_hp_turn_over(player)`，由拥有者强制选择一名
其他存活角色；选择恢复时重新计算拥有者当前已损失体力，目标先摸等量牌，再翻面。

## 原因

旧版 `fangzhu` 在伤害结束后选择其他角色，并在实际内容结算时调用 `getDamagedHp()`，因此补牌数
不能在触发入队时固化。把目标选择、动态计数和有序后续效果封装为通用 continuation，可保持等待
期间的状态变化与嵌套触发语义，同时避免按技能 ID 写宿主分支。

## 结果

- 旧 JavaScript 只作为语义规格，不进入运行时。
- 无其他存活角色时不会出现无效的可选发动提示。
- 选择恢复时会拒绝自己或已经死亡的目标，并按拥有者最新体力状态计算摸牌数。
- 摸牌及其触发链完成后才执行翻面，结算顺序与旧定义一致。
