# ADR 0078：视为技基本牌类别过滤器

## 决策

新增通用 `card_basic` 视为牌过滤器，按技能拥有者视角的有效牌名判断实体牌是否属于基本牌。主动使用、普通响应和濒死救援继续复用既有 `view_as` 窗口、来源区域及实体牌消耗管线。

SP「战杀」「战桃」「战酒」据此把一张手牌中的基本牌分别当【杀】【桃】【酒】使用或打出；旧 JavaScript 只作语义证据，不进入包或运行时。

## 原因

三个旧技能共享同一类别条件。一个稳定类别过滤器比复制三个技能 ID 分支更适合后续上千技能迁移，也保持有效牌名修正与视为技过滤的一致性。

## 兼容性

`card_basic` 沿用加法兼容的 Rule VM ABI 5，内容 Schema 保持 3；Rule IR 版本升至 6，引擎语义修订号升至 63。既有 ABI 3/4/5 包仍可由 ABI 5 主机加载。
