# ADR 0182：按使用者与目标体力比较的目标保护

## 背景

旧「卯兔」在任意角色脱离濒死后，为拥有者添加持续到下个回合开始的临时技能。期间，体力值
大于等于拥有者的其他角色不能对其使用牌。旧实现把阶段生命周期和 `targetEnabled` 回调保存在
JavaScript 技能对象中，不能直接进入确定性运行时。

## 决策

- 追加目标侧修正器 `card_target_cancel_if_other_user_hp_gte_target`。
- 每次目标合法性查询都读取牌的使用者与修正器拥有者的当前体力；仅当两者不同且使用者体力不低于
  拥有者时应用取消目标修正。
- 「卯兔」监听现有 `dying_after`，为拥有者添加稳定 ID 的辅助技能。
- 辅助技能监听拥有者的 `phase_begin` 并移除自身，表达“直到下个回合开始”的生命周期。

## 兼容性

Rule VM ABI 从 106 提升到 107，Engine Semantics 从 153 提升到 154。`ModifierTarget` 变体只在
枚举末尾追加；Rule IR 保持 76，内容 schema、包格式、协议和快照 schema 不变。ABI 107 主机
继续加载 ABI 3–106 内容包；使用新修正器的包必须声明 ABI 107。

## 结果

目标保护随双方体力变化即时更新，可供后续类似技能复用；不新增角色专用 Host 效果，也不保存
旧 JavaScript 阶段或临时技能对象。COLLAB npack 可独立发布完整卯兔闭包。
