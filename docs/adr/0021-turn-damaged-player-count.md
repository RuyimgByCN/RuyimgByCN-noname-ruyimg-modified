# ADR 0021: 回合内受伤角色去重计数

- 状态：接受
- 日期：2026-07-14

## 决策

回合状态以一个位图记录本回合受到过实际伤害的角色；引擎固定支持 2–8 人，因此位图存入现有确定性回合标志即可。失去体力不计入，角色死亡后其位仍保留，到下一名角色的回合开始时清空。

DSL 仅在 `phase_end` 触发器中暴露 `turn_damaged_player_count`。它与伤害值、卡牌目标数在事件类型上互斥，复用已验证的 VM 事件标量通道，不新增主机 ABI。

## 原因

这精确覆盖旧版 `sbbiyue` 的 `countPlayer2(...hasHistory("damage"))` 语义，同时避免为一个回合级去重计数引入通用历史查询系统。
