# ADR 0095：逻辑【杀】上下文伤害修正

## 决策

为来源侧伤害 modifier 增加 `damage_amount(sha)` 通道，并增加通用上下文值 `owner_hand_equip_gte_other`。该通道仅在逻辑【杀】实际进入伤害意图时生效；上下文值在技能拥有者与受伤角色均存活，且拥有者的手牌数、装备区牌数分别不小于受伤角色时贡献一，否则贡献零。

## 原因

旧版 `repojun3` 在【杀】造成伤害前比较来源和受伤角色的手牌数与装备区牌数。已有 `sha_damage` 通道在响应前计算，且多目标【杀】共享该阶段的数值，不能精确表达逐目标条件；伤害意图管线已有明确的来源、目标和逻辑【杀】标记，因此在此增加通用筛选能保留逐目标语义，也无需新增武将专用宿主分支。

## 兼容性

新枚举项均追加在末尾以保持既有序列化序号稳定。Rule IR 与技能 VM ABI 不变；引擎语义修订号递增到 80，未使用新通道和值的内容包行为不变。
