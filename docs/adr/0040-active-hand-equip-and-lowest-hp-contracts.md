# ADR 0040：主动技手牌/装备输入与最低体力目标契约

- 状态：已接受
- Engine semantics：24

## 背景

「活气」要求弃置一张手牌或装备牌，并且目标必须是全场体力值最低的角色。若把这两条规则放进技能专用 effect，客户端可提交非法输入，且后续同类技能会重复实现校验。

## 决策

- `select_he min max` 声明从拥有者手牌区或装备区选择牌；
- `targets min max lowest_hp` 声明所有目标必须与全场最低当前体力值相等，允许并列；
- 选择候选、命令校验和最终弃置均在权威引擎复用同一手牌/装备集合；
- 已有 `select_hand` 与不带 `lowest_hp` 的目标契约保持原行为。

## 结果

「活气」只描述输入和效果顺序，不包含技能名分支；后续同类主动技直接复用这两条契约。
