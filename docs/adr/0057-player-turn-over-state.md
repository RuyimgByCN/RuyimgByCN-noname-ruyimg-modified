# ADR 0057：通用武将牌翻面状态

- Engine semantics：41

旧版技能通过 `player.turnOver()` 切换武将牌正反面；背面角色在其下个回合开始时跳过整个回合并自动翻回正面。该语义属于玩家公共状态和回合调度，而不是某个技能的私有标记。

引擎为 `Player` 和观察者座位视图增加 `turned_over`，并增加通用 `TurnOver` effect 与 DSL `effect turn_over(player)`。回合推进按座次跳过背面存活角色、逐一翻回正面，再进入首个正面角色的准备阶段；连续多名或全部角色背面时仍保持确定性轮次推进。

实现不包含技能 ID 特判。规范状态哈希仅在玩家背面时写入专用域标记，因此既能区分规则状态，也保持所有玩家正面时的既有哈希向量不变。
