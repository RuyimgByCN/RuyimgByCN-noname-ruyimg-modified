# ADR 0034：展示牌双选项与技能内真实用牌续跑

- 状态：Accepted
- 日期：2026-07-15
- Engine semantics：18

## 决策

新增参数化的 `reveal_discard_suit_gain_or_use` 类型化效果：展示基础数量加封顶标记数的牌，允许按任意顺序执行“弃置手牌/装备并分配同花色展示牌”和“使用一张剩余展示牌”。所有选择、已完成选项和展示牌实例 ID 都写入可序列化 continuation；完成两项后增加封顶标记并重铸当前全部手牌。

技能内使用展示牌复用标准用牌管线，只跳过“必须在出牌阶段、牌必须原先位于本人手牌”的命令入口校验。杀、装备、延时锦囊、无懈窗口和后续触发仍由同一套权威规则结算。若用牌打开嵌套选择，未完成的双选项状态进入既有 deferred effect 队列，待整张牌结算完成后恢复。

`chenjian.skill` 只声明准备阶段可选触发和效果参数；旧 JavaScript 仅作为迁移语义证据，不进入包或运行时。

## 兼容性

效果 tag 25、continuation tag 21 和序列化枚举变体均追加在末尾，已有编号不变。该效果引入新的回放可见结算语义，因此 `EngineSemanticsId` 从 17 升至 18；Native、浏览器 WASM 与 skill-vm 必须重新通过跨目标一致性门禁。
