# ADR 0076：视为牌的装备牌类别过滤器

## 决策

`view_as` 新增 `card_equip` 过滤器，按牌的有效类别匹配武器、防具、进攻坐骑、防御坐骑和宝物，主动与响应路径统一复用 `CardKind::is_equip()`。来源区域仍由 `from hand`、`from equip` 或 `from hand_equip` 独立约束。

旧版 JS 只作为语义证据，不进入运行时；具体技能不增加引擎特判。

## 原因

“手牌中的装备牌”和“装备区里的任意牌”不是同一条件，单靠来源区域无法表达。一个稳定的牌类别过滤器可覆盖同类技能，同时避免把基本牌、锦囊牌误当装备牌。

## 兼容性

使用 `card_equip` 的包要求 Rule VM ABI 5；ABI 5 主机继续加载 ABI 3/4 包，ABI 4 主机拒绝 ABI 5 包。内容 Schema 保持 3，既有包无需重打。Rule IR 版本升至 4，引擎语义修订号升至 61。
