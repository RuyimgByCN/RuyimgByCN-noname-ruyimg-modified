# ADR 0576：ABI 636 3D精选薛灵芸【涟洏/暗织】

本批按武将闭包发布薛灵芸（`ddd_xuelingyun`，3444553255）与【涟洏】（`dddlianer`，
1083711762）、【暗织】（`dddanzhi`，1654153098）。旧 JavaScript 只作语义证据，不进入
npack 或运行时。

【涟洏】在红色牌完整结算后可获得仍在弃牌堆的全部实体材料。若实际可获得材料恰为一张且
点数有效，则覆盖本回合的点数上限：使用、打出或用于救援的牌必须严格小于该点数；多实体牌
只回收材料，不改写已有上限。回合结束清除限制。

【暗织】按技能实例记录全局最近一次使用或打出的牌色。角色回合开始时若记录为黑色，薛灵芸
可指定一名存活角色；该角色本回合首次成为黑色牌目标时，从当前暂停结算的目标中移除并立即
清除指定状态，未命中则在回合结束清除。目标选择使用标准可恢复 Choice，目标移除复用现有
暂停牌结算管线。

验收：【涟洏/暗织】Golden 2/2、content-compiler 526/526、engine-api 4/4、engine-core lib
55/55、Rule VM 单元 10/10 与集成 5/5、conformance 3/3、31 个扩展空 store 冷导入均通过；
内容锁为 `e05e0df5542d0ff56dead6571de9af326ea9251cd5b56b653b6f3620985064b4`。

`official/ddd@0.1.0` 更新为 ABI 636，累计含 20 名武将、43 项技能、63 个模块、57 个触发、
6 项主动规则、5 项视为规则、4 项修正器和 20 项立绘资源；logic hash 为
`5b1fe20ca7c19c61131395453651ea76ac65cae3a5c142e170f7af60842196b1`，asset hash 为
`94d95752bc43d1af01e8d3671ebcb1544fde108a6e6520e0ed138dd74a3236a2`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`763c67ae2c3d9707a54bcc4f4b93f02e6fb50d16be5f543270650f7c57cc901e`；两份薛灵芸立绘 SHA-256
均为 `a13ceb4aa7d860dad91469b7e90a33303bf3f076bbdfb692f2d82565badcfd22`。

编译产物按架构计划 §37.10 在本批门禁结束后清理；`.npack`、扩展、立绘、许可证、源码和
文档属于交付物并保留。本 ADR 只证明 3D精选第二十个武将闭包，不代表整个扩展迁移完成。
