# ADR 0128：私看牌堆顶并按花色选择获得

## 背景

旧「心战」在出牌阶段限一次、拥有者手牌数大于体力上限时，私下观看牌堆顶三张牌，可以展示并
获得其中任意张红桃牌，其余牌按原相对顺序留在牌堆顶。它同时涉及主动技合法性、隐藏牌面投影、
可取消的多选屏障、有效花色和牌堆顺序，不能把旧 JavaScript 的 `chooseCardButton` 与 DOM 牌堆操作
留到权威运行时。

## 决策

- 主动技 DSL 追加默认关闭的 `hand_gt_max_hp` 合同。权威命令入口在消耗次数和执行效果前比较
  手牌数与体力上限；字段进入包逻辑哈希，不按技能名分支。
- Rule VM ABI 38 追加 `choose_gain_top_cards_by_suit(player, count, suit)`，host effect tag 为 56。
  效果私下展示至多 `count` 张牌堆顶牌，仅把有效花色匹配的实体牌作为可选项；玩家可以取消，
  或选择任意非空子集公开展示并获得。
- 选择续体保存玩家、花色和完整牌堆顶切片。恢复时重新校验切片、实体牌唯一性与有效花色；未选
  牌不移动，因此保持原相对顺序。伪造、重复或过期选择在同一事务中拒绝且不改变状态。
- 观察者投影只向当前选择者暴露续体引用的私看牌面。该规则同时补齐既有观星类选择的牌面投影；
  其他玩家、旁观者与公开回放仍看不到未公开牌。
- 旧 JavaScript 只保留为语义和溯源证据，不进入 npack，也不在运行时解释。
