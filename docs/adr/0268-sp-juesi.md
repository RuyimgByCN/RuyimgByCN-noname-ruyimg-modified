# ADR 0268: SP「决死」复用阶段化目标自弃与普通决斗链

ABI 192 增加主动目标约束 `hand_equip_nonempty`，精确表达“目标手牌区或装备区有牌”，不把
“目标自己可弃”错误收窄成“技能拥有者可弃目标牌”。通用效果
`target_discard_then_duel_if_non_sha_and_hp_gte_owner(player, target)` 让目标强制选择并弃置
一张牌；弃牌移动及其嵌套触发完成后，才按弃牌的有效牌名、双方当前体力与当前用牌合法性决定
是否经普通【决斗】管线继续。

SP「决死」只声明手牌【杀】成本、攻击范围目标和上述共享效果；同构的「抬棺」可直接复用该
效果。SP庞德与 STANDARD「马术」组成完整技能闭包，旧 JavaScript 仅保留为语义证据。
