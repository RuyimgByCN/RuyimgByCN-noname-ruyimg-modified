# ADR 0289：EXTRA 神刘备与阶段转换技能

## 决定

旧 JavaScript 只作语义合同，运行时不加载或执行。神刘备重写为：

- `nzry_longnu` 在出牌阶段开始切换持久分支，结算失去体力或减体力上限、摸牌，并授予
  到本出牌阶段结束自移除的 helper。
- helper 复用实体来源 `view_as`；ABI 213 补充锦囊过滤、雷【杀】和按逻辑牌名判定的
  不计次数语义。
- `nzry_jieying` 复用连环标记；通用 modifier 阻止存活拥有者解除横置，并由首个存活同名
  技能拥有者提供一次全局横置手牌上限加成，避免多拥有者叠加。
- 结束阶段使用有类型的强制目标选择，恢复时重验拥有者、阶段、目标存活和未横置状态。

神刘备进入 EXTRA 角色闭包；npack 只包含编译后的模块、索引和角色数据。

## 兼容性

新增 HOST_EFFECT 212–213、`EffectRequest` 稳定哈希标签 252–253、续体标签 151。
Rule VM ABI 为 213，Rule IR 为 99，Engine semantics revision 为 187；其他版本轴不变。
