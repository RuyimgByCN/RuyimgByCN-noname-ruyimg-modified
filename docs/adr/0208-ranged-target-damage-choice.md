# ADR 0208：带范围的多目标伤害选择

## 背景

旧 SIXIANG「凶算」在拥有者的准备阶段检查其体力是否并列全场最高；满足时，拥有者必须从
所有与自己体力相等的角色中选择至少一名，并依次对这些角色造成 1 点伤害。目标可包含拥有者。
旧实现用 `[1, Infinity]`、`chooseTarget` 和异步循环表达，不能把不受约束的客户端选择直接
带入权威运行时。

## 决策

Rule VM ABI 135 增加：

- 共享目标范围 `same_hp`，包含所有当前体力等于选择者的存活角色，也包含选择者本人；
- `choose_targets_damage(player, min_count, max_count, scope, amount)`，声明静态选择边界和每名
  目标的普通伤害值；
- 引擎把实际最大数量裁剪到当前候选数，并在 Choice 恢复时重新验证技能、观察者、存活状态、
  目标范围、数量和去重；
- 合法目标按座次排序，再以 `player` 为伤害来源逐个进入普通伤害管线。

ABI 135 追加 HOST_EFFECT 147、continuation 99 和 `EffectRequest` 哈希标签 183。

## 结果

- 该能力可继续服务“选若干同体力/最低手牌/性别范围角色并依次造成伤害”的旧技能，不含
  `stdxiongsuan` 专用分支。
- 客户端提交顺序不影响权威结算顺序，目标状态变化会在恢复屏障处被拒绝。
- 旧 JavaScript 只保留为语义证据，不进入 npack、扩展目录或运行时。
