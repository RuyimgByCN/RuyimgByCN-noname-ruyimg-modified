# ADR 0578：ABI 638 3D精选夏侯玄【朗怀/玄论】

本批按武将闭包发布夏侯玄（`ddd_xiahouxuan`，3351767801）与【朗怀】
（`dddlanghuai`，4025119557）、【玄论】（`dddxuanlun`，3478177951）。旧 JavaScript
只作语义证据，不进入 npack 或运行时。

【朗怀】在摸牌阶段询问是否展示手牌并替换通常摸牌：初始阴状态摸当前手牌包含的有效花色数，
切换后的阳状态摸四种花色中缺少的数量；实际发动后切换状态。若【玄论】已删去“可”，则直接
发动【朗怀】，并只在这次实际发动后清除强制状态。

【玄论】每次受到伤害后可摸四张牌，同一回合的多次发动只保留一次回合末结算。结算时可从
手牌和装备区选择四张牌（不足四张仅限已进入强制状态的路径），按玩家给出的确定顺序拆分为
牌堆顶和牌堆底；也可暂时移除该分支并令下一次【朗怀】强制发动。顶底排列在移牌事件进入触发
队列前原子完成，Choice 恢复时重新验证技能、角色、实体牌、所属区域、数量、去重与分界符。

验收：夏侯玄 Golden 3/3、content-compiler 529/529、engine-api 4/4、engine-core lib 55/55、

`7d49184c0fa04930601f50793192a3837ae58089f81e90c699d0532907a7994c`。
