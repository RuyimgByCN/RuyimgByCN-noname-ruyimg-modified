## 修复

1. **N10-a 私有应答泄露**：`event_view_for` 沿日志维护询问 id → 观察者
   映射；`ChoiceAnswered` 对非观察者降为 `EventView::ChoiceAnsweredHidden`
   （仅保留询问 id，选项内容不透明）。观察者本人与表现层行为不变。
2. **N11-a 令牌跨实例/恢复复用**：令牌派生改为 实例熵（`RandomState`
   每实例随机，不入快照）× 令牌代次（随快照延续、恢复时 +1 轮换）×
   座位 × 计数器。同种子跨实例令牌互异；恢复前旧令牌全部失效；正确
   重签仍可用。
3. **N11-b 存档边界**：头部与载荷规则版本一致校验（改写头部 →
   `RuleVersionMismatch`）；`payload_len` 经 `usize::try_from` +
   `checked_add`（u64::MAX → `UnexpectedEof` 而非 panic）；选择提示词
   `Box::leak` 改为字符串池（同串仅泄漏一次，超长 → `BadTag`）。
4. **N04-f 快照关联校验**：将槽下标必须落在目录武将表界内；明置状态
   必须与将槽存在性一致；声明牌种牌 id 界内；新增牌归属多重集校验
   （每张牌恰在一个牌区，跨区重复 → 拒绝）；机器持牌引用递归收集并
   做界检查（观星顶牌等暂离态允许存在，不做跨集合子集断言——避免
   误拒合法挂起态，已有正反用例覆盖）。
