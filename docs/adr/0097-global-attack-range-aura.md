# ADR 0097：全场攻击范围光环使用被查询角色上下文

## 决策

追加 `global_attack_range` modifier 通道。该通道读取所有仍存活的技能拥有者，而不是只读取被查询角色自己的技能；动态值 `queried_player_hand_gt_hp_signed` 则读取当前正在计算攻击范围的角色，手牌数大于其体力值时贡献 `+1`，否则贡献 `-1`。

## 原因

旧版 `stdyinzu` 通过全局子技能修改每名角色的攻击范围，并以场上拥有〖荫族〗的角色数作为增减幅度。每个存活拥有者各提供一次相同光环后，自然得到原来的计数与叠加结果；拥有者死亡后立即不再贡献。把技能拥有者和被查询角色分成两个显式上下文，也避免将该技能写成名称特判或复制到所有角色身上。

## 兼容性

新 modifier 目标和值来源均追加在枚举末尾，既有序列化序号稳定。Rule IR 与技能 VM ABI 不变；引擎语义修订号递增到 82，未使用新通道的内容包行为不变。
