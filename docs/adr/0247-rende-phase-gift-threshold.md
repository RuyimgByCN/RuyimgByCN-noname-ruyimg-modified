# ADR 0247：仁德阶段给牌累计阈值

## 决策

ABI 172 增加 `give_selected_recover_after_phase_total_two(player, target)`。主动技本次选择的
一至任意张手牌交给其他角色；技能实例复用出牌阶段计数记录累计给牌数，累计首次从不足两张跨到
至少两张时，在移动及其嵌套触发结束后令技能拥有者回复一点体力。

标准「仁德」声明为可重复使用的
`targets 1 1 other select_hand 1 255` 主动技，不设置每阶段次数上限。

## 原因

旧 JavaScript 通过历史记录回扫本阶段此前由仁德给出的牌数。权威引擎已有随出牌阶段重置并纳入
状态哈希的技能计数，复用它即可避免新增历史解释器或状态字段；延后回复保留“先给牌、后回复”的
可观察顺序，旧 AI 与界面逻辑不进入运行时。
