# ADR 0248：突袭摸牌替换

## 决策

ABI 173 增加 `choose_other_hand_targets_gain_one_replace_draw(player)`。摸牌阶段开始时，技能
拥有者可选择一至两名有手牌的其他存活角色，随后按座次依次选择并获得各一张当前手牌；发动后
本次通常摸牌为零。

## 实现

目标选择和逐目标手牌选择使用 continuation 115；每次选择均校验当前摸牌阶段、角色存活状态、
技能归属和卡牌区域。移动牌后通过延迟尾效果等待嵌套移动触发完成，再处理下一个目标。专用
`DRAW_PHASE_DRAW_ZEROED` 回合标志只阻止本次通常摸牌，不会误启用「裸衣」的伤害加成。

旧 JavaScript 仅作语义参考；AI 估值、提示和动画不进入运行时。
