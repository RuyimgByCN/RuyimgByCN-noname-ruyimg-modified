# ADR 0144：完整【杀】结算上下文与赠牌后续用牌

## 决策

引擎在主动逻辑【杀】进入响应队列前记录使用者、实体承载牌与完整目标列表，并在每张实体【闪】支付响应成本时把来源牌追加到同一条确定性记录。所有目标、伤害、濒死与嵌套选择结束后，引擎发出独立的 `sha_resolved` 事件并消费记录。内容技能不得扫描瞬态事件历史或执行旧版 JavaScript。

`xinzhongyong` 通过 ABI 54 的类型化效果取得事件中的【杀】、【闪】与原目标列表。核心在每个选择屏障重新验证牌仍在弃牌堆、收牌者仍存活且不属于排除集合。红牌赠送完成及其移动触发结算后，再由收牌者选择一张实体【杀】来源；普通次数不消耗，普通目标禁用规则保留，距离改由原技能拥有者的攻击范围判定，且不能攻击该拥有者。

## 兼容性

所有枚举变体和效果标签只在末尾追加。Rule VM ABI 升至 54，Rule IR 升至 65，Engine Semantics 升至 140。旧包不获得新能力，其既有序列化序号保持不变。
