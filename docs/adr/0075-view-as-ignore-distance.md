# ADR 0075：视为牌的单次无距离限制

## 决策

为 `view_as` 增加可选的 `ignore_distance` 契约。它只跳过该次转化牌的普通距离校验，仍复用原牌的目标合法性、次数限制、响应、锦囊无懈链、效果和历史管线；不绕过存活、自身、目标保护或牌的其他限制。

该字段默认 `false`，进入包逻辑哈希；只有实际声明它的包要求 Rule VM ABI 4。未声明的既有 DSL 与包继续保持 ABI 3，不提升内容 Schema 版本，也不需要重打全部旧包。

旧版 JS 只作为行为语义依据，不进入新运行时；“违忤”不增加技能名特判。

## 原因

旧“违忤”用牌上的临时标记只为该张转化【顺手牵羊】放开距离。全局距离 modifier 会错误影响其他牌，技能专用引擎分支也无法复用。把这一差异声明在通用 `view_as` 条目上，可以精确覆盖本次转化，并复用既有出牌结算。

## 兼容性

`ViewAsIr` 新增加法字段，Rule IR 版本升至 3；引擎语义修订号升至 60。包字段采用缺省反序列化，旧包读入时为 `false`。ABI 4 主机可加载未使用该字段的 ABI 3 包；ABI 3 主机必须拒绝使用该字段而产出的 ABI 4 包。
