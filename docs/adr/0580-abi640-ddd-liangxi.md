# ADR 0580：ABI 640 3D精选梁习【仝御】

本批按武将闭包发布梁习（`ddd_liangxi`，4285099189，魏，4 体力）与【仝御】
（`dddtongyu`，2302761270）及其非获得型临时限制（`dddtongyu_blocker`，3861572400）。
旧 JavaScript 只作语义证据，不进入 npack 或运行时。

【仝御】在出牌阶段限一次，以一至四张花色各不相同的手牌转化为【五谷丰登】。发动者先选择
顺时针或逆时针结算；展示牌数在目标数基础上增加实体材料数。每名目标按选定方向依次选择：
接受结算并在本回合不能使用或打出手牌，或令本次【五谷丰登】对其无效。结算结束后，若展示牌
仍有剩余，梁习可令一名选择无效且仍存活的角色获得所有仍位于弃牌堆的剩余牌。

ABI 640 新增 `resolve_ddd_liangxi(player,actor,card,action)`、三个精确触发过滤器及
`dddtongyu` 多实体牌视为成本合同；牌结算状态记录来源视为技能和技能排除目标，并纳入确定性
状态哈希。实现复用现有视为牌、【五谷丰登】展示/分配、标准可恢复 Choice、目标排除、回合末
临时技能清理与实体牌移动管线，没有引入第二套牌结算框架。

验收：梁习 Golden 2/2、content-compiler 531/531、engine-api 4/4、engine-core lib 55/55、
Rule VM 单元 10/10 与集成 5/5、conformance 3/3、31 个扩展空 store 冷导入均通过；最终内容锁为
`947a200c1d347c3cbca0df750c6c6c26046aab5d0aff4c30d91880880ac603f6`。

`official/ddd@0.1.0` 更新为 ABI 640，累计含 24 名武将、52 项技能、84 个模块、78 个触发、
6 项主动规则、6 项视为规则、6 项修正器和 24 项立绘资源；logic hash 为
`567d81ab6c8e5e6df4d4a6146993e2f6161516a66e34459236e616c93bac6fd0`，asset hash 为
`3d47ee1a83b957488a090b3906231c9f7549fcbe42750bc8b876573b227201cb`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`69a7d09935e7240f1d126b6aa9d022c3e9eab73403f414544191896e58a52d29`；两份梁习立绘 SHA-256
均为 `4a855101a0cee9856930a3b2816b8667a92ae5e293fd067cd2f5dafcf48ff758`。

编译产物按架构计划 §37.10 清理：工作区 `target/`、统一外部 `CARGO_TARGET_DIR`、临时打包目录
与本批冷导入 store 均删除；`.npack`、扩展、立绘、许可证、源码和文档属于交付物并保留。
本 ADR 只证明 3D精选第二十四个武将闭包，不代表整个扩展或上游归档迁移完成。
