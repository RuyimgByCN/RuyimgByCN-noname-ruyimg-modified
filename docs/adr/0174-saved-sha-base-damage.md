# ADR 0174：当前【杀】基础伤害快照

## 状态

已接受（2026-07-23）。

## 背景

旧版「挽弓」在使用基本牌后强化下一张牌：下一张【杀】无距离和次数限制且基础伤害加一，任意
下一张牌都会消费状态；若下一张仍是基本牌，父技能会在同一用牌事件重新获得状态。把伤害加成只
做成临时 modifier 会在 `card_used` 时随状态移除，早于后续伤害计算；延迟移除又会错误影响再下一张牌。

## 决策

Rule VM ABI 99 增加：

1. `owner_source_basic` 与 `owner_source_non_basic`，按当前用牌的逻辑牌种过滤；
2. `increase_current_sha_base_damage(player, card, amount)`，重新校验来源/实体牌属于当前保存的
   主动【杀】续体，再以饱和加法更新该次用牌的基础伤害；
3. 单目标续体更新 `amount`，多目标续体更新共享基础值，因此所有目标读取同一快照；
4. 「挽弓」的无限次数、无距离、添加与移除临时技能继续复用已有 modifier 和效果。连续基本牌
   保留临时技能，非基本牌移除；【杀】在移除或刷新之前把加成写入当前续体。

旧 JavaScript 只作为语义合同，不进入 DSL 包或运行时。

## 后果

- 当前牌的加成不依赖临时技能存活到伤害阶段，也不会泄漏到后续牌。
- 新效果是通用、定长、可哈希的当前【杀】快照操作，可供同类技能复用。
- ABI 98 主机拒绝 ABI 99 包；ABI 99 主机继续加载 ABI 3–98 的加法式内容包。
