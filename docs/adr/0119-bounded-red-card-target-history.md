# ADR 0119：有界的回合红牌目标历史

## 背景

旧「扶援」在角色成为【杀】目标时遍历所有角色本回合的 `useCard` 历史，检查该目标是否曾被
另一张红色牌指定。只保存“曾被红牌指定”位图会丢失 `evt.card != event.card`：同一实体牌再次
出现时，旧规则仍会排除它；保存完整用牌日志又会让权威状态随回合用牌数增长。

## 决策

新增通用过滤器 `owner_alive_sha_target_no_other_red_card_this_turn`，只接受逐目标
`card_targeted` 上下文，并要求：

- 技能拥有者与事件目标均存活，当前逻辑牌为【杀】；
- 当前回合不存在一张不同于当前实体牌、且曾指定事件目标的红色牌。

只有加载该过滤器的内容包才启用历史维护。每名角色保存一个饱和状态：`0` 表示没有红牌，`1`
表示恰好一张并附带其实体牌 ID，`2` 表示至少两张不同红牌。该表示足以回答“是否存在另一张”，
状态大小固定为玩家数上限，不随用牌次数或扩展技能总量增长。

`CardUsed` 先生成并筛选全部 `CardTargeted` 上下文，之后才登记本次红牌目标。因此当前事件天然
不会把自己算入历史；同一实体牌的重复记录也不会把状态从 `1` 提升为 `2`。换回合时与其他
回合历史一起清零。`huicui:refuyuan` 可选发动并令事件目标摸一张牌；AI 态度、音频和日志目标
不进入权威规则。陈登仍依赖尚未重写的 `reyingshui`、`rewangzu`，所以本次不提前发布武将。

## 版本

该能力要求 Rule VM ABI 29、Rule IR 40、引擎语义修订 115。ABI 29 主机继续按加法兼容规则
加载 ABI 3–28 内容包；内容 Schema、网络协议、回放 Schema、快照 Schema 与包格式均不变。
`TriggerFilter` 新枚举项追加在末尾，回合历史使用稳定的玩家分区键 501–508 与 601–608。
