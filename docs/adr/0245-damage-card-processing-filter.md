# ADR 0245：处理区伤害牌过滤器

## 决策

ABI 170 增加 `owner_is_target_card_in_processing`：仅当技能拥有者是受伤角色，且本次伤害的
实体牌载体仍在公共处理区时匹配。

标准「奸雄」在该可选触发中复用 `event_card`、`zone` 与 `move_card`，把载体从处理区移入
拥有者手牌。无实体牌伤害、牌已离开处理区或选择取消时均不获得牌。

## 原因

旧 JavaScript 的条件与效果都是围绕伤害牌实体，不是固定摸牌。过滤器保证无可获得牌时不打开
无意义选择；移动原语在续效执行时再次校验来源区域，无需新增技能专属 Host effect。
