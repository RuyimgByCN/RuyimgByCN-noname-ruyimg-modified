# ADR 0111：回合内因使用或响应进入弃牌堆的实体牌历史

## 决策

新增触发过滤器 `owner_is_target_use_response_discarded_at_least_hp`。它只在技能拥有者是当前回合角色与事件角色，且本回合所有角色因使用或响应而进入弃牌堆的实体牌总数不小于拥有者当前体力时通过。

计数由服务器在 `CardUsed` / `CardResponded` 的权威管线内维护：无实体虚拟牌、装备后仍位于装备区的牌不计；成功置入判定区的延时锦囊会撤销临时弃牌区计数；被【无懈可击】抵消而最终留在弃牌堆的延时锦囊与响应的【无懈可击】均计入。只有加载了使用该过滤器的内容包时才启用该历史能力。

## 原因

旧版 `mobilejingce` 统计的是弃牌堆移动历史，不是逻辑用牌次数。直接复用 `CARD_USED` 会漏掉其他角色的响应，也无法正确表达多实体牌转化、装备牌和延时锦囊的区别。将它建成通用历史语义，后续同类技能无需复制技能专用状态机。

## 兼容性

该能力要求 Rule VM ABI 21、Rule IR 32、引擎语义修订 107。ABI 21 主机继续按加法兼容规则加载 ABI 3–20 包；内容 Schema、网络协议、回放 Schema 与快照 Schema 均不变。新增 `TriggerFilter` 枚举项追加在末尾，回合标志使用新的稳定键 15。
