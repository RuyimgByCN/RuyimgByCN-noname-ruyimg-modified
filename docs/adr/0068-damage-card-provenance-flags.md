# ADR 0068：伤害牌来源标记

## 决策

- 卡牌关联伤害增加通用 `card_flags` 位集，首个位表示该【杀】由【酒】强化。
- `DealShaDamage`、内部 `CommitDamage`、元素连环的 `DealCardDamage` 和伤害触发上下文完整传递该位集。
- 【杀】响应及多目标续执行把伤害属性放在低 8 位、来源标记放在随后 8 位，保持原载荷长度；标记为零时编码不变。
- DSL 增加 `owner_is_target_red_or_jiu_sha` 过滤器，按权威牌色或明确的【酒】标记判断。

## 理由

旧「恃勇」区分红色【杀】与被【酒】强化的【杀】。不能用伤害值反推【酒】，因为裸衣等规则也会
增加【杀】伤害。通用来源位集可以继续承载其他卡牌使用阶段事实，避免为上千技能增加技能 ID
特判或一次性状态字段。

## 兼容性

新增字段均提供反序列化默认值，枚举成员只在末尾追加；引擎语义修订号递增到 52。
