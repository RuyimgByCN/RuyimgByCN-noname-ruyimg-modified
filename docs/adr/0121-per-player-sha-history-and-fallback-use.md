# ADR 0121：按角色的【杀】历史与取消用牌回退

## 决策

旧扩展 JavaScript 只作为语义证据。对“本回合使用过【杀】”新增按内容需求启用的有界事实：
`TurnState` 以稳定玩家 ID 保存逻辑【杀】使用计数，并在换回合时与其他每角色计数一起清理。
过滤器 `owner_alive_used_sha_this_turn` 只读取技能拥有者自己的计数，不使用只描述当前回合角色的
全局 `SHA_PLAYED`，因此技能在其他角色回合使用【杀】时也能精确工作。

新增类型化效果 `choose_use_virtual_sha_or_draw(player)`。它生成无实体、无花色的【杀】，遵守普通
距离、目标合法性、响应和伤害管线，但按旧 `chooseUseTarget(..., false)` 语义不校验且不消耗普通
【杀】次数。玩家取消目标、用牌被禁或没有合法目标时改为摸一张牌；选择屏障把技能实例写入续体，
保证恢复后的摸牌来源可追踪。客户端只提交候选 token，权威状态机负责候选生成和恢复时校验。

## 兼容性

新 `EffectRequest`、Rule IR 语句和触发过滤器都追加在枚举末尾；效果字节码 tag 为 49。该能力要求
Rule VM ABI 31、Rule IR 42、引擎语义修订 117。ABI 31 主机继续按加法兼容规则加载 ABI 3–30 包，
旧主机拒绝需要新效果或过滤器的包。Native、浏览器 WASM、skill-vm 与冷导入门禁必须重新通过。

## 首个使用者

四象张翼「执义」在任意角色回合结束时检查拥有者本回合的逻辑【杀】历史，并强制执行一次
“不计次数的虚拟【杀】或摸一张牌”。发布包不包含、加载或解释旧 JavaScript。
