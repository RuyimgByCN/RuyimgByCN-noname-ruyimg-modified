# ADR 0264: SP「枪舞」判定点数牌策略

ABI 188 增加通用效果 `judge_set_skill_mark_to_rank(player, skill)`：使用标准判定管线，并把最终
实体判定牌点数写入来源技能的同名标记。增加两个按实体牌查询的修正器：低于标记点数的逻辑
【杀】忽略距离；高于标记点数的逻辑【杀】绕过且不消耗通常使用次数。等于判定点数时均不生效；
旧 JS 的 `unsure` 分支映射为无点数逻辑【杀】同时获得两项策略。

效果复用已有判定、标记和 `JudgmentResolved` 事件，不增加 continuation。出牌阶段结束时移除
标记，使查询策略同步失效。SP 张星彩与旧张星彩分别通过 SP、OLD npack 完成精确技能闭包；旧
JavaScript 只作为语义证据，不进入 npack 或运行时。
