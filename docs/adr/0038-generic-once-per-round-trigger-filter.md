# ADR 0038：通用每轮一次触发过滤器

- 状态：已接受
- Engine semantics：22

## 背景

引擎已有每轮触发记账，但原过滤器把“拥有者存活、事件来源存活、每轮一次”绑定在一起，只适合伤害类技能。联动「反转」在任意角色回合开始时触发，不依赖事件来源，也需要每轮一次。

## 决策

新增 `owner_alive_once_per_round` 过滤器：

- 仅要求技能拥有者存活；
- 复用 `SkillInstance.round_fire_round` 和既有可选触发确认流程；
- 玩家拒绝可选发动时不消耗本轮次数，确认并执行后才记账；
- 不新增技能专用状态或 continuation。

「反转」的体力目标值使用 `max_hp(self) - hp(self)`，变化量由 DSL 算术计算；正值复用回复，负值复用失去体力，随后摸绝对变化量的牌。

## 结果

以后所有不依赖特定事件来源的“每轮限一次”触发技都可复用同一过滤器，包仍只包含声明式规则与 typed effects。
