# ADR 0022: 末段伤害值修正通道

- 状态：接受
- 日期：2026-07-14

## 决策

新增通用 DSL 修正目标 `damage_taken_final_amount`，在普通伤害值修正与装备效果之后、实际扣减体力之前执行；可按普通、火焰或雷电属性筛选。失去体力不进入该通道。

`tiansuan2_1` 用 `min 1` 表达旧版 `damageBegin4` 的最终封顶语义，并把旧 `group: "tiansuan2_damage"` 的可选摸牌规则合并进同一权威技能定义。旧 JavaScript 仅作语义来源，运行时不加载。

## 原因与兼容性

复用原有 `damage_taken_amount` 会在藤甲火焰伤害加成之前封顶，错误地产生 2 点最终伤害。末段通道是可供所有最终伤害改写技能复用的规则原语，不包含技能专用分支。

新枚举变体追加在末尾以保持既有序列化变体索引稳定。规则语义扩展使 `EngineSemanticsId` 从修订 6 升至 7；Native 与浏览器 WASM 一致性门禁必须通过。
