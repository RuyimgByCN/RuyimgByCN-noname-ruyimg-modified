# ADR 0547：ABI 624 3D精选曹髦【太思/驱车/潜龙】

本批按武将闭包发布曹髦（`ddd_caomao`，329683403）、【太思】（632127901）、【驱车】
（2669792322）、临时距离规则（3815717800）与【潜龙】（3550796651）。旧 JavaScript 只作
语义证据，不进入 npack 或运行时。

【太思】在任意角色回合结束时检查曹髦本回合是否实际变过体力，并只列出本回合进入弃牌堆且
当前仍在弃牌堆的实体牌；发动后选择任意存活角色和其中一张牌令其获得，若该角色本回合曾对
曹髦造成伤害，曹髦摸两张。【驱车】首次交出一张红色手牌/装备牌，随后可把一张黑色手牌/装备
牌当普通目标规则、普通距离但不计次数的【杀】使用，再选择是否开始下一轮；每完成一次赠牌或
用杀，临时距离标记加一，完整轮数不超过当前体力上限。上游可执行 JS 设置 `event.count=1`
但从未递增或检查，和技能译文“至多 X 次”冲突；本重写按正式译文执行上限。【潜龙】在主公
击杀角色后摸三张。当前身份模式尚无击杀奖惩的额外摸牌/弃牌流程，因此其“取消奖惩摸牌或
弃牌”条款当前没有可观察事件，不另造一套模式奖惩旁路。

ABI 624 增加 `resolve_ddd_caomao(player,action)`、太思精确过滤器及可恢复选择续体。实现复用
既有回合体力变化、进入弃牌堆实体牌、伤害来源计数、实体赠牌、临时技能、同名标记距离、
实体牌转【杀】和死亡触发；所有选择恢复点重新验证角色、牌区、颜色、技能与【杀】合法目标。

验收：曹髦 Golden 4/4，DDD 八个武将累计 25/25，content-compiler 521/521、engine-api
4/4、Rule VM 10/10 与 5/5、engine-core lib 55/55、conformance 3/3，以及 31 个扩展空 store
冷导入均通过。

`official/ddd@0.1.0` 更新为 ABI 624，累计含 8 名武将、14 项技能、20 个模块、18 个触发、
2 项主动规则、1 项视为规则、1 项修正器和 8 项立绘资源；logic hash 为
`dbfdac0b0e27a30733dfaa397c86976eb37a58830eb23f61411bd5221a552404`，asset hash 为
`9ec88f728828618d2ef9a0440ea78e141163f9df83d67657a6047356dd889b74`。源码目录与
`extensions/ddd` 四份 npack SHA-256 均为
`764f850eac0d01dd796a077eda7f4d9b093e9bd5c7a21c68c38e04a844b7da27`；两份曹髦立绘
SHA-256 均为 `c14f875c76c7f4c54dac5847b0bcc8e044153eba5072dbe6d6863a3c53a8621b`。

按架构计划 §37.10，本批门禁结束后只删除 Rust/Cargo 编译产物：工作区 `target/` 与备用
`/private/tmp/noname-next-cargo-target-root` 原本不存在，共享 `/private/tmp/noname-next-cargo-target`
删除 7,707 个文件（Cargo 报告 5.0 GiB）并移除空目录。验收时三处编译目录均不存在；
`.npack`、`extensions/`、立绘、许可证、源码及文档全部保留，清理后发布包与立绘哈希不变。

本 ADR 只证明 3D精选第八个武将闭包，不代表整个扩展迁移完成。
