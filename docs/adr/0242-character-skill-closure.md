# ADR 0242：武将技能精确闭包

## 决策

目录只在以下条件全部成立时把武将标为 `ported`：

- 旧武将声明的技能均可解析且已标为 `ported`
- npack 中该武将的技能 ID 数量、内容和顺序与旧声明完全一致
- 角色元数据与动态授予等递归依赖已通过既有审计

无依赖包在修改注册表前校验武将技能引用；有依赖包允许按任意顺序装入，但内容锁全部载入后
必须通过全局闭包校验，仍缺失技能时拒绝启动。
自定义内容锁启动标准规则时仍加载完整内建 STANDARD 包，不再加载清空技能索引的名单壳包。

## 原因

此前同步器只检查角色 ID 是否出现在 npack，导致缺少技能的武将被误报为完成。精确闭包同时
阻止目录误报和不可执行角色进入运行时。名单壳包会让标准武将存在但技能不可执行，完整内建包
直接复用现有模块与稳定 ID；两项修复都不需要新增包格式或复制跨包技能。
