# ADR 0158：最少手牌目标作用域

## 决策

ABI 83 为既有 `choose_target_draw` 与 `choose_targets_draw` 效果追加 `min_hand` 目标作用域，并增加
通用触发过滤器 `owner_alive_targeted_by_other`。`min_hand` 包含所有并列拥有全场最少手牌的存活
角色，也允许技能拥有者自己成为候选。

选择请求生成和恢复执行都通过同一目标匹配器校验；若候选在等待选择期间不再是手牌数最少者，
恢复时拒绝该选择。旧作用域的编码和最低 ABI 保持不变，只有使用 `min_hand` 的内容要求 ABI 83。

## 原因

旧版 `nzry_jianxiang` 在拥有者成为其他角色用牌目标时，允许从所有并列最少手牌角色中选择一人
摸一张牌。把“最少手牌”建模为可复用作用域，可以继续使用现有的类型化选择续体和权威复验，
无需为技能 ID 增加宿主分支。

## 结果

- 旧 JavaScript 仍只作为语义规格，不在运行时加载。
- 其他需要选择最少手牌角色摸牌的技能可复用同一作用域。
- 选择等待期间的手牌变化不会让过期候选绕过服务器校验。
