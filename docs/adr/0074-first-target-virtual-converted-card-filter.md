# ADR 0074：首目标的虚拟牌与转化牌过滤器

## 决策

新增通用触发过滤器 `owner_alive_first_target_virtual_or_converted_card`，复用既有 `card_targeted` 事件及其中保留顺序的目标列表。仅当拥有者存活、拥有者是本次用牌的第一个目标，且该牌是虚拟牌或转化牌时触发。

虚拟牌定义为没有实体牌定义（`CardDefId::NONE`）；转化牌包括事件中的有效牌名与实体牌原始牌名不同，或主动 view-as 管线以 `VIEW_AS_CARD` 标记的实体牌。后者在结算期间可能已临时重标牌名，不能只靠牌名差值识别。多目标牌仍会逐目标发出事件，但只有第一个目标能通过过滤器，因此每次使用至多触发一次。

旧版 JS 只作为行为语义依据，不进入新运行时；“戏语”不增加技能名特判，只用 DSL 的可选触发与现有 `draw_cards` 效果表达。

## 原因

旧逻辑的 `isFirstTarget`、`isVirtualCard` 与 `isConvertedCard` 都是通用用牌概念。将其实现为事件过滤器，可以保留目标顺序、视为技改名后的有效牌名以及无实体牌的虚拟用牌语义，并供后续同类技能复用。

## 兼容性

过滤器枚举只在末尾追加，现有序列化序号不变；没有新增 VM 指令或宿主效果，包仍使用规则 VM ABI 3。引擎语义修订号升至 59。
