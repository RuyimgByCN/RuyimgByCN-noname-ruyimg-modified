# ADR 0041：按逻辑【杀】限定伤害转体力流失

- 状态：已接受
- Engine semantics：25

## 背景

「阴兵」只把拥有者使用的【杀】所造成的伤害改为等量体力流失。已有 `damage_as_hp_loss` 会转换拥有者造成的全部伤害，直接复用会错误影响锦囊牌和技能伤害。

## 决策

- `modifier damage_as_hp_loss(sha) override 1` 只匹配权威引擎的逻辑【杀】伤害通道；
- 不带选择器的 `damage_as_hp_loss` 保持转换全部来源伤害的原行为；
- 是否为逻辑【杀】由伤害原语传入意图解析，不依赖技能名、物理牌名或客户端声明；
- 选择器目前仅接受 `sha`，拒绝会产生歧义的其他牌或属性选择器。

## 结果

「阴兵」可完全由通用修正器与 `hp_lost` 触发器表达；后续仅转换【杀】伤害的技能可直接复用同一契约。
