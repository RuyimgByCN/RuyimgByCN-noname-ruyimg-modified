## 决策

旧 JavaScript 只作为语义合同，不进入内容包或运行时。新增 ABI 568 的
`resolve_potcaoshuang(player, target, card, action)`，复用现有技能牌堆、实体牌使用/响应、
私密选择、权威随机数、技能增删、体力上限和伤害修改管线。只补充持久实体牌标签、渐专的
固定状态及按轮记录的溺尊原牌使用历史，不引入旧扩展加载器。

## 语义

- 典易：每轮在造成伤害、受到伤害、进入濒死三个时机各限一次；第 X 次发动随机取得其他
  角色区域内至多 X 张牌，累计获得数超过体力上限后失去 1 点体力。
- 奢权：三个时机各限一次；所有其他合法角色依次私密选择一张未标记手牌，全部选择冻结后
  再统一添加持久标签，避免前一名角色的结果影响后一名角色。
- 渐专：前三次合法时机分别分配给典易或奢权；全部分配后下一次合法事件觉醒，失去其中一个
  技能、获得溺尊，并按已分配时机数减一增加体力上限及回复体力。
- 溺尊：回合结束时收取弃牌堆中的奢权标签牌作为公开技能牌堆；每回合限一次使用或打出其中
  一张原牌；本轮每实际使用一张，受到的伤害增加 1。移除技能时牌堆回到弃牌堆。
- 奢权标签牌在渐专拥有者手中点数视为 K，否则视为 A；物理牌点数保持不变。
