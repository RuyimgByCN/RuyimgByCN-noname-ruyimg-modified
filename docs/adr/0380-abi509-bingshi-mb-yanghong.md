# ADR 0380：ABI 509 兵势杨弘间计、远谟

旧 `bingshi/skill.js` 仅作为语义证据，JavaScript 不进入新运行时。

- `resolve_mbjianji` 复用权威手牌选择、拼点完成事件与不限距离/次数的虚拟杀；两名参与者
  均可秘密选择同一张“间计牌”，该实体牌只移动一次，若其为杀则依次伤害选择者。
- `resolve_mbyuanmo` 复用通用场上牌移动合法性、攻击范围查询和摸牌管线；移动前记录失牌者
  可攻击人数，移动后仅对正差值提供至多五张的可选摸牌。
- `mb_yanghong.skill` 与角色索引进入 bingshi 包；Golden 覆盖真实主动技输入、共享牌拼点、
  虚拟杀后伤害、武器移动和攻击范围差值摸牌闭环。
