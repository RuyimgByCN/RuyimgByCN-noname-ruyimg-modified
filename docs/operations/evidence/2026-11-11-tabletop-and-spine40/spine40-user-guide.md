# Spine 4.0 玩家动皮本地导入与截图对照验证指引

本文档供玩家与测试人员在本机验证自备 Spine 4.0 动态皮肤在 noname-next 原生客户端中的渲染效果，并与旧版无名杀进行并排截图比对。

---

## 一、净室规范与合规声明

1. **零附带动皮资源**：noname-next 严格遵守开源与知识产权规范，客户端安装包内**不附带任何受商业版权保护的动态皮肤（Spine）文件或官方演示资源**；
2. **纯自研净室播放器**：播放器核心由开发团队依据 Spine 4.0 公开规范自主编写，未引入官方 Spine 运行库（零 `@esotericsoftware/*` 或 `pixi-spine` 依赖）；
3. **格式支持范围**：仅支持 **Spine 4.0.x** 导出的资源。3.5、3.7、3.8、4.1、4.2 等旧版或新版格式将被自动拦截，并安全回退为静态立绘；
4. **二进制解码状态重要提示**：当前二进制 `.skel` 解码处于**「未经真实资源验证」**状态（仅通过自研编码器合成数据流的往返测试验证）。**若遇到解析异常，请优先导入 `.json` 格式的骨骼文件**。

---

## 二、准备动皮文件

请在本地准备好合法拥有的 Spine 4.0 动皮全套三件套：
1. **骨骼文件**：`<skin>.json`（推荐）或 `<skin>.skel`（二进制，未经真实资源验证）；
   - *核验方法*：打开 `.json` 文件，确认头部 `"skeleton": { "spine": "4.0.xx" }`。
2. **图集描述文件**：配套的 `<skin>.atlas`（或 `<skin>.atlas.txt`）；
3. **贴图纹理文件**：配套的 `<skin>.png`（图集切片图片）。

---

## 三、导入步骤

1. **启动客户端**：
   - 在项目目录运行 `pnpm --dir apps/web-client dev`，并在浏览器中打开测试牌桌；
2. **展开动皮导入抽屉**：
   - 在牌桌扩展控制面板中，点击按钮 **「玩家动皮导入 (saveSkinParams)」**；
3. **填写武将与参数**：
   - 输入武将 ID（例如 `caocao`）；
   - 输入皮肤名称（例如 `魏武霸业`）；
   - 确认版本号为 `4.0`；
   - 填写默认动作（例如 `DaiJi` 或 `GongJi`）；
4. **依次上传三个文件**：
   - 点击 **「骨骼 (.json/.skel [未经真实资源验证])」**，选中你的 `.json` 或 `.skel` 文件；
   - 点击 **「图集 (.atlas)」**，选中配套的 `.atlas` 文件；
   - 点击 **「贴图 (.png)」**，选中配套的 `.png` 图片；
5. **观察渲染效果**：
   - 上传完成后，抽屉上方的 Canvas 画布与 WebGL 画布将立即解算骨骼层级、网格变形与贴图混合，开始播放待机动画；
   - 下方解析结果将显示：`ready-spine40 — SPINE_40_LOADED:4.0.xx`；
   - 若未上传贴图或格式不符，界面将显示 `static-portrait-fallback`，安全呈现静态立绘卡片，绝不崩溃。

## 四、旧版无名杀同场景截图对照指南

为了验证原生净室播放器与旧版无名杀在视觉呈现上的等价性，请按如下步骤采集并排比对截图：

### 1. 视口与环境统一
- 统一使用 **1440 × 1080** 视口分辨率；
- 保持相同的武将立绘缩放比例（Scale）与舞台偏移坐标（X, Y）。

### 2. 旧版无名杀截图采集
1. 打开旧版无名杀，启用「十周年UI」或「皮肤切换」扩展；
2. 将相同的动皮文件放入对应武将皮肤目录；
3. 进入身份局对局，在武将处于待机状态（`DaiJi`）或发起杀攻击（`GongJi`）时截图；
4. 保存为：`upstream_<武将名>_<动作名>.png`。

### 3. noname-next 原生截图采集
1. 在 noname-next 中加载相同动皮与参数；
2. 在相同的视口（1440×1080）与动作关键帧下，截取对应角色座位画面；
3. 保存为：`native_<武将名>_<动作名>.png`。

### 4. 视觉等价性检查要点清单
| 检查维度 | 合格标准 | 常见问题排查 |
|---|---|---|
| **骨骼关节对齐** | 头部、手臂、武器关节相对位置与角度完全一致 | 检查 TransformMode 是否为 `noRotation` 或 `noScale` |
| **反向运动学 (IK)** | 手腕/脚踝准确到达目标骨骼点，弯曲方向正确 | 检查 2-bone IK 旋转方向与权重解算 |
| **网格变形与权重** | 衣服布料下摆、飘带网格形变平滑自然 | 检查加权网格顶点混合与 Deform 时间轴关键帧 |
| **遮罩裁剪 (Clipping)** | 边界多边形精确裁剪，凹角多边形不裁切两翼 | 检查耳切法凹多边形三角化与 Sutherland-Hodgman 插值 |
| **半透明混合 (Blend)** | 刀光火焰发光正常，无黑色脏边底纹 | 检查纹理是否为预乘透明度（PMA），混合模式设为 Additive |
| **动作混合切换** | 待机到技能动作过渡平滑，无骨骼闪烁突变 | 检查 AnimationState 多轨道混合权重 |

## 五、问题反馈与日志记录

若在导入或截图比对过程中发现异常：
1. 记录浏览器控制台日志（Console log）及解析失败信息；
2. 记录骨骼文件的导出工具版本（如 `Spine 4.0.64 Professional`）；
3. 将比对截图存入 `docs/operations/evidence/` 目录供进一步复核排查。
