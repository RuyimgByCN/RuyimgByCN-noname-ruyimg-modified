The supervisor confirmed these discriminator spellings as routine refinement of Decision30's leaf shapes. Source/tests freeze them for independent review:

- `FrozenOwnerKey.kind="package"`: namespace/package_id/version/logic_hash/content_hash exactly mirror LockedPackage. `kind="original"`: repository/adopted_revision/catalog_sha256/asset_manifest_sha256. All hashes are lowercase fixed-length hex; source commit is40hex. Repository is an explicit bounded identifier/URL string, not a display name or executable URL request.
- QualifiedDefinitionKey has owner, kind=general/skill/card and local_id. Package local_id is u32; current schema permits0 for general/skill, while card IDs reject0. Original local_id is exactly `{pack,raw_symbol}`; the parser jointly validates owner/local_id representation, with no loose untagged fallback acceptance. Future resolver must establish actual frozen definition membership.
- BoundAudioAsset has source, reference, digest_algorithm, digest and positive safe size. Reference kind=package reuses namespace/package_id/asset_id; reference kind=original uses existing canonical path/source_category/source_path. Original requires SHA256; package manifest payloads use BLAKE3. Asset aggregate hashes are not treated as payload hashes. Distinct dependency sources remain explicit; structural validation does not fabricate a current verified dependency context.
- Public voice role is a qualified general, form is explicit null or bounded token, assets are ordered exact payload candidates. The frontend does not compare occurrence-time roles against final slots, read hidden snapshots, or claim that these DTOs validate producer privacy or genuine commitment.
