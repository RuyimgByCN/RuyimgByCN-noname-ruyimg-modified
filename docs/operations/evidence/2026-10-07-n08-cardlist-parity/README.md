## 对照方法

（108/108 全命中），逐张清单见 [upstream-deck.txt](upstream-deck.txt)。
对照口径：牌种键（`CardKind::key()`）比对 + 数量比对；原生泛型建模
（Weapon/Armor/HorsePlus/HorseMinus）按功能位映射。
