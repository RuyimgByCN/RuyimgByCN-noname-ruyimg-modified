# NC12 目标档位：WASM 产物档（2026-10-18）

- 日期：2026-10-18
- 工作包：**NC12**（[方案 §NC12](../../../architecture/native-convergence-plan.md#nc12)）——「浏览器/WASM 档位」的**产物侧**测量
- 规则版本 v322（工作树）/ 存档格式 v105
- 结论：**WASM 产物档七项指标已取得基线 + 一项跨档反例**；**未启动浏览器**，故不等于浏览器档位验收

## 1 口径与边界（不得外推）

- 工具：`apps/web-client/scripts/nc12-wasm-bench.mjs`（新增）——加载**既有 WASM 产物**
  （`src/worker/native-pkg/`，sha256 见 [wasm-sha256.txt](wasm-sha256.txt)），Node 下驱动，
  **不重建源码、不启动浏览器**；
- 同设备同负载：采样时 `load average 15.54 / 14.41 / 14.69`（[load.txt](load.txt)）→ 只有 p50 可比较；
- 30 样本/项，`nearest-rank` 分位；完整日志 [wasm-bench.log](wasm-bench.log)。

## 2 结果（p50，纳秒）

| 指标 | p50 | p95 | 说明 |
|---|---:|---:|---|
| `build_with_packs`（4 座 + 1 扩展包） | 69,125 | 155,000 | 建局 |
| `build_standard`（标准目录） | 16,333 | 34,083 | 建局基线 |
| `legal_actions`（权威动作查询） | 43,334 | 69,625 | 与 NC03 前端实测 0.415 ms/次同量级 |
| `view_json`（座位视图） | 23,875 | 30,792 | 投影 |
| `save_hex`（归档） | 119,792 | 191,709 | 存档 |
| `restore_hex_with_packs`（扩展局读档） | 87,500 | 259,458 | 读档 |
| `general_candidates_json`（选将候选） | 107,542 | 280,000 | 选将 UI 数据源 |

**跨档反例（门禁有分辨力）**：用**标准入口**恢复扩展局快照 →
`REJECTED RuleVersionMismatch`（明确失败，不静默接受）——与 NC08 跨目标门禁的反例同源。

## 3 与原生档的对照（同机不同档，**不计算收益**）

NC12 原生档 p50（[基线证据](../2026-10-18-nc12-baseline/README.md)）：标准建局 4.75 µs、
swd 建局 72.5 µs、规则结算 8.1–12.4 µs。WASM 档为 16.3 µs（标准建局）等——**两者不是同一
运行时**（wasm32 + JS 绑定 + 序列化边界），方案要求**分档报告、不跨档计算收益百分比**，故此处
只并列记录。
