- 结论：**惰性缺席座位回收已实现 + 回归通过**；时限可配置（默认 600 秒，0 = 关闭）

## 1 动机（承接房间持久化）

房间跨重启恢复后，落盘的成员会**长期占用座位**（令牌仍有效，可重连）；若无回收机制，
满员房间在成员长期缺席时**无法接纳新玩家**（此前登记为待办）。

## 2 实现（**惰性**，不引入定时器）

| 面 | 内容 |
|---|---|
| 时限来源 | `room_native_actor::SEAT_TIMEOUT_SECS`（`AtomicU64`，默认 600 秒；`set_seat_timeout_secs` 可设，0 = 关闭）。**actor 循环不直接读环境变量**（生产源码门禁禁止 `env::var`），由 spawn/配置侧写入 |
| 活动时间戳 | `NativeActorMember.last_seen: Instant`，在 `Submit` 分支更新 |
| 回收时机 | **入座请求**时：若本次入座会因满员失败，且存在**最久未活动**且已超过时限的玩家成员 → `session.reclaim_seat(conn)`（成员 + 令牌一并移除）→ 落盘 → 广播名册 → 继续本次入座 |
| 语义边界 | 只回收 `role == Player` 的成员；**重连令牌随之失效**（回收即放弃该座位）；`Disconnect` 仍走原路径（保留座位与令牌，供重连） |

## 3 回归（`nc09_native_actor.rs` 新增）

`nc09_actor_reclaims_idle_seat_lazily`（2 座房间）：

| 判据 | 结果 |
|---|---|
| 两人入座（座位 0、1）后**满员** | 通过 |
| 满员且未超时 → 第三人入座**失败** | 通过 |
| 等待超过时限（1 秒）→ 第三人入座**成功**并拿到被释放座位 | 通过 |
| **时限设为 0** → 满员时不回收，第三人入座仍失败 | 通过 |
| 用例结束复位默认时限（600 秒） | 通过 |
