- 但**改分母会让 0/22–24 变成 0/12**，**这是对外可见的数字变化** ⇒ **必须由维护者确认** ⚠️

**建议的表述**（同时保留两种读法）：

> **规则差异：0/12（已转换来源）**；**另有 25 个来源未转换（规则内容未搬入），记在「来源覆盖」项**。

⇒ **这样「0」的含义才是准确的**：不是「12 个来源都不合格」，而是「12 个里没有一个达到 0 缺陷」✅
⇒ **而 `L19` 是唯一 0 缺陷的**（附 21）⇒ **它离 1/12 只差一个口径判定** ❗
