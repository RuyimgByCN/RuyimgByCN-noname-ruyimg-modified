## 定案

1. **马 6 张：维持泛型 + 批③数量对齐（±各 3 张落位）**——语义零债，
   命名差异登记为展示层，不立项逐把。
2. **八卦阵 2 张：维持泛型 Armor，批③按 2 张落位**（判定语义已有）。
3. **仁王盾：随批③实现**（锁定「黑色杀无效」，sha 结算防具检查小改动）。
4. **武器 9 把：逐把特效分批、每把落地才落位声明表**（未实现前不入牌堆，
   避免错误语义进牌堆）。建议由简到繁：青釭（无视防具）→ 麒麟弓（弃马）
   → 寒冰剑（伤害替代弃牌）→ 诸葛连弩（杀不限次）→ 贯石斧（闪后弃二
   强伤）→ 青龙偃月刀（闪后再杀）→ 丈八蛇矛（双卡转化）→ 雌雄双股剑
   （性别分支）→ 方天画戟（多目标，最重）。
