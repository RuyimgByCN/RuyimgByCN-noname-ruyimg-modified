| 缺口**被转换** | 测试**失败**并**列出已转换的键** ⇒ 提示**更新清单（第 117 行）与台账**、**启用对应行为面用例** |

## 边界

1. 本测试只判「**是否出现在目录**」；**不判实现与语义等价**；
2. 解析依赖证据文件的**小节标题与代码块格式**——若改版式需同步调整（测试会因解析为空而**数量异常**，
   可据 `DBG` 行的包数/项数核对）；
3. 项数 **56** 与清单「49 项」的差异来自代码块内含**子技/噪声键**（如 `g_yuchan_equip`），
   不影响「不存在」这一断言的有效性。
