## 评估结论（登记于规则基准「方天画戟立项评估」节）

- **上游口径**：使用【杀】时若全部手牌均被选为该杀的卡牌（= 杀为最后
  手牌；国战除外），可选目标上限 +2（至多三个目标）。
- **原生差距**：ShaResolveMachine 单目标设计（target 字段、无双双闪、
  护驾队列、流离、armor_judged/dodges_used/tieji_red 均为单目标语义）；
  PlayCard Sha 臂 `targets.len() != 1` 硬门控。
- **工程范围五项**：①PlayCard 门控放宽（方天+最后手牌，1..=3 目标逐个
  合法性检查）；②ShaResolveMachine 目标队列化（逐目标完整走 仁王盾→
  铁骑→八卦→流离→护驾→双闪→贯石斧/麒麟弓/寒冰→伤害）；③无双=每目标
  双闪、护驾每目标一轮、流离可转移后再续队列、青龙队列耗尽后追问；
  ④Sha 快照结构随实现批一次递增（版本递增 + golden 重录）；⑤体量
  ≈前七把总和。
- **定案**：批③-b⑨ 单独立项、独立批次一次成型；**不拆半成品入牌堆**
  （沿用批②「未实现不落位」定案）。前置批③-a/③-b①~⑧ 均已完成。
