   存档行（`KOF1 池 池 胜 胜 场`）恢复续跑——两者终局会话行完全一致
   （将池淘汰/轮转/比分/场次逐字段）。
2. **中间恢复续跑（引擎层）**：KOF 单局（装配将技能/体力）以确定性
   策略驱动，30 命令检查点快照/恢复——恢复件哈希与检查点一致，续跑
   30 命令后状态哈希与不中断路径一致。**口径说明**：KOF 单局可能因
   将技能面进入长局或超时判负，故用哈希轨迹而非胜者断言。
3. **死亡清理**（真实终局时）：败者手牌/装备/判定区清空（DeathMachine
   既有行为固化；超时判负无人死亡，不作断言）。
