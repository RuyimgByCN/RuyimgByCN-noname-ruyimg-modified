## 立项方案（三阶段，G0 完成条件对齐台账）

| 阶段 | 内容 | 产出/验收 |
|---|---|---|
| LX.1 静态可读化 | Node 隔离环境执行字符串表解码器（仅 `game.import` 回调体不执行），babel AST 常量折叠+控制流还原；**先中和 2 处 debugger 陷阱** | 可读版 extension.js（标注来源哈希）+ 段落清单（character/skill/card/config/UI hook 各段计数） |
| LX.2 隔离旧线动态采样 | 旧线浏览器 noname + 勾桩（wrap `game.import`/`lib.extend`/`lib.character/card/skill` 写入与 `ui.` 调用），隔离 profile 断网运行 | 注册武将/技能/卡牌/配置菜单枚举清单 + 行为样本轨迹（存证同目录） |
| LX.3 清单定案与接口分配 | LX.1/LX.2 交叉验证；每配置/子插件/规则分支登记功能、依赖、平台调用 | 台账 L29 行按「规则面/界面面」分配目标接口；范围明确后方可估完成率（G0 完成条件） |

**边界**：LX.2 执行的是混淆过的第三方代码——只在隔离环境（无网络、
独立 profile、一次性容器/浏览器配置）运行，不进入构建链；采样产物
（清单/轨迹）须与 LX.1 静态读稿交叉印证后方可入台账。
