## 2 判读（**如实**）

1. **同包内不同 seed 的步数波动很大**（如 `gwent` **156→363**、`cardpile` **261→352**）⇒
   **单 seed 的墙钟不能代表该包性能** ❗ —— 之前的「22 包单 seed 跑批」只能看**量级**，不能排序；
2. **墙钟与步数正相关**（`swd` 步数最高 ⇒ 墙钟最高 ✓）⇒ 若要**公平比较包间性能**，需**统一步数**（`min_cmds`/`max_steps`）；
3. **全部 18 次零拒绝、全部收敛** ⇒ **稳定性**（不是速度）**得到额外证据** ✅；
4. **不是**优化前后对比；**不是**产品级（无 server/浏览器）。

## 3 边界

1. **6 包 / 3 seed**，不是全部 22 包；
2. **未控制步数**（各局自然结束步数不同）⇒ **包间墙钟不可直接比较**；
3. 机器无其他负载控制（**未做 CPU 亲和**）。
