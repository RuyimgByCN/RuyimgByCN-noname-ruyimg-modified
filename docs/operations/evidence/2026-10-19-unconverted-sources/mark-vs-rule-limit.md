## 3 ⚠ 结论：**别再用 token 法给结论**

1. **每补一轮 token，「规则」数就掉一半**（191 → 137 → **77**）⇒ **说明剩下的 77 个里仍有大量标记/UI**；
2. **token 法的上限到此为止** —— 继续加 token 只会**无限逼近 0** 而不产生可靠数字（**并且可能开始误杀真规则**）；
3. **唯一可靠的办法是逐条读块** —— 77 个块，按本轮速度（4 块/次调用）约 **20 次调用**；
4. **本轮不再加 token**，也不再据此给「待迁移数」。
