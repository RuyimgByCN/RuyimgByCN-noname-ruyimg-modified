## 2. 六维度真实对局事件路径核验摘要

   - 验证 5 项全局技能注册入 `Catalog` 并挂载到全部座位；
   - `_eloMechanism` 在 `gameStart` 对 `game.me`（seat 0）仅触发 1 次（`usable: 1`），再次对 seat 0 或非 `game.me` 的 seat 1 调用均返回 `false`；
   - `_eloInitCards` 在开局标记全部初始手牌为 `elo_known`；当 `phase_number > 0` 时 `phaseBefore` 不再标记新入手法牌；当 `hand` 与 `equips` 均为空（仅判定区有牌）时返回 `0`；
