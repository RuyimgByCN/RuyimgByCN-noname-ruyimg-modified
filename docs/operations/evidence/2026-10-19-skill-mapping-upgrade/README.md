## 边界（**如实**）

1. **已知映射改名**（改到另一个**已登记**值）不在本例范围——其**存档语义**由既有
   `e02_c3_lifecycle`（内容锁拒绝 + 回滚恢复）覆盖；
2. **同映射、语义变更**（实现行为改变但 mapping 值不变）**无法在数据层识别** ⇒
   属**实现面**，需规则版本/内容哈希机制（`ruleset_version` 已有；**逐技能哈希未建**）⇒ 登记待办。

## 结论

升级面的**数据层**已闭环：**版本号**（`e02_c3_lifecycle`）、**内容增量/降级**（`nc08_upgrade_acceptance`）、
**未登记映射**（本例）三类漂移均有拒绝或可预期行为；**剩余**是「**同映射语义变更**」的检测机制。
