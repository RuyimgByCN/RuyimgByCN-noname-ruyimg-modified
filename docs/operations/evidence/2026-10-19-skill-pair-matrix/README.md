# 「组合」的**技能/武将层面**矩阵：**190 对、0 失败**（2026-10-19）

- 工作包：**NC08 / 八项第 4 项（组合）**；规则版本 v322（工作树）/ 存档格式 v105
- 用例：`crates/engine-native/tests/nc08_skill_pair_matrix.rs`
- 原始输出：[run.txt](run.txt)

## 1 由来

台账第 178 行（[组合矩阵适用边界](../2026-10-19-composition-scope/README.md)）指出：
卡牌配对矩阵的「目录 = 两包之和 + 标准牌」不变式**不适用于**纯武将/纯技能包 ⇒ **若要覆盖须另立判据**。
本文件即该判据。

## 2 判据（每对包）

对**每个含 `cards.json` 或 `character.json`** 且相对标准**有增量**的包，记 `(cards, skills, generals)`；两包同载后断言：

1. `cards    = a.cards    + b.cards    + 标准牌数`；
2. `skills   = a.skills   + b.skills   + 标准技能数`；
3. `generals = a.generals + b.generals + 0`。

**不含 `pile.json`**（替换牌堆语义，求和无意义）。

## 4 意义

| 矩阵 | 配对 | 覆盖面 |
|---|---:|---|
| `nc08_composition_pair_matrix`（卡牌） | **45 对** | 10 个**有卡牌**的包，判据「**目录卡数**」 |
| **`nc08_skill_pair_matrix`（本文件）** | **190 对** | **20 个包**（卡牌 + 武将 + 技能），判据「**卡数 + 技能数 + 武将数**」|

⇒ 新矩阵**包含**旧矩阵的 10 包（45 对 ⊂ 190 对），并把判据**扩展到技能与武将** ⇒
「组合」项由 **45 对**提升到 **190 对**，且**纯武将包不再被排除**。

## 5 边界（**如实**）

1. 只验**加和不变式**（数量），不验**同名技能跨包语义合并**（若两包声明同一 `mapping` 会去重，属另一面）；
2. 不含 `pile.json` 包（替换牌堆）；
3. 不验**对局内实际交互**（谁触发谁、结算先后）——那属行为样本（第⑦层）范围。
