## 2 为什么不采纳（**不变式不适用**）

本矩阵的不变式是：

> 「**两包同时加载**后，目录卡数 = 两包卡数之和 + 标准牌数」且「**每包声明的卡都在目录里**」。

以下三类包**不满足前提**：

| 类别 | 例子 | 为何不适用 |
|---|---|---|
| **牌堆补丁包**（`pile.json`） | `cardpile-*` | **替换牌堆**语义；与卡牌包配对会**重复计牌**，且「两包之和」无意义 |
| **纯武将/纯技能包** | `d3`、`boss-zhugeliang` | **贡献 0 张卡**（`cards: []`，只有 `generals`/`skills`）⇒ 缺卡检查把它们**引用的卡名**当成"应有卡"，产生误报 |
| 放宽发现后混入的**其它武将包** | `longxue`、`shaai-ow` 等 | 同上，且与原矩阵设计的「卡牌组合」不是同一件事 |

⇒ **保留 10 包 / 45 对**（回退后 **0 失败**），并把边界写进用例注释与本文。

| 项 | 状态 |

| 非卡牌包的「组合」语义 | ❓ **未定义**（若需要，应另立「武将/技能组合」判据，而非复用卡牌目录不变式）|

**升级矩阵**（13/13）与**保存恢复矩阵**（13/13）**不依赖**目录求和不变式
