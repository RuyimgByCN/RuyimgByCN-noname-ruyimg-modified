# 逐包**公平性能指标**：µs / 命令（2026-10-19）

- 工作包：**NC12 / 八项第 8 项（性能）**
- 工具：`nc12_bench drive tier=dir:<包> seats=4 budget=64 lookahead=1 variant=0 seed=<42007..42009> min_cmds=200`
- 原始输出：[run.txt](run.txt)

## 1 为什么需要换指标

上一轮（[多 seed 稳定性](../2026-10-19-nc12-seed-stability/README.md)）发现：
**同包跨 seed 的步数波动极大**（`gwent` 156→363），⇒ **「整局墙钟」不可比** ❌。

本轮先试 `min_cmds=200` **强制推进到 200 条命令** —— **无效** ❌：
`min_cmds` 是「**至少这么多**」，对局**自然结束**就停（实测 `accepted` 120–301，多个包 < 200）。

⇒ 改用**归一化指标**：**`µs / accepted 命令`** = 墙钟 ÷ 已接受命令数。

## 2 结果（6 包 × 3 seed）

| 包 | accepted 范围 | **µs/命令 中位** | 范围 |
|---|---:|---:|---|
| `wudian` | 142–178 | **53.57** | 52.43–53.66 |
| `shahai-gwent` | 131–301 | **54.30** | 51.06–56.39 |
| `d3` | 174–245 | **55.61** | 54.23–**108.31** ⚠️ |
| `huanle` | 120–189 | **56.73** | 55.91–60.91 |
| `cardpile` | 214–290 | **61.18** | 58.93–62.21 |
| `shahai-swd` | 223–286 | **68.99** | 66.51–69.52 |

## 3 判读（**如实**）

1. **归一化后跨 seed 非常稳定**（除 `d3` 一个 108 µs 异常值）✅ ——
   说明**「整局墙钟波动」几乎完全来自「步数不同」**，而**每命令开销是稳定的**；
2. **包间差异很小**：**53.6–69.0 µs/命令**，**极差 1.29×** ⇒ **单包内容大小对每命令开销影响有限** ✅
   （与「装载期 36–52 ms 随包大小变化」形成对比）；
3. **`d3` 的 108 µs 异常**：很可能是**该 seed 首次运行的缓存/页缺失**（**未证实** ❗）；
4. **本表可用于「同设备同负载」的逐包比较** ✅ —— 但**仍不是**优化前后对比、**不是**产品级。

## 4 口径与边界

| 项 | 说明 |
|---|---|
| 指标定义 | `墙钟(ns) / accepted` ⇒ µs/命令；**accepted 不含被拒命令** |
| 样本 | **6 包 × 3 seed = 18 局**（**不是全部 22 包**）|
| 未控制 | CPU 亲和、后台负载、首次运行预热 |
| 适用 | **同机同构**的逐包横向比较；**跨机不可比** |
