确定性身份局

默认原生引擎后端（engine-native-wasm 窄壳，Worker 内运行）。界面只消费观察者投影，不持有完整权威状态。可用 VITE_ENGINE_BACKEND=legacy 回退旧线。

联机大厅

通过 game-server WebSocket 加入权威房间。浏览器仅提交命令并接收自己的观察者投影。

架构要点

  • 主线程：Vue Shell + DOM 战斗层 + 动画时间线
  • 本地：Worker + 原生窄壳（默认）/ 旧线 WASM；联机：WebSocket + 权威服务器
  • 扩展包管理：安装 / 启停 / 升级 / 卸载（导航「扩展」）
  • 支持自动步进、存读档、倍速、跳过动画、减少动态效果
