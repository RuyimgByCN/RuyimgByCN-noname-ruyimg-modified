# 牌归属分区不变式（U01 差异 #6 的恢复面验证，2026-10-19）

- 工作包：**NC08 / 扩展台账**；规则版本 v322（工作树）/ 存档格式 v105
- 用例：`crates/engine-native/tests/nc08_card_ownership_partition.rs`

## 背景

U01（末焱）的差异 #6：「空牌库与空弃牌堆的负例把多余的牌挪到 **`core.table`**，
**只为让恢复时每张牌仍有归属**」（见[差异提炼](../2026-10-19-u01-u03-l04-diff/README.md)）。
由此可提炼一条**通用不变式**：

> **每张牌在任意时刻恰好属于一个区**（手牌/装备/判定/牌堆/弃牌/桌面），且**恢复前后归属不变**。

## 结果

```
DBG 归属分区：d3-upstream-noname 牌数 124（有归属）→ 124（恢复后）；唯一归属 ✅
DBG 归属分区：wudian-upstream-noname 牌数 138（有归属）→ 138（恢复后）；唯一归属 ✅
```

| 包 | 有归属牌数 | 唯一归属 | 恢复前后一致 |
|---|---:|---|---|
| **`d3-upstream-noname`（U01）** | **124** | ✅ | ✅（`card -> zone` 映射**完全相等**） |
| **`wudian-upstream-noname`（U07）** | **138** | ✅ | ✅ |

**断言方式**：对每张牌记录其所在区（`p{i}.hand/equips/judge`、`deck`、`discard`、`table`），
**同一张牌出现在两个区即 panic**（唯一归属），并在 `save → restore` 后比对**完整映射**。

## 边界（**如实**）

1. 只检查「**唯一归属**」与「**往返一致**」；**不检查**归属**是否与原游戏语义相同**；
2. **未构造**「空牌库 + 空弃牌堆」的**极端负例**（U01 #6 的原始场景）——本用例是其**通用形式**；
3. 未覆盖 `seat_ring` 等非牌区。
