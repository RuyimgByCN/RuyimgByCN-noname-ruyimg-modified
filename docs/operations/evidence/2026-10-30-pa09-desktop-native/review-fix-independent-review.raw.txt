- **Correct: Allocation and navigation ordering do not expose a verified late-allocation defect in the reviewed macOS path.**

  `native_engine_open` and `native_engine_close` remain synchronous Tauri commands. The installed command wrapper executes these functions inline; it does not defer allocation to Tokio. Tauri’s IPC protocol handler directly calls the invoke handler, and Wry’s WKWebView scheme handler directly dispatches that protocol callback. Thus an allocation already executing is completed before another main-thread lifecycle callback can retire the table entries.

  The installed Wry implementation emits `PageLoadEvent::Started` from `didCommitNavigation`: [navigation.rs:17](/Users/ruyimg/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/wry-0.55.1/src/wkwebview/navigation.rs:17). The source does not support treating resource allocation as an independently spawned operation that can resume after cleanup.

  The reload fixture strengthens this source assessment: [pa09-document-reload.ts:35](/var/folders/b5/2mh_j5tj7m71xhcjsk2z1t4c0000gn/T/noname-pa09-76hf4fur/worktree/apps/web-client/scripts/pa09-document-reload.ts:35) allocates all seven remaining slots after each replacement document creates its validator.   The twelve beacons record **120 unsettled JavaScript operations** at navigation. That establishes pending UI activity, not that all 120 native operations had started. The report correctly preserves that distinction.

- **Correct: Retirement preserves executing-command and queued-command semantics.**

  [native_engine_host.rs:79](/var/folders/b5/2mh_j5tj7m71xhcjsk2z1t4c0000gn/T/noname-pa09-76hf4fur/worktree/apps/desktop-client/src/native_engine_host.rs:79) extracts the existing owner loop without changing dispatch semantics.
