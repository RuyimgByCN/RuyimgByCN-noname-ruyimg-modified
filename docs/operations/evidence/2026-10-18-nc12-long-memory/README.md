# NC12 长程内存口径：计数分配器实测（2M 命令，净活字节 +48 KB）（2026-10-19）

- 日期：2026-10-19
- 工作包：**NC12**（[方案 §NC12](../../../architecture/native-convergence-plan.md#nc12)）「≥30 分钟持续负载」的内存面
- 规则版本 v322（工作树）/ 存档格式 v105
- 结论：**2,000,214 命令 / 14.6 亿次分配后，净活字节仅 +49,242（≈48 KB），峰值活字节 3.39 MB** → **无内存泄漏信号**；**RSS 仍不可测**（沙箱）

## 1 方法

```bash
./target/release/examples/nc12_bench long tier=swd seats=4 budget=8 \
  min_cmds=2000000 max_games=200000 sample_every=2000 alloc=1
```

`alloc=1` 打开示例内置的**计数分配器**（`GlobalAlloc` 包装，统计累计分配/释放/次数/峰值活字节），
在 `phase=process_start` 与 `result=OK` 各输出一次快照。日志：[alloc-long.log](alloc-long.log)。

## 2 实测

| 指标 | 值 |
|---|---|
| `total_cmds` | **2,000,214** |
| `heap_allocated_bytes`（累计） | 340,614,417,851（≈340 GB） |
| `heap_freed_bytes`（累计） | 340,614,368,609 |
| **`heap_live_delta_bytes`（净活增长）** | **49,242（≈48 KB）** |
| `heap_alloc_calls`（累计分配次数） | 1,458,248,476（≈14.6 亿） |
| **`heap_peak_live_bytes`（峰值活）** | **3,394,526（≈3.39 MB）** |
| `rss_*` | `NA` / 0（**沙箱禁用 `ps`，RSS 不可测**） |

**判读**：14.6 亿次分配后净活仅 +48 KB、峰值 3.39 MB → **未见随命令数增长的堆活字节积累**
（该口径覆盖 Rust 堆分配；**不含** mmap/线程栈/第三方库自有分配 → 不能等同于「RSS 无增长」）。

## 3 口径边界（不得外推）

- 本口径是**计数分配器**（堆分配统计），**不是**进程 RSS；沙箱禁止 `ps`，故 RSS 与温控仍缺失；
- 运行时长约 **4 分钟**（2M 命令）——内存面结论**不替代** ≥30 分钟门槛（后者见
  [20M 长程证据](../2026-10-18-nc12-plan-crash/README-long.md)，其中 RSS 同样为 `NA`）；
- 未做**跨进程**比较（例如同一二进制两次运行的基线差异）。
