# O2 全量测试合并·第一批（2026-10-14）

## 任务来源

[O2 测量与试点](../2026-10-14-o2-build-efficiency/README.md) 的立项决定：全量合并（1,078→约 50–100 个按批次族分组文件）为 91s 增量重链的主要杠杆。本批为第一批。

## 合并方式（逐字 mod 包裹——零改名、零语义转换）

每个源文件逐字包裹为 `mod <原文件名> { … }` 并按家族前缀（`original_<族>_`）归入
`tests/original_merged_<族>.rs`（25 个家族文件）。**#[test] 函数名不变、测试数量不变**；
测试全名获得确定性前缀（`原文件名::函数名`，子串过滤行为不变——`cargo test <fn>` 仍命中）；
`include_bytes!/include_str!` 相对路径不受影响（同目录）；`super::`/`crate::` 语义：前者
不变（同为测试 crate 根），后者一例自引用（sp 族 `crate::setup`，指本文件根）改写为
`super::<原文件名>::setup`（3 处）。

**纳入面**：805+113=918 个源文件（含试点后残留）并入 25 个家族文件；跳过 195 个
（89 个家族<3 文件保持独立、70 个 use 本地名与固定注册表冲突[canonical_state_hash/
project_observer 两路径族]、45 个 #[test] 名跨文件冲突——保留为独立文件，零改名）。
试点合并的 `original_small_pack_asserts.rs`（8 测）保持不变。
