## 3 **根因已查明**：所谓「状态依赖」是夹具假象（2026-10-19 同轮）

**排查链条**：
1. 初版失败（`WrongPhase`）→ 登记两种猜测（牌种限制 / 检查顺序），**未判定**；
2. 两种子对照 → 看似「状态依赖」→ **撤回两种猜测**；
3. 8 组矩阵（2 种子 × 2 推进方式 × 2 授予时机）→ **唯一决定因素是种子**；
4. **打印 card id/suit** → **真相**：`debug_place(player, name)` **只按名字查找**，同名的
   【无懈可击】既有 ♦（红）也有 ♣（黑）实例：

```
seed=20265501 → placed card=73 suit=Diamond（红）→ 奇袭不转化 → Rejected(WrongPhase)
seed=20265601 → placed card=71 suit=Club  （黑）→ 奇袭转化   → Accepted
```

→ **原生行为一致且正确**（黑→转化、红→不转化）；此前的「状态依赖」**是夹具假象**，**已撤回**。
**夹具修法**：按**花色取 card id** 后直接放入手牌（不再经 `debug_place` 的名字查找）→ 用例**转为通过**。

**方法学（写入证据，第 4 条）**：`debug_place(player, name)` **不保证实例**（同名牌可能有多花色）
→ 凡涉及**颜色/花色**的验证，必须**按 id 布阵**。

## 4 夹具经验（写入证据）

- 【闪】**全为红色** → 无法作「黑色载体」（武圣样本已踩过，本样本再踩一次）；

  原牌种本身可玩（本样本初版即因此把「黑色无懈被接受」误读为转化生效）。
