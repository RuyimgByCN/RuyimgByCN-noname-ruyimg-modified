## 3 未验收项的两种可能（**未判定，不写成结论**）

以**黑色【无懈可击】**为载体时实测 `Rejected(WrongPhase)`：
1. 转化对**牌种**有限制（只覆盖部分黑色牌；对照：武圣样本中**红色**无懈曾被接受）；
2. **可玩性检查在转化之前**执行（先按原牌种判 `WrongPhase`）。

→ 需分别构造「黑色非锦囊」载体与「可玩性检查顺序」探针来区分；`#[ignore]` 已保留诊断。

## 4 夹具经验（写入证据）

- 【闪】**全为红色** → 无法作「黑色载体」（武圣样本已踩过，本样本再踩一次）；

  原牌种本身可玩（本样本初版即因此把「黑色无懈被接受」误读为转化生效）。
