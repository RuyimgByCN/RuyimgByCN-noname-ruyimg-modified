⇒ **上游「结束/之后」类时机无法一一对应**，属**表达力边界**，**不是映射错**。

**受影响**：U05-XJ 的 8 条、U05-SWD 的 2 条（`damageAfter` 类）—— **同类问题不再逐包登记**。
