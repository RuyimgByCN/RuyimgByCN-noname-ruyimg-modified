# 交付/实现/登记 三维核对（2026-10-19）

- 工作包：**NC08 / 扩展台账**；规则版本 v322（工作树）/ 存档格式 v105
- 目的：找出「**包内已交付**但**原生无实现**」的卡（样本 125 闪电箭即此类 ⇒ 需系统化）

## 方法

对每个 `packages/extensions/*/assets/cards.json` 的**全部卡名**，做**两个维度**的检索：

1. **实现维**：`crates/engine-native/src/**/*.rs`（小写）是否出现该名；
2. **登记维**：`docs/**/*.md`（小写）是否出现该名。

**归一化**（**关键，缺一则误报**）：剥离来源前缀（`swd_`/`gw_`/`gj_`/`ycn_`/`wd_`/`hl_`/`xz_`/`ow_`/
`hearth_`/`mtg_`/`zf_`/`hslingjian_`）**并剥离尾部数字**（多副本编号，如 `swd_caoyao1/2/3`）。

> **未做尾部数字归一时**，swd 会误报 **21 项**「无实现且无登记」、zhenfa **4 项**；
> 归一后**降至 1 项** ⇒ 该归一化是**必须**的。
