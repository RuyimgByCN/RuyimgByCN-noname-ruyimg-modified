# ⚠ 「牌堆包 + 卡牌包」的目录构成：**判据被实验否定**（2026-10-19）

## 1 想验证什么

第 178 行结论：`pile.json` 是**替换牌堆**语义，不能与卡牌包按「两包之和 + 标准牌」求和。
**我假设**：既然它替换牌堆，那么两包同载时**标准牌不该计入** ⇒
「目录 = 牌堆包卡数 + 卡牌包卡数」。

## 2 实测（20 对，全失败）


以第一行为例：`244 - 120 = 124` —— **恰好是标准牌数**。

⇒ **结论**：**标准牌仍然计入目录**，`pile.json` 只是**在目录里增加自己的牌**，
「替换」发生在**开局发牌/牌堆初始化**那一层，**不是目录层** ❗

## 3 因此

| 项 | 结论 |
|---|---|
| 我的判据「目录 = 牌堆包 + 卡牌包」 | ❌ **否定**（差 124 = 标准牌）|
| 正确的目录构成 | **= 标准牌 + 牌堆包 + 卡牌包**（**未验证** —— 本轮没跑这个判据）|
| 第 178 行的「求和不变式不适用于 pile 包」 | ✅ **仍然成立**（只是原因不是「目录不计标准牌」）|
