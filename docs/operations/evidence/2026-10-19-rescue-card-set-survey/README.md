# 救援检测卡牌集合普查（2026-10-19）

- 工作包：**NC08 / 修复清单第 52 项**；规则版本 v322（工作树）/ 存档格式 v105
- 目的：**系统核对「哪些牌被视为救援牌」**（承接第 52 项的对照实验）

## 方法

对候选救援牌逐一构造**同一濒死局面**：0 号持该牌、1 号 **1 血**、0 号出**【杀】**（1 号无【闪】⇒ 受伤至 0），
观察濒死时该牌**是否出现在 `dying_save` 窗口中**。

## 结果（**可复核清单**）

| 救援牌 | 获提供 | 被救回 | 询问 |
|---|---|---|---|
| **【桃】** | **true** | **true** | `dying_save` |
| **【酒】** | **true** | **true** | `dying_save` |
| **【虎符】** | **false** | **false** | **`[]`**（无窗口） |

⇒ **救援检测的卡牌集合 = {【桃】,【酒】}**，**不含【虎符】** ⇒ 与第 52 项结论一致。

## 用途

1. **修法直接依据**（第 52 项）：把 `Hufu`（**及所有救援类牌**）并入救援检测；
2. **回归防线**：本普查可作为「救援牌集合」的**可复核清单**——新增救援类牌时应同步纳入，
   避免**同类遗漏**；
3. **边界**：本普查只判「**是否获提供**」；**哪些牌应当**是救援牌由上游语义与规则基准判定。

## 夹具要点（**第 5 次同类教训**）

首轮用 `c.name == card_name` **相等匹配** ⇒ 虎符（目录名 `swd_hufu`）**静默漏卡**、误报 `NOT_IN_CATALOG`；
改用 **`contains`** 后正常 ⇒ **按卡名检索一律用 contains/归一**。
