### 仁王盾（新牌种 Renwang，编码 94）

equip2 防具（♣2）：**锁定——黑色【杀】对装备者无效**（先于八卦阵判定；
红杀照常进入判定/出闪流程）。与泛型 Armor 的八卦阵语义分牌种互不干扰。
测试 `renwang_blocks_black_sha_only`：黑杀免疫（无伤/无询问）+ 红杀照常
（跨回合规避 ShaLimit）。
