## 组合矩阵（`huanle_combo_*` 三测试）

| 组合 | 测试 | 结果 |
|---|---|---|
| 写轮眼×据守 | `huanle_combo_stolen_jushou_fires_for_thief` | 窃得的据守在窃得者回合结束阶段真实触发（确认门 → 翻面 + 摸 1）；目标保留原实例（窃取为复制非转移）；途中其他玩家可选触发一律放弃以保持状态干净 |
| 写轮眼×据守×面具 | `huanle_combo_stolen_jushou_flip_cancelled_by_mask` | 前置取消窗口（TurnOverBefore）对**窃得技**的翻面同样生效：翻面被取消、摸牌仍执行（登记差异复用） |
| 苦无×手里剑 / 苦无×雷杀 | `huanle_combo_kuwu_sha_like_and_non_sha_damage` | ③ 手里剑造成的伤害**不是杀**：苦无不触发（目标弃权受伤、手牌不变——两线语义一致的负例）；④ 雷杀伤害触发苦无（`is_sha_like` 含雷/火杀——登记差异的行为面固化），确定性弃目标首张手牌 |

**矩阵口径**：六卡 + 据守间的语义交互通道共四类——伤害来源联动（苦无）、
翻面前窗口（面具）、技能窃取（写轮眼）、使用前取消（猴子）；酒尾（结束
阶段自回血/摸牌）与手里剑（基础牌直伤）不与其他通道交叉。跨通道组合由
上述测试覆盖；同通道内无重叠；其余两两组合为无交互独立技并存（装备
授予/撤销生命周期由既有测试覆盖）——组合项据此关账。
