## 语义（上游唯一 reyicong 定义 = refresh 改版）

锁定技，纯状态面（无触发无机器，computed_distance 状态修饰，马术同款）：
- **外向**：义从持有者计算与其他角色的距离 −1（无条件）；
- **内向**：其他角色计算与义从持有者的距离 +1（持有者体力值 ≤2 时）。
- 与 ±马/马术在统一修饰链叠加，共享饱和下限 1。

经典「体力>2 时 −1」口径与此不同——已按上游实际定义实现并在规则
基准登记取舍。

## 测试（`gongsunzan_assembly_yicong_distance`）

- 装配授予 + 体力上限 4。
- 高体力（4）：外向 −1（三人局饱和下限 1）、内向不加成。
- 掉到 2 体力：他人算向持有者 +1（0→1、2→1 均为 2），外向仍 −1。
- 与 0 号 +1 马叠加：1→0 = 1+1−1 = 1（防御马与外向 −1 抵消）、
  0→1 = 1+1 = 2（0 号的防御马不影响 0→1）——首版测试把马的方向
  搞反（+1 马影响他人→持有者），已修正断言数学（技能实现无改动）。
