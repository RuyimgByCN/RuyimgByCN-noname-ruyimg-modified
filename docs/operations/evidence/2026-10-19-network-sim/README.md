# NC12 弱网档位：**CDP 网络模拟**尝试（2026-10-19，**结论：对 loopback 无效**）

- 日期：2026-10-19
- 工作包：**NC12**
- 规则版本 v322（工作树）/ 存档格式 v105
- **结论（必读）**：在 **localhost 静态服务**下，CDP `Network.emulateNetworkConditions`
  **无法**使三个档位产生可区分差异 → **本方法不能用于弱网验收** ✗（**如实登记，避免被误引**）

## 1 方法

`nc12-browser-coldstart.mjs` 新增**第 7 参数**（`none` 默认 | `slow3g` | `fast3g`）：

| 档位 | 下行 | 上行 | 延迟 |
|---|---:|---:|---:|
| `slow3g` | 400 kbps | 400 kbps | 400 ms |
| `fast3g` | 1.6 Mbps | 750 kbps | 150 ms |

## 2 实测（同产物、同服务、各 3 次迭代）

| 档位 | to_interactive_ms | p50 | all_interactive | console_errors |
|---|---|---:|---|---|
| none | `[260, 260, 261]` | **260 ms** | true | `[]` |
| slow3g | `[260, 261, 262]` | **261 ms** | true | `[]` |
| fast3g | `[261, 261, 263]` | **261 ms** | true | `[]` |

原始输出：[network-profiles.txt](network-profiles.txt)。

**判读**：三档位 p50 差异 **≤1 ms**（在噪声范围内）→ **模拟未生效** ✗。原因：目标是
**loopback（127.0.0.1/localhost）**，Chromium 的网络条件模拟**不作用于回环流量**（常见行为）。

## 3 因此

- **不**据此宣称「弱网档位已验收」✗；NC12 的**真实网络**项在[进度主稿](../../../architecture/native-progress.md)
  中**仍为未验收**；
- 若要做弱网验收，需**非回环**条件：① 真实远端源站；② 本机反向代理（如 `toxiproxy`/`tc`）
  置于浏览器与源站之间；③ 或直接以**真机 + 真实网络**测量（**当前无设备**）。

## 4 保留价值

- 脚本的**第 7 参数**已就绪 ✓：一旦改用非回环源站，**无需改脚本**即可复跑三档位；
- 本节的**否定结论**可防止后续把「localhost 三档位无差异」误读为「弱网无影响」✗。
