## 1 U01（d3 / 末焱）—— **6 条**（原文有「## 登记差异」小节）

| # | 差异 | 备注 |
|---|---|---|
| 1 | **开局已在判定阶段且 `round == 1` 时不发阶段开始** | 末焱**不补发上游 `{global:"roundStart"}` 的第 1 轮** |
| 2 | **取消和未选中的牌立即弃置** | 上游**留在处理区** |
| 3 | **展示牌挂在宿主机器上** | **不进桌面或处理区** |
| 4 | **获得＝手牌推入 + `CardsGiven`** | **不发** `CardsMoved`/`CardsDrawn`/`CardsDiscarded`；**不是上游 `gain2`** |
| 5 | **点数与随机流无关** | —— |
| 6 | **空牌库/空弃牌堆负例把多余牌挪到 `core.table`** | 仅为**恢复时归属**，非末焱结算区 |

## 2 U03 / L04（cardpile 两包）—— **各 5 条**（原文「规则差异」列）

| # | 差异 | 备注 |
|---|---|---|
| 1 | 追加牌名含 **`_scale_huosha_`**，`kind.key()` 为 `huosha` | 两包一致 |
| 2 | 花色按 **club、diamond、heart、spade** 排序 | **只改变生成顺序** |
| 3 | **点数不是 `Math.random`** | 确定性 |

| 5 | **`playpackconfig` 未逐项对照**；**不记为上游等价** | 明确的验收保留 |

> L04 与 U03 的条目**基本相同**，但台账明确「**不因此把两行合成一次验收**」⇒ 本表**分来源登记**。
