# 阶段 5 / M1：标准身份局

> M1：标准包自动装载、25 武将、扩展锦囊、属性杀/防具/无懈、DSL 过滤器（`owner_from_hand_empty` 等）驱动连营/枭姬。


## 开局

1. 2–8 人，座位 0 固定为 **主公**；其余身份按标准表生成后确定性洗牌。
2. 从标准武将池洗牌各发 1 名武将；主公体力上限 +1。
3. 武将技能挂到 Trigger/Modifier 索引（如曹操奸雄、赵云/吕布马术示意、司马懿攻击范围示意）。
4. 标准牌堆（基本牌 + 装备 + 常见锦囊：无中/过河/顺手/决斗/AOE/延时/借刀/铁索/火攻/**无懈**）。
5. 每人起始手牌 4；主公进入摸牌阶段再摸 2。

## 胜负（经典简化）

| 条件 | 结果 |
|---|---|
| 主公死亡，场上仅剩 1 名存活且为内奸 | `RenegadeWin` |
| 主公死亡，其它情况 | `RebelWin` |
| 反贼与内奸全部阵亡，主公仍在 | `LoyalistWin` |

死亡时弃置手牌与装备，并立即检测胜负。

## 出牌（Phase 5）

- **杀 / 火杀 / 雷杀 / 桃 / 酒 / 闪**：普通杀伤害 `nature=0`；**火杀** 火焰；**雷杀** 雷电。酒仍可 +1 伤害（属性保留）。
- **装备**：替换同槽；武器提供攻击范围；进攻马 -1 距离；防御马 +1 被距离。
- **无中生有**：摸 2。
- **过河拆桥** (`PickTargetCard` mode=0)：点选目标 **手牌 / 装备 / 判定区** 各区任意 1 张弃置。
- **顺手牵羊** (`PickTargetCard` mode=1)：点选目标 **手牌 / 装备**（不含判定区）1 张收入手牌。
- **火攻** (`HuogongShow` → `HuogongDiscard`)：目标展示 1 张手牌；使用者弃置 1 张同花色手牌则造成 **1 点火焰伤害**，否则可取消/无法弃置则失败。
- **无懈可击** (`WuxieWindow`)：锦囊使用后、效果结算前，按座位轮询有无懈者；出无懈则翻转抵消奇偶并重启询问；**奇数**张无懈则锦囊无效，**偶数**则正常结算。不可在出牌阶段主动打出。铁索**重铸**不走无懈。
  - 非延时：抵消摸牌/点选/决斗/AOE 等 deferred 效果。
  - **延时**（乐/兵粮/闪电）：先弃入弃牌堆，未抵消则再移入目标判定区；被抵消则留在弃牌堆。

## 伤害属性与防具

- `DealDamage.nature`：`0` 普通 / `1` 火焰 / `2` 雷电（`rule_api::damage_nature`）。
- **火攻 / 火杀** 为火焰；**雷杀 / 闪电** 为雷电；普通杀与 AOE/决斗默认普通。
- `CardKind::is_sha()` / `sha_nature()`：统一普杀/火杀/雷杀。
- **藤甲**（装备 def=`DEF_TENGJIA=111`）：
  - 锁定：你成为 **南蛮入侵** 目标时效果对你无效（不响应、不受伤）。
  - 锁定：受到 **火焰伤害** 时此伤害 **+1**（失去体力通道不触发；火杀/火攻均触发）。
- **八卦阵**（装备 def=`DEF_BAGUA=110`）：
  - 需出 **闪** 时（杀响应 / 万箭），选项含 `BAGUA_RESPONSE_TOKEN`。
  - 选择八卦：翻判定牌；**♥ 视为打出闪**；非红心则失败，可再选闪或再次八卦，或取消受伤。
- 铁索传导：属性一并传导；各目标独立结算藤甲增伤。

## Headless Runner

`run_identity_match`：自动处理 Choice（濒死求桃、弃牌、过河/顺手、火攻、**无懈一律 Pass**、杀闪优先真闪否则八卦），出牌启发式含过河/顺手/火攻。

```bash
cargo run -p engine-cli -- match 4 42 2000
```

相同 `players + seed + max_steps` 下结果（outcome、hash、steps）完全一致。


## 判定阶段与延时锦囊（M1+）

- 判定区 `ZoneKind::Judge` 每座位一份；延时锦囊面朝上。
- 置入：`trick_effect::DELAYED_PLACE`（经无懈窗口后）；`face_up=true`。
- 判定：从牌堆翻顶（空则洗牌），`RuleNote code=200` 记录结果。
- **乐**：非♥ → `turn_flag::SKIP_PLAY`，判定后摸牌正常，出牌阶段被跳过进入弃牌。
- **兵粮**：非♣ → `turn_flag::SKIP_DRAW`，离开判定后直接进入出牌。
- **闪电**：♠2–9 造成 3 点**雷电**伤害并弃置；否则移到下家判定区（下家已有闪电则弃置）。
- 死亡时弃置判定区。


## 杀-闪响应（M1+）

1. 使用杀后，若目标有合法「闪」响应选项，打开 `ContinuationKind::RespondToSha`。
2. 选项：手牌闪 / **view_as 闪**（龙胆等）/ **八卦 token**（有八卦阵时）。
3. 取消或空选择 → 结算伤害；打出闪 → 消耗该牌；八卦成功 → 视为闪。

## 制衡

`ActivateSkill` 制衡时：
- 带 `card_targets`：直接弃这些牌并摸等量；
- 否则打开 `ZhihengDiscard` 多选（至少 1 张）。


## AOE / 决斗 / 无双

- **南蛮** (`RespondAoeQueue` kind=1)：逐人出杀，取消受伤。
- **万箭** (kind=2)：逐人出闪，取消受伤。
- **决斗** (`JuedouDuel`)：双方轮流出杀，先放弃者受伤；最多 32 次交换。
- **无双**：出杀时 `need=2` 张闪（或视为闪）。
- 响应弃牌用 `MoveCards`（不触发 `CardUsed`/集智），避免无限摸牌。
- 濒死求桃必须**消耗一张桃**；濒死可打断 AOE 并在结算后 `resume`。


## 鬼才 / 借刀 / 铁索

- **鬼才** (`GuicaiRewrite`)：判定牌翻出后、生效前，持有鬼才且有手牌者可打出一张手牌代替判定结果。
- **借刀** (`JiedaoChoice`)：指定有武器角色与目标；持刀者选交武器或对目标出杀。
- **铁索**：`MARK_CHAIN` 横置；受伤（非失去体力）时传导给其他横置角色并全部重置。
