# 阶段 9：旧扩展迁移工具链

## 原则

- 旧引擎只用于**语义研究、清单提取、差分辅助**
- 新引擎**不执行**旧 JavaScript
- 自动生成 DSL 是**辅助**，不宣称与任意 JS 语义等价

## 兼容等级

| 等级 | 含义 |
|---|---|
| **A** | 静态可映射（如 forced 触发 + 可识别 draw）→ 骨架可编译候选 |
| **B** | 结构完整，需人工补 filter/cost/content |
| **C** | 结构可识别，逻辑需重写 |
| **D** | DOM / 网络 / 文件 / eval / 非确定性 RNG 等 → 仅数据与资源 |

## CLI

```bash
cargo run -p legacy-analyzer -- analyze path/to/skill.js \
  --json report.json --md report.md --skeletons out/skills

cargo run -p legacy-analyzer -- skeleton path/to/skill.js --out out/skills

cargo run -p legacy-analyzer -- hash content.pkg.json
cargo run -p legacy-analyzer -- sign content.pkg.json --key secret --out sig.json
cargo run -p legacy-analyzer -- verify content.pkg.json sig.json --key secret
```

对上游标准包示例：

```bash
# from noname-next/; selected original repository lives one level above this repo
cargo run -p legacy-analyzer -- analyze \
  ../archive/upstream/noname/apps/core/character/standard/skill.js \
  --md /tmp/standard-migration.md --skeletons /tmp/sk
```

全仓清单、源码与资源同步：

```bash
node scripts/sync-original-content.mjs
node scripts/sync-original-content.mjs --verify-only
```

同步器使用 TypeScript AST 读取顶层定义，再复用 `legacy-analyzer` 生成能力画像。当前目录覆盖
上游 **1.11.5** 的 26 个武将包、2526 名武将和 6068 个顶层技能（2026-08-16 复核，head
`2eb3513b`，全部 `ported`）；详见 `content/original/README.md`。这一步只生成迁移输入和
证据，不会自动把 A 类或任何骨架标成可玩语义闭环。

## 输出

- **JSON / Markdown 报告**：每技能等级、原因、能力命中、触发摘要
- **`.skill` 骨架**：带 TODO 与 disclaimer 的 Next DSL
- **签名**：keyed blake3（完整性/来源标签，**不替代** VM 沙箱）
